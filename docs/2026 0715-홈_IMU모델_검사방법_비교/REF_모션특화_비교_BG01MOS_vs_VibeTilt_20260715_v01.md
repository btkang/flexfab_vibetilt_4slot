# REF_ 모션(지그) 특화 검사방법 비교 — BG01 MOS Tester ↔ VibeTilt 모션검사 (2026-07-15, v01)

## 목적
- 사용자 메모: "IMU 모델 검사방법 비교, 특히 모션 특화"
- 참조 4개 모델(pCOM2/pSMC/BG01핸디/BG01 MOS) 중 **모션지그(자동 기울임)를 쓰는 것은 BG01 MOS Tester가 유일**하므로, BG01 MOS ↔ VibeTilt 모션검사를 축으로 심층 비교한다.
- 전체 모델 비교는 `REF_IMU모델_검사방법_비교_20260715_v01.md` 참조.

## 0. 계보 확인 — 같은 지그 컨트롤러 혈통
소스 대조 결과 **두 프로그램은 동일한 EMIO 스텝모터 컨트롤러(PM 명령 체계)를 사용**한다. VibeTilt 모션지그는 BG01 MOS 턴테이블의 직계 후속이다.

| 증거 | BG01 MOS (C++/MFC) | VibeTilt (C#) |
|---|---|---|
| 원점복귀 | `PMO011` (`BoardLevelMo_BG01.cpp` JIG_INIT) | `PMO011`/`PMO012` (IN1/IN2 선택) (`ff_vibetilt/MotionJig.cs:783`) |
| 소프트리밋 | `PMS071288000` / `PMS08129-8000` | 동일 명령 (`MotionJig.cs:587,589,725,727`) |
| 상대 이동 | `PMD071LL±n` / 펄스확인 `PML011` | `MoveSteps()` 동일 계열 |
| 에러클리어/토크/속도 | `PPC00`, `PMS05105xx`, `PMS0712xxxxx` | JIG 초기화 계열 동일 |

차이: 지그 기어비/분해능과 **기준각 센서**.
- BG01 MOS: 마이크로스텝 256, **1500펄스 = 10.54688°** (≈0.00703°/펄스)
- VibeTilt: **0.1125°/step** (800step = 90°, `MotionJig.cs:20`), 원점→0도 1250step

## 4. 영점(0도) 확립 방법 — 모션특화 핵심 차이

**BG01 MOS**
- 현행: 기준 경사센서에 `setzcur`(현재 위치를 0으로 선언)만 수행 → 지그 기구의 절대 수평은 신뢰하지 않고 상대 기준만 잡음.
- 구버전(`angle_0_init`, 미사용): 기준센서 읽으며 **1펄스씩(≈0.007°) 미세 이동해 ±0.005° 이내 수평 트림**, 최대 100회 — VibeTilt FineAdjust의 원형.
- DUT 영점은 건드리지 않음 → DUT 오프셋 불량은 0±0.3° window에서 걸러짐(공차가 큼).

**VibeTilt**
- 홈센서(IN1/IN2, notch)로 기계적 기준 → 0도까지 정해진 step 이동 → **자이로 기준 FineAdjust(±0.05°, 방향반전 임계 0.02°, max 250step)** → **수평 확립 후 지그 자이로에 `setzcur`로 기준점(0) 설정** (`MotionJig.cs:870`).
- 순서가 핵심: setzcur를 FineAdjust **전에** 하면 자이로가 0으로 리셋되어 실제 수평을 찾지 못함 (`MotionJig.cs:860` 주석). BG01 MOS는 수평 확립 절차 없이 setzcur로 현위치를 0 선언(상대) — VibeTilt는 수평을 만든 뒤 setzcur(절대)라는 점이 같은 명령의 결정적 차이.
- 시간단축 장치: `home_every_n=10`(최초 1회+N회마다만 PMO011 ~22s), `home_skip_max_deg=7`(자이로가 7도 밖이면 강제 홈복귀), Y결합 `skip_home`.
- 이후 **DUT OFFSET(영점 캘리) 실행 + AN ±0.05 검증 + SAVE + APPCFG 확인**까지 수행 — 참조 모델 어디에도 없는 완결 사이클.

관찰: BG01 MOS는 "지그를 믿지 않고 외부 기준센서로 보정", VibeTilt는 "지그 자이로를 믿고 보정". 지그 자이로 자체의 드리프트/고장은 VibeTilt 체계에서 자기검증이 안 됨(간접 안전장치는 home_skip_max_deg, FineAdjust 발산 감지 정도).

## 5. 모션특화 시사점 (VibeTilt 검토 대상)

1. **기울기 자세에서 ACC 측면축 교차검증 (BG01 MOS 방식)** — 저비용·고가치.
   ±45° 측정 시 AN 각도만 판정하는데, 같은 자세의 GAC 측면축이 sin45°≈0.707g인지 동시 window 판정하면 각도 연산부와 가속도 원시값의 정합을 공짜로 확인. 기존 스트리밍 데이터로 가능(추가 이동 없음).
2. **Z 방위각(조립 방향) 판정** — BG01 MOS는 180°±0.3°로 수평면 회전 오조립을 감지. VibeTilt는 Z축 진동값(0.98~1.02g)으로 상하 뒤집힘만 감지 가능. VibeTilt 기구에서 커넥터/장착 방향상 이 불량 모드가 물리적으로 가능한지 확인 필요 (TODO — 기구 확인 전 판단 보류).
3. **지그 기준의 독립 검증** — BG01 MOS의 외부 기준 경사센서처럼, 지그 자이로와 독립적인 기준(예: 주기 점검용 상용 경사센서 마스터 시료)으로 지그 드리프트를 정기 확인하는 운영 절차 검토. 프로그램 변경 없이 운영으로도 가능.
4. **다채널 병렬** — BG01 MOS는 3보드 동시 검사로 사이클 타임을 나눔. VibeTilt는 X/Y 2결합 순차라 구조가 다르지만, 양산 수량 증가 시 지그 2대 병렬 운용(포트 분리) 관점의 참고 사례.
5. **매 사이클 원점복귀 비용** — BG01 MOS는 매번 PMO011(+6500ms delay). VibeTilt는 `home_every_n=10`으로 이미 개선 — 현행 유지 근거로 기록.
6. **Longrun(반복 내구) 모드** — BG01 MOS는 체크박스 하나로 전체 시퀀스 무한 반복(+GA 판정 완화). VibeTilt는 `repeat_all_count`가 있으므로 기능상 동등 — 내구 평가 시 활용 가능.

## 6. 결론
- VibeTilt 모션검사는 BG01 MOS의 지그 제어(PM 명령)와 영점 트림(1펄스 미세이동 → FineAdjust) 개념을 계승하면서, 측정 포인트(2점→4점+진동 3자세+정지), 판정 통계(1회→N샘플 all_in_spec), DUT 영점(간접→실행+검증+저장), spec 관리(하드코딩→JSON)를 모두 확장한 상위 호환이다.
- BG01 MOS에서 가져올 것이 남은 부분은 **(1) ACC 측면축 교차검증, (2) Z 방위각 판정(기구 확인 후), (3) 독립 기준센서 운영 절차** 세 가지로 정리된다.
