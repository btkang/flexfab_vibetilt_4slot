## 3. IMU 검사 상세 (핵심)

### (a) I2C 존재/통신 — Stage1
`<I2C_TEST,MOT_SEN>` → result 0 = IMU I2C 정상. (실장/버스 결선 확인, 판정 `:3440`)

### (b) 기울기 실동작 — Stage2 `ThMotSensTest` (`BG01QCDlg.cpp:4044~4227`)
검사원이 핸디 지그를 X축·Y축으로 직접 기울이고, DUT가 IMU로 계산한 각도를 폴링해 임계각 초과 확인. 화면(`CMotionSensorGuideDlg`)에 X/Y/Z 실시간 표시 + "X축/Y축 기울여 주십시오" 안내.

프로토콜:
1. `<msopen>` → `[msopen=OK]` (`:4095, :4111`)
2. `<MOTSEN>` 반복 (`:4121`) → `[MOTSEN,result,ang_x,ang_y,ang_z]` (argc>4, `:4138`)
   - result(argv[1])=0 필수 (`:4141`), 각도는 정수(도) 파싱 (`:4143~4145`)
3. `<msclose>` → `[msclose=OK]` (`:4190, :4205`)

판정 (`:4148~4171`):
| 서브 | 축 | PASS 조건 |
|---|---|---|
| 0 | X축 안내 | — |
| 1 | **X축** | `ang_x < -10 or ang_x > 10` (절댓값 **10도 초과**) |
| 2 | Y축 안내 | — |
| 3 | **Y축** | `ang_y < -10 or ang_y > 10` |

- 초기 표시 `SetXYZ(0,0,180)` (`:4081`). Z각은 표시만, 판정 미사용.
- **±10도 임계는 소스 하드코딩** (`:4155, :4165`) — config.ini에 없음.
- 15초 내 두 축 모두 넘겨야 PASS.
- **자이로/진동/영점 캘리브레이션 항목 없음** — 각도 산출·영점은 DUT 펌웨어 몫, PC는 임계 판정만.
