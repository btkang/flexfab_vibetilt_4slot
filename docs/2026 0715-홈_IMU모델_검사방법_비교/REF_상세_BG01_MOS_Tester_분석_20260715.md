## 3. IMU 측정/판정 상세

### 응답 프레임 (`<mstest>` 응답, 파싱 `angle_measureEach` `:373~390`)
```
A=<ax>,<ay>,<az>,ACC=<x>,<y>,<z>,T=<temp>,GA=<gx>,<gy>,<gz>
예) A=0.33,-0.14,0.00,ACC=0.002,0.005,1.004,T=45.52,GA=0.00,0.00,0.00
```
스케일링 `atofval(dot,str)`=값×10^dot (`:337~351`): Angle ×100(0.01°), ACC ×1000(mg), GA ×100

총괄 spec 주석 (`:358`): `// Angle +/-0.3  Accel +/-5 Gyro +/-100`

- 가속도: 수평축 0±5mg, 중력축 ≈0.98g±8mg, 측면축 ≈±0.18g (sin10.5°≈0.182 일치)
- GA(자이로 표기) 0점 축 ±1.00 (기울기 축 GA는 각도와 동일 스케일 거동 — 원소스 표기 유의)

### Longrun 모드 (`m_bChkLongrun_BG01`)
- X/Y 판정에서 GA 조건 skip (`:411~415, 433~437`), Step11에서 반복 → 내구 시험 대용 (진동 시험 아님)

### 영점 처리
1. 레거시 `angle_0_init` (`:979~1020`): 기준센서 각도가 ±0.005° 이내 될 때까지 1펄스씩(`PMD041LL1`/`PMD051LL-1`) 미세이동, 최대 100회 — 현재 미사용
2. 현행 `angle_0_init_Revision` (`:1022~1061`): 기준센서에 `setzcur`(현위치=0)만 전송
3. DUT 자체 0점: **CAL 명령 없음**, 수평축 각도 0±0.3° window 통과로 간접 판정
4. 진동/전용 자가진단 항목 없음
