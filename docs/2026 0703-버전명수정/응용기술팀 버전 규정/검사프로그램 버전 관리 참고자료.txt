1.버전 체계 정의
  버전은 x.x.x의 3자리 구조로 운영
 
    0.x.x : 시험/개발 버전
      내부 검증용으로 사용하며, 양산 라인에는 미적용 또는 제한적으로 적용
      기능 및 사양 변경 가능성이 높은 상태
    1.x.x : 양산 배포 버전
      캔탑스엠 이관 완료 기준
      양산 라인에서 사용하는 기준 검사 프로그램
   2.x.x 이상 : 대규모 변경 버전
      검사 알고리즘 변경 (판정 로직, 검사 방식 변경 등)
      하드웨어 인터페이스 변경 (카메라, 센서, 통신 방식 등)
      데이터 포맷 또는 로그 구조 변경
      기존 버전과의 호환성이 유지되지 않는 경우

2.적용 예시
      0.3.2 : 개발 테스트 버전
      1.0.0 : 양산 최초 적용
      1.1.0 : 오검출 문제 수정
      1.1.1 : 로그 개선
      2.0.0 : 검사 알고리즘 변경 (판정 기준 변경 등)

3.운영 권장 사항
      양산 라인에는 1.x.x 이상의 버전만 적용
      모든 버전 변경 시 변경 이력(Release Note) 관리 필수
      프로그램 파일명 및 로그에 버전 정보 명시
