# Release Note — ff_vl (진동기울기센서 검사프로그램)

 ── 버전 체계 변경 (2026-07-03, 응용기술팀 버전 규정 적용) ──────────────
  · 규정: 버전 = x.x.x 3자리 구조. 날짜 접미어(YYMMDD) 폐지
      - 0.x.x : 시험/개발 (내부 검증용, 양산 미적용)
      - 1.x.x : 양산 배포 (캔탑스엠 이관 완료 기준)
      - 2.x.x 이상 : 대규모 변경 (판정 로직/HW 인터페이스/데이터 포맷 변경 등 비호환)
  · 이하 v0.x.x.YYMMDD 이력은 구(舊) 체계 표기이며 참고용으로 보존한다.
  · 제조팀 배포용 간략 이력은 별도 문서(버전변경이력_ff_vl_README.txt) 참조.
