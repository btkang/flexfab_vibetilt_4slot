# PLAN_모션검사 0도 정지 정상 필터 추가 (B안)

- 작성일: 2026-06-04 / 작성: Claude
- 목표 버전: **0.7.2** (현재 0.7.1.60601의 다음)
- 대상: **모션검사** (VL20 485 우선) / `MP_workspace_motion_485_VL20.json`
- 관련 문서: 같은 폴더 `PLAN_보드정지노이즈검사_20260604_v01.md` (보드검사 측) — **상호보완**
  - 보드검사 = 첫 게이트 / 모션검사 = 2보드 구조 백업. 둘 다 있어야 완성.

## 1. 목적
**0도(평평) 상태에서 "정상이 아닌" 보드를 걸러내는 필터.**
정지 상태인데 센서값이 출렁이거나(미세 변동), 값 자체가 정상밴드를 벗어나거나, 드롭아웃(0 반환)인 보드를 모션검사 0도 지점에서 검출한다.

## 2. 핵심 발견 — 모션검사는 2개 보드 동시 검사 구조
- `#3` 작업자 안내문(line 149): **"X축 결합위치와 Y축 결합위치에 제품을 안착해 주세요"**
- UART가 둘로 분리: **X결합 보드 = `uart_485`**, **Y결합 보드 = `uart_485_y`**

| 항목 | 대상 보드 | 0도? | 0도 진동(GAC) 스트림 |
|---|---|---|---|
| #3 영점 / #4 CAL / #5 저장 | **X결합 (uart_485)** | ✅ | ❌ (#4 `verify_an` 단발 ±0.05만) |
| #6 기울기 / #7 진동(+90도) | X결합 | ❌ | #7=90도 |
| #10/#11/#12 | Y결합 (uart_485_y) | ✅ | ❌ |
| **#13 진동(0도)** | **Y결합 (uart_485_y)** | ✅ | ✅ (현재 Z 1G만 판정) |
| #14 기울기 / #15 진동(-90도) | Y결합 | ❌ | -90도 |

→ **0도 진동 스트림은 #13(Y결합) 하나뿐. X결합 보드는 0도 진동 측정이 아예 없다.**
→ **#13만 손대면 Y결합만 필터되고 X결합은 통째로 빠진다. ⇒ 양쪽에 각각 넣어야 함.**

## 3. 현재 사각 (왜 지금은 못 잡나)
- **#4 verify_an (±0.05, X)**: OFFSET(캘) 직후 단발/평균성 판정 → 캘로 0 편향 + 대칭 노이즈 상쇄(zero-mean blind). 가장 약한 고리.
- **#13 / tilt all_in_spec (tail 5/10 + retry 3)**: 큰·지속 노이즈는 잡지만, **끝 N샘플만 + 재시도 3회**가 작은/간헐 노이즈를 가린다.
- **RMS 미판정**: #13은 Z(1G)만 보고 RMS(흔들림 지표)는 안 본다.
- ⇒ **작은/간헐 정지 노이즈는 현재 설정으로 escape 가능.**

## 4. 설계 — B안 채택 (양쪽 보드에 동일한 별도 항목)

### 4.1 왜 B안 (≠ 기존 항목 병합)
| 기준 | A안(#4·#13 병합) | **B안(별도 항목)** ✅ |
|---|---|---|
| 기존 인증 판정 | #13 1G 사양(tail5/retry3) 건드림 | **무손상** |
| 다축 판정 | `check_axis_index` 단일 제약 | 자유 |
| 두 보드 일관성 | verify_an방식 vs 진동방식 = **비대칭** | **동일 방식** |
| FAIL 원인 식별 | 사양/필터 혼재 | **명확** |
| DLL 작업 | 어차피 필요할 수 있음 | 한 번에 깔끔 |

### 4.2 배치 위치
```
X결합:  ... #5 X축 파라미터 저장(0도) → [신규] 정지 안정성 검사(0도)  → #6 기울기
Y결합:  ... #13 Z축 진동값 측정(0도)   → [신규] 정지 안정성 검사(0도)  → #14 기울기
```
- 0도(평평) + 캘/저장 직후 = 모터 이동 없음 → 추가 모터부담 0, 사이클 영향 최소.

### 4.3 검사명 / id
| 위치 | 표시명(name) | id |
|---|---|---|
| 모션 X결합 (#5 직후) | **#5-1 X결합 정지 안정성 검사 (0도)** | `MOTION_STAB_X_485` |
| 모션 Y결합 (#13 직후) | **#13-1 Y결합 정지 안정성 검사 (0도)** | `MOTION_STAB_Y_485` |
| (참고) 보드검사 | 정지 안정성 검사 RS-485 | `STAB_485` (v01 문서) |

`_comment` 예: `"0도 정지 상태에서 X·Y·Z·RMS가 정상밴드 내 안정한지 판정. 값이상/미세변동/드롭아웃 필터 (all_in_spec, retry 0, no require_motion)"`

### 4.4 측정/판정 방식
- MODE **02(GAC)** 진입 → **정지** 상태 ~1초 스트리밍 수집 (이동 없음)
- 판정: **`all_in_spec`(수집 전구간 전부 밴드 이내)** = 값 정상 + 안정성 **동시** 확인
- **retry = 0** (간헐 노이즈 안 가려지게) / **tail = 전구간** / **require_motion 없음**
- 지표: **X·Y·Z 밴드 + RMS 밴드** (가능하면 X·Y **p2p(max−min)** 병행 — 아래 6 참고)

## 5. 판정 기준값 (데이터 기반 시작값)
6/2·6/4 **보드검사** 로그 GAC 실측 (평평 Z≥0.99, 정지 구간):

| 축 | 정상 중심 | std | **권장 밴드(시작값)** | 잡는 불량 |
|---|---|---|---|---|
| X (idx0) | -0.035 | 0.019 | **-0.12 ~ +0.05** | 값이상/틀어짐 |
| Y (idx1) | -0.024 | — | **-0.10 ~ +0.10** | 값이상 |
| Z (idx2) | ~1.00 | — | **0.98 ~ 1.02** | 1G 이상 |
| RMS (idx3) | 0.584 | 0.022 | **0.50 ~ 0.68** | 드롭아웃/죽은센서 |

- ⚠️ X는 **음(-) 편향(-0.035)** — 0 중심 아님(지그/실장 오프셋). 밴드를 이쪽으로 맞출 것.
- ⚠️ 0.00 드롭아웃이 정상품에도 ~0.1% 혼입 → `all_in_spec` 전구간이면 오검출. **소수 outlier 허용 또는 0.00(통신드롭) 제외** 처리 필요.
- ⚠️ 위 밴드는 **보드검사(수동지그)** 데이터라 다소 넓음. 모션 #13은 **0도 post-CAL**이라 더 타이트할 것 → **모션 0도 정상 데이터로 재확정 필요**(현재 검사 PC에 모션 로그 없음).

## 6. RMS 민감도 한계 — X/Y p2p 병행 권장 (중요)
- 실측상 RMS는 보드를 실제로 흔드는 중에도 거의 0.66을 안 넘김(std 0.022). **고주파 떨림에 둔감.**
- ⇒ **RMS = 드롭아웃/죽은센서용. "미세 변동" 검출은 X·Y의 변동폭(p2p/std)이 더 직접적.**
- 권장: RMS 밴드 + **X·Y p2p ≤ 임계**(예: p2p < 0.05~0.08, 데이터로 확정) 같이 판정.

## 8. 선결 확인 포인트 (1회 시험으로 분기 결정)

   - 먹히면 → 일부 설정으로 가능 / 안 먹히면 → **DLL에 다축 0도 정상 판정 추가**(정석).
2. **모션 0도 정상 데이터 수집** → 밴드/ p2p 임계 **재확정**.
3. (선택) 노이즈 의심 시료로 **FAIL 재현**.

## 9. 리스크 / 미결
