## 1. 무엇을 했나
0도 정지 상태에서 센서 출력 노이즈(출렁임)를 거르는 `#5-1 X결합 정지 안정성 검사` 항목을 모션검사에 추가.

- **코드 변경 없음 (JSON-only).** 보드검사 0.7.2의 `VIBE_STILL_Internal` 핸들러를 그대로 재사용.
  - `ResolveUart`의 `uart_id` 오버라이드 지원(밀어내기 2포트) — 별도 코드 불필요
  - 전축(X·Y·Z) p2p 판정 + `measure_only` 토글 이미 구현됨
  - 정지 자동측정(작업자 팝업 없음, VibeTilt.cs:2211) → 모션 자동흐름에 무간섭
- proc `id`는 핸들러로 라우팅되므로 `VIBE_STILL_485` / `VIBE_STILL_232` 그대로 사용.

## 2. 배치 / 설정
```
X결합: #5 X축 파라미터 저장(0도) → [신규] #5-1 X결합 정지검사(0도) → #6 기울기
```
- `measure_only: false` (양산 판정 ON)
- `still_p2p_max: 0.05` (전축 변동폭 ≤0.05 PASS / 초과 노이즈 FAIL)
- `_still_rms_max` 는 `_` 비활성 (RMS는 정지/동작 무관 ≈0.58, 노이즈 판정 무의미)
- 프로토콜(tests): 485 = `<MODE,1,0>`→`<MODE,1,2>`→`<START,1>`→`<STOP,1>`→`<MODE,1,0>` / 232 = `<MODE,2>`→`<START>`→`<STOP>`

## 3. 실측 근거 (485, 2026-06-09)
| 조건 | GAC | 전축 p2p | 판정 |
|---|---|---|---|
| 기울어짐(영점 skip) ①② | Y/Z≈0.7 | **0.01** | (measure_only) |
| **진짜 0도 post-CAL** | Z=1.00, X/Y≈0 | **0.0000** | **PASS (판정 ON)** |

- p2p(변동폭)는 자세(기울기)와 무관 → 0도 아니어도 노이즈 측정 유효함을 확인
- 진짜 0도 post-CAL에서 p2p=0.0000 (108샘플 완전 정지) → 정상품 충분히 안정
- 임계 0.05 = 정상 노이즈(0.00~0.01)의 5배 마진. 보드검사 232·485에서 이미 양산 검증된 값

## 5. 검증 결과
- **485**: 진짜 0도(영점→CAL→저장 후) `#5-1` → `[STILL] PASS value=0.0000` ✅ 양산 조건 검증 완료
- **232**: `#5-1` 삽입 완료. 실기 검증은 232 시료 연결 시(`[STILL] PASS value≈0.0/0.01` 확인). 보드 232에서 0.05 이미 검증돼 안전.
