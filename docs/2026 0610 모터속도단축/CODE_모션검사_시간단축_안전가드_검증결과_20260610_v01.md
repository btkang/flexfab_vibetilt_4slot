## 3. ③ +20°/-20° 방향전환 헤맴 수정 (C1) — ★핵심 성과

### 원인
방향전환(예 -45°→+20°)은 65° 큰 coarse 이동(578 step ≈ 580ms)인데, coarse 후 대기(`tilt_move_wait`)가 300ms로 짧아 **coarse가 끝나기 전에 FINE이 시작** → 잔여 이동 + FINE step 충돌 → 오버슈트 → 왕복.

### 수정 (C1, MotionJig.cs RunTiltMeasure coarse 이동부)
고정 대기 대신 **이동량 비례 대기**:
```
int coarseSettle = Math.Max(_tiltMoveWait, Math.Abs(steps) + 200);
Thread.Sleep(coarseSettle);
```
→ 큰 이동일수록 더 대기, 작은 각도는 기존과 동일(빠름).

### 검증 (X +20° 4회 재현)
| | C1 전 (어제) | C1 후 (오늘) |
|---|---|---|
| 시작오차 | -9.6° 또는 +41° 오버슈트 | **5.1 / 5.2 / 5.6 / 5.1°** (정상) |
| FINE step | 12~19개 (왕복 12~18초) | **3개** (수렴) |

Y -20°도 동일하게 step 3~4개로 정상화. **방향전환 왕복 제거 확정.**

### 한계
-20°/-45° 첫 측정 등 작은 각도는 backlash 오버슈트로 여전히 step 5~10개. **이건 C1과 무관한 기구부 유격이라 SW로는 못 잡음.**

## 4. ④ 안전장치 C2 + C3 — ★핵심 성과 (사고 차단)

## 5. ★ #6/#14 단독 실행 동작 규칙 (다음에 헷갈리지 말 것)
