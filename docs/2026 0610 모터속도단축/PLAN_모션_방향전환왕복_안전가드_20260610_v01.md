## 1. 배경 (실측으로 드러난 2가지)

### 1-1. tolerance 완화만으론 단축 안 됨 — 진짜 병목은 "방향전환 왕복"
2026-06-10 TEST 풀런(tolerance 0.15 + fine_step 300): **3m05s — baseline 2m46보다 오히려 느림.**
- X +20°(−45→+20 전환): 왕복 **12초**
- Y −20°(+45→−20 전환): 왕복 **18초** (FINE step 19개)
- 작은 각도에서 tolerance로 번 1~2초를 방향전환 왕복이 완전히 압도.

**원인:** 방향전환은 65° 큰 coarse 이동(578 step ≈ 580ms)인데 `tilt_move_wait`가 300ms → **coarse 이동 중(절반쯤, 자이로 ~중간값)에 FINE 시작** → FINE이 큰 step 발사 + coarse 잔여이동 충돌 → 오버슈트 → 왕복. (zero_settle 발산과 같은 뿌리: 이동시간 > settle)

### 1-2. 영점 없이 #6 실행 시 FINE 발산 → 케이블 2바퀴 감김 (안전사고)
풀런 직후 #6 연속 실행 → `_zeroInitialized=true`라 **영점(InitMotionZero) 자동 스킵** →
- 자이로 기준(setzcur) 불일치: FINE 시작 오차 **38.7°**(목표 −20°, 자이로 +18.7°)
- **soft limit이 운용값 ±1600(180°)으로 안 줄고 ±8000 상태**
- FINE step 발산(275→390→620→1347…) → soft limit 넓어 **2바퀴(720°+) 감김** → 사용자 강제종료

이건 tolerance와 무관. 영점 없이 기울기 실행 + 넓은 soft limit + FINE 발산 무방비가 겹친 사고.

## 2. 목표
1. **안전**(최우선): FINE 발산으로 케이블 감기는 사고 원천 차단.
2. **시간단축**: 방향전환 왕복 제거(진짜 병목).
3. CAL/영점 정밀도·판정 정확도 불변.

## 3. 코드/구조 사실 (재사용 지점, MotionJig.cs)
- `FineAdjust()` (~1468): 루프에서 step 계산·이동·자이로읽기·방향반전. **누적 이동/오차 상한 없음 → 발산 무방비.**
- `MoveSteps()` (~1573): `PMD0{len}1ML{steps}` 전송 후 `EmioRecvUntil("pmd0011", timeout)`. pmd0011이 명령ACK인지 이동완료인지 불확실 — 작은 이동은 `tilt_move_wait`로 충분, 큰 이동은 부족.
- `RunTiltMeasure()` coarse 이동(~945): `MoveSteps` 후 `Thread.Sleep(_tiltMoveWait)`(기본500/TEST300). 큰 이동 시 부족.
- `InitMotionZero()` soft limit(~866): 영점 끝에 ±1600 설정. 영점 스킵 시 미적용.
- 자이로 폴링 패턴: 홈복귀 대기(~804)에 이미 "연속 2회 안정 → 정지판정" 코드 있음 → coarse 완료 판정에 재사용 가능.

## 4. 변경 계획

### Phase C1 — coarse 완료 보장 (방향전환 왕복 제거) ★시간단축 핵심
- `RunTiltMeasure` coarse 이동 후 고정 `tilt_move_wait` 대신 **이동량 비례 대기** 또는 **자이로 안정화 폴링**:
  - 안: coarse step 수가 임계(예 >300) 이상이면 `wait = max(tilt_move_wait, |steps|×0.6 + 여유)`, 또는 홈복귀처럼 자이로 연속 2회 안정까지 폴링(상한 타임아웃).
- 효과: +20/−20 방향전환에서 FINE이 정확한 위치(±2°)에서 시작 → 왕복 제거 → 각 12~18초 → 정상(~9초)대.
- 작은 각도(작은 이동)는 기존과 동일(빠름).

### Phase C2 — FINE 발산 안전가드 ★안전 최우선
- `FineAdjust` 루프에 **이탈 상한** 추가: `|current − targetAngle|`가 초기 오차 또는 절대 한계(예 목표±15°)를 **초과하면 즉시 abort**(FAIL 반환).
- 방향반전이 N회(예 4) 연속 + 오차 미감소면 abort.
- 효과: 영점 불일치/탈조로 발산해도 **2바퀴 감기기 전 정지**. 케이블 보호.

### Phase C3 — soft limit 상시 보장
- 기울기/측정 진입 시(또는 MoveSteps 전) soft limit이 운용값(±1600)인지 보장. 영점 스킵돼도 넓은 ±8000 방치 안 함.
- 또는 `_zeroInitialized=false`거나 FINE 시작 오차 과대 시 **영점 강제 실행**.

### 부수 — tolerance/fine_step 원복 검토
- 현 TEST의 tolerance 0.15 / fine_step 300은 효과가 방향전환에 묻혀 미미 → **일단 원복**(0.05/500), C1~C3 적용 후 재평가. (작은 각도 이득은 C1로 왕복 잡힌 뒤 다시 측정)
