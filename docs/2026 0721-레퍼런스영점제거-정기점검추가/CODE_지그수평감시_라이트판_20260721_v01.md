### 판정 로직 (JigHealthCheck)

```
jig_health_check=false → 통과 (기본, JSON으로만 켬)
!homed → 판정 생략 (로그는 IsTest에서만: "홈 생략 사이클 — 판정 생략")
rPre=NaN → 판정 생략 (로그: "판독 없음")
dev = |rPre − baseline|
grade: |rPre|>abs_limit 또는 dev>ng → NG / dev>warn → WARN / 그외 OK
로그(IsTest 밖): [JIG] 기구영점 X: read=+0.000 base=+0.000 dev=0.000 (경고 0.10 / NG 0.25) OK
NG 연속 ng_streak회 또는 abs 가드 → confirmCallback 팝업 (실행당 1회)
  확인 → "[JIG] 작업자 점검 확인 (dev=...)" 후 계속
  취소 → "[JIG] 작업자 취소 — 지그 점검 필요" + 항목 FAIL
```

### 점검 후 재판정 절차 (팝업 문구에 안내 포함)

점검 조치 후 **프로그램을 껐다 켠다** — static 3개(_motionZeroCount/_jigNgStreak/_jigAlertShown)가
리셋되어 첫 #3이 무조건 홈 수행 → 즉시 [JIG] 재판정. 조치 실패(여전히 NG)면 팝업 재발.
재시작 없이는 다음 판정이 최대 10사이클 뒤 + 팝업 소진 상태이므로 재시작이 사실상 필수.
