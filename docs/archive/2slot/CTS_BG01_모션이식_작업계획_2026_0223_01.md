## 3. 현재 확인된 핵심 사실 (내일 구현 기준)
### 3.1 모션 시퀀스(상태머신)
- 시작: `OnBnClickedButtonStart()` -> `m_iTestStep_BG01 = JIG_INIT`
- 단계:
  1. `JIG_INIT`
  2. `OPEN`
  3. `DEGREE_0_CHECK`
  4. `ANGLE_p_10_5_0`
  5. `MEASURE_ANGLE_p_10_5`
  6. `ANGLE_m_10_5_0`
  7. `ANGLE_INIT_0`
  8. `pCOM_INIT`
  9. `ANGLE_m_10_5_1`
  10. `MEASURE_ANGLE_m_10_5`
  11. `ANGLE_p_10_5_1`
  12. `ANGLE_INIT_1`
  13. `END`

### 3.2 EMIO 핵심 응답 패턴 (실로그 교차확인됨)
- 원점복귀: `pmo0011` 후 `pmp0011` 자동 수신.
- 이동 중 첫 오류 패턴: `pmd5011 -> ppc606138000 -> pmd0011`.
- 이후 이동 완료는 `pmd0011` 반복.
- pcom 로그에서 파일별 공통 관측:
  - `pmo0011`: 1회
  - `pmp0011`: 1회
  - `pmd5011`: 1회
  - `ppc606138000`: 1회
  - `pmd0011`: 35~36회

### 3.3 측정 통신
- 센서 open/close: `<msopen>`, `<msclose>`
- 센서 측정: `<mstest>\r\n`
- 응답 파싱 포맷: `A=...,ACC=...,T=...,GA=...`

### 3.4 PASS 판정 구조
- 이동 PASS: `PML011` 목표 위치 문자열 포함 확인
  - `pml00517500`, `pml00516000`, `pml00514500`, 초기 `pml0051-500`
- 측정 PASS: `angle_measureEach(signX, signY, signZ)` 결과 bitmask == `deviceconnected_BG01`
- 반복 상수:
  - `REPEAT_MOVE_COUNT = 2`
  - `REPEAT_MEASURE_COUNT = 3`

## 6. 구현 전 고정해야 할 정책 (필수 의사결정)
1. 이동 오류 처리
- 권장: `pmd4011` 또는 `pmd5011` 수신 시 즉시 FAIL하지 않고, 재시도/대기 후 `pmd0011`로 최종 판정.

2. PMO 완료 처리
- 권장: `pmo0011`만 완료 기준으로 사용, `pmp0011`은 자동 알림으로 무시.

3. PMS 응답 처리
- 권장(실용 모드): `pms` 시작 + 정상 상태 바이트 포함 시 성공 처리.
- 보완: 실기기 첫 실행에서 raw 로그 저장 후 엄격모드 전환 여부 결정.

4. 동시성 모델
- 권장: EMIO 수신 대기와 UART 측정 폴링 분리(비동기/Task 분리).

## 7. 위험요소 및 대응
1. 응답 코드 불일치 리스크
- 현상: 코드 일부는 `pmd4011`, 실로그는 `pmd5011`.
- 대응: 양쪽 허용 + raw 로그 저장 + 최종 `pmd0011` 판정.

2. PMS 포맷 미확정 리스크
- 대응: 임시 성공 규칙(`pms` prefix) 적용, 실패 시 재송신 1회.

3. 임계값 이식 리스크
- 대응: `angle_measureEach()` 값을 테이블로 고정 후 그대로 반영.
- 비고: 비정상 수치 의심 항목(`-11500` 등)은 별도 검증 플래그.

4. 장비 상태 의존 리스크
- 대응: 시작 전 `PPP00`, 포트 연결상태, 초기 위치(`PML011`) 사전체크.

## 8. 테스트 케이스 (내일 최소 수행)
1. 단일축 케이스
- X only / Y only / Z only 각각 1회
- 기대: 단계 진행 + 해당 축만 PASS bit 설정

2. 3축 동시 케이스
- X+Y+Z 1회
- 기대: 각 측정 단계에서 bitmask `0x07` PASS

3. 이동 오류 내성 케이스
- 첫 이동에서 `pmd5011` 발생 시나리오
- 기대: 즉시 FAIL 없이 `pmd0011` 도달 후 계속 진행

4. Longrun 케이스
- 3 cycle
- 기대: 반복 카운트 정상, 마지막 `END` 처리
