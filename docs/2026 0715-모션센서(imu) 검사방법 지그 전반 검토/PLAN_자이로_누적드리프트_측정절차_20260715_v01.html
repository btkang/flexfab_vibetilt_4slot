1. 왜 재야 하나 (요약)

검사 항목 #3/#10(영점 초기화)이 매 사이클 자이로에 setzcur(현재 자세를 0으로 등록)를 보낸다. 이 명령은 비휘발이라 전원을 꺼도 유지된다(datasheet p.2, p.6).

  • 그래서 자이로의 "0도"는 최초 1회만 공장(중력) 기준이고, 이후로는 직전 사이클이 정한 자세다.
  • 제품 영점(<OFFSET,1>)은 그 자세를 그대로 물려받으므로, 자이로 0이 진짜 수평에서 D만큼 틀어져 있으면 전 제품이 D만큼 기울기 바이어스를 갖고 출하된다.
  • 기존 검사망은 D를 검출하지 못한다:
  • #6/#14 기울기 판정 = VL − 자이로 상대비교 → D가 양쪽에 똑같이 들어가 상쇄 → 전량 PASS
  • #4/#11의 verify_an = OFFSET 직후 VL 자기 출력을 보는 것 → 지그가 어디에 있든 항상 0.00x

즉 D가 얼마든 검사는 통과한다. D의 실제 크기는 측정 외에는 알 방법이 없다.

참고: setzcur는 지그제작요청서(2026-03-26)에 없는 명령이며, BG01 테스터 코드(BoardLevelMo_BG01.cpp) 1:1 이식(2026-02-24) 때 딸려온 것이다. 원출처는 2019년 pCOM 테스터. 상세는 배경 문서 참조.

2. 측정 원리

setzfac = "Cancels tare function and resets zero to factory setting" (datasheet p.6). setzcur로 누적된 tare를 취소하고 공장(중력) 기준으로 되돌린다.

setzfac 직후 같은 자세에서 get---x 로 읽은 값  =  그동안 누적된 D

지그를 평소 "0도"라고 여기던 자세에 둔 채로 실행하면, 그 자세가 진짜 수평에서 얼마나 벗어나 있었는지가 그대로 숫자로 나온다.

3. 준비

항목 값 비고
대상 자이로 SOLAR-360-420 232/485 공용 1대 (workspace 양쪽 다 동일 포트)
포트 COM16 개발 PC 기준. 양산 PC는 다를 수 있음 — 아래 확인 필수
통신 38400 / 8 / None / 1
개행 명령 끝에 LF(\n) 코드가 "setzcur\n" 형태로 송신
도구 시리얼 터미널 아무거나 TeraTerm, PuTTY, 하이퍼터미널 등

포트 확인 방법 (USB COM 드리프트 이슈 있음 — 반드시 실물 확인) - 검사 프로그램의 workspace JSON에서 uart_gyro → config.port 확인 - 파일: output\Release\net8.0-windows\MP_workspace_motion_232_VL10.json - 또는 검사 프로그램 포트 설정 화면에서 확인

주의: 검사 프로그램을 먼저 종료할 것. 포트를 잡고 있으면 터미널이 못 연다.

4. 절차

[1] 지그를 평소 0도 자세로 만든다
     - 검사 1사이클 돌려서 영점 초기화(#3 또는 #10)가 끝난 직후 정지
     - 이후 모터를 움직이지 말 것 (기울기/진동 항목으로 넘어가면 안 됨)

[2] 검사 프로그램 종료 → 터미널로 COM16 접속 (38400 8N1)

[3] setzfac  전송  →  응답 OK 확인          ← tare 취소, 공장 기준 복귀

[4] get---x  전송  →  ★ 값 기록             ← 이 값이 누적 드리프트 D
                     응답 형식: ±xxx.xxx  또는  OK±xxx.xxx

[5] 끝. 터미널 닫고 검사 프로그램 재시작

[4]를 여러 번(3~5회) 읽어 흔들림도 같이 기록하면 좋다. 노이즈와 실제 드리프트를 구분할 수 있다.

5. 결과 해석

D (get---x 값) 의미 조치
|D| ≤ 0.05 사실상 안 흘렀음. 제품 spec(±0.05) 이내 현행 생산 유지. 계획대로 setzcur 제거 진행
0.05 < |D| ≤ 0.2 흘렀음. 제품 영점이 spec을 벗어난 채 출하됐을 수 있음 출하 이력 검토 + 제거 우선순위 상향
|D| > 0.2 상당량 누적. #6/#14 spec(±0.2)에 근접 라인 판단 필요. 골든샘플로 기출하품 확인 검토

D의 부호도 기록할 것 — 어느 방향으로 틀어졌는지가 원인 추적(기구 마모 방향)에 쓰인다.

6. 안전성 — 왜 지금 해도 되나

  • setzfac는 tare만 취소한다. setdir(측정 방향)·필터·baudrate 등 다른 설정은 건드리지 않는다 (datasheet p.6).
  • 실행 후 다음 검사 사이클에서 자동 정상화된다: FineAdjust가 공장 기준으로 진짜 수평을 찾아가고 → 거기서 setzcur → 영점이 중력 기준으로 리셋된다. 즉 측정 자체가 현 상태보다 나은 상태로 만들어 놓는다.
  • 되돌릴 필요 없음. 별도 복구 작업 불필요.

단, [1]에서 모터를 움직이면 측정이 무의미해진다. 영점 직후 자세를 유지한 채로 [3]/[4]를 해야 한다.
