## 0. 세 줄 요약

1. **모터 1스텝(0.1125°)이 FineAdjust 허용밴드(±0.03 = 0.06° 폭)보다 넓다.** 지그는 ±0.03° 정밀도로
   설 수 있는 물건이 아니다.
2. 실측 로그상 **0도 잔차(0.005)가 기울기 잔차(0.022)보다 4.2배 정밀**하다. 같은 모터·같은 함수인데
   차이가 나는 이유는 **0도만 직전 사이클 setzcur가 그 자리를 0으로 정의해 뒀기 때문**이다.
   → `[FINE] 수렴 완료: 오차=0.002`는 **정밀 위치결정의 결과가 아니라, 목표를 모터가 선 자리로 옮긴 결과**다.
3. 출하 관점의 실질 차이는 하나다. **setzcur 없으면 출하품 0도 오차의 상한을 계산할 수 있고, 있으면 없다.**

> ⚠ **본 문서만으로 제거를 결정할 수 없다.** 제거 시 영향의 **크기**가 미측정값 D에 달려 있다 (§6).
> `setzfac` → `get---x` (5분, 터미널만 필요)가 **여전히 선행 필수**다.

## 3. setzcur가 실제로 하는 일 (재정의)

**수평을 만드는 게 아니다. 모터가 이미 서 있는 자리를 "0도"라고 개명하는 것이다.**

```
사이클 N-1 : FineAdjust → 모터가 어딘가 섬 → setzcur → "여기가 0"
사이클 N   : 홈복귀 → 1250스텝 → 거의 같은 자리
             → 자이로 판독 "0.002"  → 이미 밴드 안 → 0스텝 이동으로 수렴
             → setzcur → "여기가 0"   ...반복
```

### 수식

- `M_N` : N번째 사이클의 기구 자세 (홈 + 1250스텝), 중력 기준 절대각
- `Z_N` : N번째 사이클 종료 시 자이로의 0점, 중력 기준 절대각
- 자이로 판독(자세 P) = `P − Z`
- 도달 가능 자세는 격자뿐: `M_N + k × 0.1125`

```
FineAdjust 종료 자세  P_N = Z_(N-1) + ρ_N ,  |ρ_N| ≤ tol
setzcur              Z_N = P_N = Z_(N-1) + ρ_N     ← 자기참조 점화식
```

`u_N ≡ M_N − Z_N` 로 두면, 격자 성질에 의해 **u는 항상 0.1125의 정수배**이고 사이클 간 보존된다.
실측 0도 잔차(평균 0.005 ≪ 밴드 0.03)는 `k = 0`(무이동)에서만 나오는 값이고,
`k = 0`은 `|M_N − Z_(N-1)| ≤ 0.03`을 뜻한다. 즉 **u ≈ 0**, 따라서

> **`Z_N ≈ M_N`** — 자이로의 0이 기구 위치를 추종한다.
> 그리고 `ρ_N ≈ M_N − M_(N-1)` = **기구 반복도**. 실측 0.005는 이 지그의 홈센서+백래시 반복도다.

**결과:** 기준자가 자이로(중력)에서 **기구(홈센서 + 1250스텝)로 넘어간다.**
자이로는 기준자 지위를 잃고 **"기구 위치를 재현하는 도구"**가 된다.
중력은 **최초 1회 이후 이 루프에 참여하지 않는다.**

> ※ `u ≈ 0`(추론)은 실측 0.005를 설명하는 유일한 해로 보이나, **직접 측정된 값은 아니다.**
>   `M_N`·자이로 노이즈·백래시를 분리 측정하지 않았다. §7 한계 참조.

## 4. 출하 전체 영향

DUT는 `<OFFSET,1>`을 **FineAdjust 종료 자세 `P_N`에서** 실행한다. 즉 **출하품의 "0도" = `P_N`**이다.

| | **setzcur 있음 (현행)** | **setzcur 없음** |
|---|---|---|
| 자이로 0 | `Z_N ≈ M_N` (기구 추종) | `Z_0` = 공장(중력) 기준, **고정** |
| 출하품이 0도를 배우는 자세 | `P_N ≈ M_N` — **기구 위치** | `P_N = Z_0 + ρ_N` — **중력 수평** |
| 실질 기준자 | **기구** (자이로는 도구) | **중력** (자이로가 기준자) |
| 출하품 0도 오차 (진짜 수평 대비) | **`D` ± 기구반복도(0.005)** | **`ε` ± `ρ_N`** |
| 그 오차의 정체 | `D = M̄ − 진짜수평` — **미지** | `ε` = 자이로 공장오차 (**datasheet 스펙**) |
| **오차 상한 계산** | **불가** — D를 모른다 | **가능** — ε는 스펙, ρ는 밴드로 상한 |
| 제품 간 편차 | ±0.017 (실측) — 매우 균일 | ρ의 변동 (§6에 따라 다름) |
| 시간에 따른 이동 | **가능** — 홈센서 마모·지그 재조립·자이로 재장착 시 D 이동. **로트마다 달라져도 모름** | 없음 — 중력은 안 움직인다 |

### 핵심

지금 제품들은 **아주 균일하게(±0.017) 모여 있다.** 문제는 **어디에** 모여 있는지 아무도 모른다는 것이다.

- `D = 0.01`이면 운이 좋았던 것이고,
- `D = 0.5`면 **양산 전량이 0.5도 기울어져 출하됐는데 검사는 전량 PASS**다.

setzcur를 빼면 **모이는 자리가 중력이 되고, 오차 상한을 숫자로 보증할 수 있게 된다.**
양산 품질보증에 필요한 것은 균일함이 아니라 **보증 가능한 상한**이다.

### 왜 기존 검사망이 D를 못 잡나 (재확인)

| 검사 | 이유 |
|---|---|
| `#6`/`#14` 기울기 | 판정이 `VL − 자이로` **상대비교** → D가 양쪽에 동일하게 들어가 **상쇄** → 전량 PASS |
| `#4`/`#11` `verify_an` | `<OFFSET,1>` **직후 VL 자기 출력** → 지그가 어디 있든 **항상 0.00x** (`VibeTilt.cs:1268~1357`) |

→ **D를 볼 수 있는 눈이 검사망 어디에도 없다.**

## 5. `PLAN_setzcur제거` 4.1절 — 근거 보강 (수치 정정 아님)

PLAN 4.1은 제거 시 영향을 **`δ ≤ 0.03`, spec ±0.2 대비 15%**로 잡았다. **이 수치는 유효하다.**
`FineAdjust`는 `|판독| ≤ tol`일 때만 `true`를 반환하므로, **수렴에 성공하는 한 δ ≤ 0.03(10초 내) / ≤0.05는 보장**된다.

> ⚠ **정정:** 2026-07-16 대화 중 "δ가 0.022~0.05로 4배 악화된다"고 말한 바 있으나 **이는 과장이었다.**
> 0.022는 *기울기*의 격자 잔차이고, 0도의 δ는 여전히 밴드가 상한이다.
> **PLAN 4.1의 δ ≤ 0.03은 고칠 필요 없다.**

**보강할 것은 수치가 아니라 근거다.** PLAN 2.5절(지금 구조의 문제)에 아래를 추가 권장:

> **setzcur의 실제 기능은 "목표를 모터가 선 자리로 옮기는 것"이다.**
> 모터 1스텝(0.1125°)이 0도 밴드(0.06°)보다 넓어, 지그는 위치결정만으로 ±0.03에 설 수 없다.
> 실측상 0도 잔차(0.005)가 기울기 잔차(0.022)보다 4.2배 정밀한 것이 그 증거다 —
> 0도만 목표가 격자 위에 있기 때문. 그 결과 **자이로의 0이 기구 위치(홈+1250스텝)를 추종**하고,
> 자이로는 기준자 지위를 잃는다.

## 6. 새 리스크 — 제거 시 0도 수렴 (D에 종속, **미확정**)

setzcur를 빼면 0도 목표가 `Z_0`(공장 기준)로 고정된다. 도달 가능 자세는 격자뿐이므로,
`|centered_mod(M − Z_0, 0.1125)| ≤ 밴드` 여야 수렴한다. 그리고 **`M − Z_0`가 곧 `D`다.**

| D (mod 0.1125) | 결과 |
|---|---|
| ≤ 0.03 | **무영향** — 지금처럼 0스텝 수렴 |
| 0.03 ~ 0.05 | 10초 대기 후 relaxed(0.05)로 수렴 — **영점에 ~10초 추가** |
| > 0.05 | 격자점이 밴드에 없음 → **수렴 실패 위험** (`[ZERO] FAIL: 0도 미세조정 실패`) |

**즉 제거 영향의 크기가 D에 직접 종속된다. D를 모르면 예측이 불가능하다.**
→ **`PLAN_자이로_누적드리프트_측정절차`(setzfac + get---x, 5분)가 선행 필수**임이 다시 확인된다.
→ PLAN 5절 작업순서 "1과 3은 순서 무관"은 **재검토 필요**. 3(±20/±45 실측)은 유효하지만,
   **0도 수렴 자체가 D에 걸려 있으므로 1을 먼저 하는 편이 안전하다.**

### 다만 실패 위험은 낮아 보인다

이론상 `밴드 0.10 ÷ 격자 0.1125` → **11%는 수렴 불가**여야 한다.
그런데 **기울기는 이미 그 조건에서 30/30 전부 수렴**했다 (§2, 목표가 격자와 무관한데도).
자이로 노이즈(σ ≈ 0.005~0.01 추정)와 수렴확인 2회 판정이 흡수하는 것으로 보인다.
→ **0도에서도 같은 메커니즘이 작동할 개연성이 높다.** 단 **보장은 아니다.**
