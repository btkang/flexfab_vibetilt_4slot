## 1. VibeTilt 특징 — 레퍼런스(지그 자이로)가 3번 개입

VL은 **"수평 잡고 → 기울기 측정"** 두 단계인데, 두 단계 모두 판정 기준선을
**그때그때 레퍼런스(지그 자이로)가 정한 각도**로 삼는다.

| # | 단계 | 레퍼런스(지그 자이로)가 하는 일 |
|---|---|---|
| 1 | **영점(수평 잡기)** | `FineAdjust`로 \|자이로\|≤0.03° 폐루프 정렬 → **`setzcur`로 자이로 자체를 tare** (레퍼런스도 영점을 잡음) |
| 2 | **측정각 세팅** | 각 목표각(±20/±45)에서 **`FineAdjust`로 자이로가 target±0.05° 될 때까지 미세조정** |
| 3 | **판정** | 그 각도의 자이로 실제각 `gyroAngle` 확정 → **`\|VL − gyroAngle\| ≤ spec`** 비교 |

### 1-1. 두 단계 상세

**① 수평 잡기 (영점 · MOTION_ZERO)**
1. `setdir6/5` — 자이로 방향 지정
2. 홈센서(IN1/IN2) coarse — 대충 0도 근처로
3. **`FineAdjust`** — 자이로 읽어 \|자이로\|≤0.03°까지 모터 폐루프 서보 (10s 후 0.05° 완화) → **실제 0도 확정**
4. **`setzcur`** — 현 자세를 지그 0점으로 tare
5. **DUT 영점** — `<OFFSET,1>` → `AN` 0도 ±0.05 검증(verify_an) → `SAVE` → `APPCFG`

**② 기울기 측정**
1. 각도 이동 — `AngleToSteps` coarse → `FineAdjust`로 자이로 target±0.05°
2. **레퍼런스 확정** — `get`으로 `gyroAngle` 읽음
3. DUT 측정 — `<MODE06><START>`→`AN` 스트리밍→`<STOP>`, 마지막 N샘플
4. **판정** — `error = VL − gyroAngle`(부호 무관, 크기 비교), **±0.2°(20°) / ±0.5°(45°)**, 마지막 N개 전부(all_in_spec), retry 3
5. 안전체크 — `\|gyroAngle − VL\| ≥ sensor_diff_error` 면 즉시 중단(하드웨어 이상)

### 1-2. 한 문장 정의

> **VL = 레퍼런스도 영점(setzcur)하고, 측정각에서도 레퍼런스를 미세조정(FineAdjust)한 뒤,
> `레퍼런스각도 − DUT각도`를 spec과 비교하는 상대측정 구조.**
> 판정 기준선이 「고정 절대값」이 아니라 「그때그때 레퍼런스가 정한 각도」다.

## 2. 레퍼런스 영점 「잡음 vs 안 잡음」

### 2-1. 모델별 실태

| 모델 | 레퍼런스 영점(setzcur/tare) | 게이트 | 결과 |
|---|---|---|---|
| **VibeTilt (VL)** | **매 사이클** (FineAdjust 뒤) | 없음 | 잡음 |
| **BG01 MOS** | **매 정렬 무조건** (`angle_0_init_Revision`, `// Temporarily`) | 없음(우회) | 잡음 |
| **pCOM/pSMC 원본** | **체크박스 ON일 때만** ("Ref. Gyro Sensor Init") — 기본 OFF → 공장영점(`setzfac`) 유지 | 체크박스 | **기본은 안 잡음** |

→ 즉 **"레퍼런스 영점 안 잡는"** 대표는 **pCOM/pSMC 원본의 기본 모드**(공장영점 절대기준 유지).

### 2-2. 잡으면 vs 안 잡으면 — 무엇이 달라지나

| 항목 | **레퍼런스 영점 잡음** (tare/setzcur) | **레퍼런스 영점 안 잡음** (공장영점 유지) |
|---|---|---|
| **수평 기준** | 현재 지그 자세 = 0 으로 **재정의**(상대) | 공장 절대 수평을 **유지**(절대) |
| **지그 드리프트/기구 마모** | 영점에 **흡수** → 안 보임 | 레퍼런스가 절대기준이라 **편차로 드러남**(감지 가능) |
| **온도 영점 이동** | tare 시점 자세로 **각인 누적** | 영점 불변 → 편차로 노출 |
| **DUT 판정 성격** | **상대오차**(레퍼런스가 곧 참값) | **절대 window** 가능(레퍼런스·DUT 독립) |
| **common-mode 상쇄** | 위험 있음 (레퍼런스 틀어지면 DUT도 같이 통과) | 없음 |
| **셋업 편의** | 매번 자동 0 (교정 불필요) | 초기 **공장영점 교정** 필요 |
| **각도 유연성** | 임의 각도 세팅 쉬움 | 기계 리밋 등 절대 기준 필요 |

### 2-3. 핵심 시사점

- **잡는 쪽(VL)**: 편의·유연성을 얻지만 **레퍼런스 신뢰성에 판정 전체가 의존**.
  특히 VL은 `FineAdjust`가 이미 0도로 맞춘 **뒤에** `setzcur`를 쳐서 — 정렬 기능은 잉여이고
  **수렴 잔차(≤0.03°)만 비휘발 영점에 누적**된다. 모든 판정이 `DUT − 레퍼런스` 상대비교라,
  레퍼런스 영점이 틀어지면 DUT cal도 같은 기준을 물려받아 **common-mode 상쇄 → 전량 PASS 위험**.
- **안 잡는 쪽(pCOM 원본)**: 레퍼런스가 **독립 절대 수평 기준**으로 남아 지그 드리프트/기구 마모를
  DUT와 무관하게 잡아낼 수 있다. 대신 초기 공장영점 교정과, 각도를 정하는 별도 기준(기계 리밋)이 필요.
- **방향**: VL의 `setzcur`를 **제거하거나 원본처럼 옵션화**(JSON 플래그 `ref_gyro_sensor_init` 기본 false)하면
  원본 설계·지그 요청서와 일치하고, 레퍼런스가 절대기준을 유지해 common-mode 리스크가 사라진다.
  단 실기 회귀 검증 필수, 온도 오차는 별건으로 분리 처리. (상세 → `REF_영점기울기_3모델비교…_v01.md` 5장)
