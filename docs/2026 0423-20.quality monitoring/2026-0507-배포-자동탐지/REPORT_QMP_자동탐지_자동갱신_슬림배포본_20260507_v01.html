QMP 자동 탐지 + 자동 갱신 + 슬림 배포본

2026-05-07 QMP v0.1.0.60506 step8-485-stop-fix

요약: QMP를 검사 프로그램 배포 폴더 옆에 두고 더블클릭만으로 양산 운영 가능하도록 4가지 핵심 개선:
  1. ResultDir 자동 탐지 (어디 두든 4가지 후보 패턴으로 자동 매치)
  2. 화면 자동 갱신 신뢰성 확보 (mtime 기반 cache key로 새 검사 즉시 반영)
  3. 워크스페이스별 scope 자동 설정 (board/motion 폴더명 감지)
  4. 5MB 슬림 배포본 신설 (tools/prod_release/qmp_v0.1.0.60506)

1. 변경 전 / 후 운영 흐름

변경 전

  • QMP의 ResultDir이 상대경로 하드코딩 — 위치 옮기면 깨짐
  • 매 배포본마다 ResultDir 수동 수정 필요
  • 화면 자동 새로고침 없거나 cache 때문에 데이터 안 갱신
  • 사이드바 범위 매번 수동 선택
  • QMP 폴더 1042MB (seminar/ 시연 자료 포함)

변경 후

  • QMP 폴더만 배포 폴더 옆에 두면 자동 매치
  • 화면 60초 자동 갱신 + F5 즉시 갱신 둘 다 동작
  • start_board485 → 사이드바 자동 board, start_motion485 → 자동 motion
  • cmd 더블클릭 → 8초 후 브라우저 자동 오픈
  • 슬림 배포본 5MB로 다른 PC 이관 부담 제거

2. 자동 탐지 (ResultDir)

2.1 동작 방식

prod\start_*.ps1이 4가지 후보 경로를 순서대로 시도하여 처음 발견되는 곳을 ResultDir로 사용:

$workspace = 'VL20보드검사(RS-485)_MP'
$candidates = @(
    Join-Path $qmp "..\net8.0-windows\Result\$workspace"             # 1. 배포본 (qmp 옆 net8.0-windows)
    Join-Path $qmp "..\..\output\Release\net8.0-windows\Result\..."  # 2. 원본 + Release 빌드
    Join-Path $qmp "..\..\output\Debug\net8.0-windows\Result\..."    # 3. 원본 + Debug 빌드
    Join-Path $qmp "..\..\net8.0-windows\Result\$workspace"          # 4. 변형 패턴
)
$found = $candidates | Where-Object { Test-Path $_ } | Select-Object -First 1

3. 자동 갱신 신뢰성

3.1 진단된 원인

Streamlit @st.cache_data의 hash 처리 특성 — _ prefix 인자는 hash에서 제외되어 cache key가 절대 변하지 않았음.

증상원인
F5 눌러도 데이터 안 변함_token underscore로 cache key에서 제외
"캐시 새로고침" 버튼만 동작이건 강제 cache.clear() 호출
자동 새로고침 60초 후에도 동일autorefresh가 페이지 재실행해도 cache hit

3.2 fix 코드

def _result_token(path_str: str) -> str:
    """폴더 변경 감지용 토큰 (mtime + 파일 수)."""
    p = Path(path_str)
    if not p.exists(): return "missing"
    files = list(p.rglob("*.json"))
    if not files: return "empty"
    latest = max(f.stat().st_mtime for f in files)
    return f"{latest:.0f}|{len(files)}"


@st.cache_data(show_spinner=False, ttl=60)
def _load_json(path_str: str, token: str = "") -> pd.DataFrame:
    # ↑ underscore 제거 — 이게 핵심
    return load_results(Path(path_str))


# 호출처:
df_all = _load_json(result_dir, _result_token(result_dir))

3.3 갱신 트리거 (모두 동작 검증)

방법동작상태
F5 (브라우저 새로고침)페이지 재실행 + 새 token으로 호출 → cache miss즉시
자동 새로고침 (60초)autorefresh 페이지 재실행 → token 변경 시 cache miss60초 주기
"캐시 새로고침" 버튼강제 cache clear즉시

3.4 자동 새로고침 default ON

사이드바 체크박스 default를 True로 설정 — 사용자가 켜는 절차 없이 양산 시작 즉시 자동 갱신.

4. 워크스페이스별 자동 scope

4.1 동작

ResultDir 폴더명에서 "보드"/"board" 또는 "모션"/"motion"을 감지하여 사이드바 "범위" 기본값 자동 설정.

def _scope_from_path(result_dir: str) -> str:
    rd = result_dir or ""
    if "보드" in rd or "board" in rd.lower():
        return "board"
    if "모션" in rd or "motion" in rd.lower():
        return "motion"
    return "전체"

8.2 데이터 형식 — Long format

QMP 이벤트별 CSV는 업계 표준 Long format (Tidy data):

  • 1행 = 1 측정 항목 (1 SN당 7행 = 7개 검사 항목)
  • 스키마 안정 — 검사 항목 추가/제거 시 컬럼 변경 없음
  • R/Python/PowerBI/Tableau 분석 도구 호환
  • Wide format 필요 시 Excel 피벗테이블로 변환 가능
