## 0. Context (왜 만드나)

- 회사 ERP는 박사님이 만들어 운영 중. **품질 메뉴는 비어있고 사용자가 채울 영역**.
- 사용자는 검사 프로그램(C# WinForms)과 품질 모니터링(Python Streamlit)을 만들어 양산 가동 중.
- 모니터링에 모니터링/조회/데이터/SPC 메뉴 완료. 다음 단계로 **검사 성적서 발행** 추가.
- 양산 규모: 일<100대, 다품종 소량. ERP 풀패키지(승인 워크플로 등) 오버스펙.
- 추후 ERP 품질메뉴로 통합 가능성 있음 (스택/시점은 합류 시 결정).

## 1. ERP QC 항목 vs 우리 결정

박사님 ERP 게시판 QC-08~12 (성적서) 항목별 적용 결정.

| 항목 | 내용 | MVP | 사유 |
|---|---|---|---|
| **QC-08 발행** | 검사 결과 기반 자동 생성 | ⭐ 포함 | 핵심, 양산 30대 단위 |
| QC-09 승인 | 작성→검토→승인 워크플로 | ❌ 제외 | 작은 조직, 부담만 됨 |
| QC-10 품목별 양식 | 품목 커스터마이즈 | △ 부분 | 양식 2종(VL10/VL20)으로 시작 |
| **QC-11 고객별 양식** | 고객사 매핑 (CIS 등) | ⭐ 포함 | CIS 양식 이미 받음 |
| **QC-12 이력** | 과거 조회/비교 | ⭐ 기본 | 추적성 필수 (비교는 추후) |

**참고**: ERP 게시판은 ERP 제작자가 업체에 제시하는 풀 메뉴 카탈로그. 작은 조직엔 다 안 씀. 우리 양산 규모(일<100대, 다품종)에 맞게 **MVP만** 채택.

## 2. 범위 (MVP)

### 포함
- 시리얼 다중 선택 (조회 탭 흐름과 일관)
- 메타 입력: LOT 번호, 거래처, 발행자, 비고, 발행일
- 양식 선택: 표준 / CIS AX / (추후 추가)
- 미리보기 (셀 매핑 결과)
- 발행 → xlsx 다운로드 + 이력 자동 기록
- 발행 이력 표 (cert_no/Rev./시간/거래처/시리얼/상태)
- 재발행 시 Rev. 자동 증가 (이전은 폐기 표시)

### 제외 (ERP 영역 또는 추후)
- 승인 워크플로 (QC-09)
- 품목별 자동 양식 선택 (현재는 사용자가 드롭다운 선택)
- 거래처 마스터 (ERP)
- 출하 워크플로 (ERP)
- 자동 결재/메일 발송

## 3. 데이터 모델

### `certificates` 테이블 (SQLite, schema v3)

| 컬럼 | 타입 | 의미 |
|---|---|---|
| id | INTEGER PK AUTOINCREMENT | 내부 PK |
| cert_no | TEXT NOT NULL | 성적서 번호 (예: `COA-20260428-001`) |
| revision | INTEGER NOT NULL DEFAULT 0 | Rev. 0/1/2 |
| template | TEXT | 사용 양식 (`standard`/`cis`) |
| project | TEXT | 프로젝트 |
| lot_no | TEXT | LOT 번호 (사용자 입력) |
| customer | TEXT | 거래처 |
| issuer | TEXT | 발행자 |
| issued_at | TEXT (ISO8601) | 발행일시 |
| serial_count | INTEGER | 시리얼 수 |
| serials | TEXT | 시리얼 목록 (CSV) |
| status | TEXT DEFAULT '유효' | 유효 / 폐기 / 재발행 |
| remark | TEXT | 비고 |

**인덱스**: `idx_cert_no(cert_no)`, `idx_cert_issued(issued_at)`

**ERP 이관 대비**: 컬럼명 영문 (`cert_no`, `lot_no` 등). PostgreSQL/MySQL/SQL Server 어떤 DB든 그대로 옮김.

### 성적서 번호 채번
- 패턴: `COA-{YYYYMMDD}-{NNN}` (예: COA-20260428-001)
- 같은 날짜 발행 카운트 + 1 (DB COUNT)
- 재발행 시 같은 cert_no, revision +1

## 4. 양식 매핑

### 4-1. 표준 양식 (코드 자동 생성)
- openpyxl로 코드에서 xlsx 워크북 생성 (별도 .xlsx 파일 X)
- 우리 검사 항목 100% 매칭 (DPM/TILT/VIBE/COMM 모두)
- 구조: 헤더(메타) → 시리얼 컬럼 헤더 → 검사 항목 행(N개) → 종합 판정 → 서명란
- PASS는 녹색 배경, FAIL은 빨강 배경

### 4-2. CIS AX 양식 (`templates/CIS AX 검사성적서 양식_최종.xlsx`)

**고정 구조** (양식 분석 기반):
- 시리얼 컬럼: **F · H · J · L · N · P · R · T · V · X** (10 슬롯)
- 시리얼 헤더 행: **17**
- 메타 행 15-16 (제조일/모델명/SN/Mac/FIRMWARE 등 — 양식 텍스트 그대로, 미사용)

**데이터 행 매핑** (MVP):
| 양식 행 | 양식 항목 (1.x) | 우리 데이터 매칭 |
|---|---|---|
| 18 | 1.1 MAIN 24V (22.8~25.2V) | DPM 24V |
| 20 | 1.3 MAIN 3.3V (3.13~3.47V) | DPM 3.3V |
| 30 | 1.13 24V 소비전류 (150~250mA) | DPM 전류 |
| 32 | 1.15 유/무선 통신 Test | COMM 합/불 |
| 37 | 1.20 Motion / Temp Sensor Test | MOTION (TILT/VIBE/SENTEMP) 합/불 |

**빈 항목** (5V, 12V, ISO, RTC, ADC, Aging 등): **빈칸**. 운영자가 양식 안에서 수동 채움 가능.

### 4-3. 양식 추가 방법 (운영 중)
- `templates/*.xlsx` 폴더에 양식 두기
- 매핑 정의는 코드 안 dict (MVP). 추후 yaml 분리 (양식 3+ 시점)
- 양식 추가 시: dict 한 항목 추가 → 즉시 사용 가능

### 4-4. 합/불 표기 규칙
- 우리 데이터 result `OK` → 양식에 `합`
- 우리 데이터 result `FAIL` → 양식에 `불`
- 측정값 항목은 숫자 그대로 (단위 별도 표기 없음, 양식이 단위 정의)

### 행동 흐름
1. 시리얼 선택 → 메타 입력 → 양식 선택 → 미리보기 자동 갱신
2. **발행** 클릭:
   - cert_no 채번 (DB COUNT 기반)
   - xlsx 생성 (양식 채움)
   - DB INSERT (이력)
   - 브라우저 다운로드
3. 같은 LOT 재발행 시:
   - 이전 cert_no status='폐기'
   - 새 row revision +1, status='유효'

## 8. 검증 시나리오

1. **CIS 양식 발행**
   - 백업 데이터에서 보드 검사 시리얼 10개(VL20보드검사_MP) 선택
   - 메타: LOT=L-CIS-2026042801, 거래처=ABC, 발행자=홍길동
   - 양식: CIS AX 선택
   - 미리보기에서 24V/3.3V/전류/COMM 매핑 확인
   - 발행 → xlsx 다운로드
   - xlsx 열어서:
     - F17~X17 시리얼 채워짐
     - F18~X18 = 24V 측정값 (3자리)
     - F20~X20 = 3.3V
     - F30~X30 = 전류
     - F32~X32 = "합"/"불"
     - F37~X37 = "합"/"불"
   - 빠진 항목(F19=5V 등)은 양식 그대로 빈칸

2. **표준 양식 발행**
   - 모션 검사 시리얼 5개(VL2-...) 선택
   - 양식: 표준
   - 발행 → xlsx 다운로드
   - 우리 검사 항목 모두 채워짐 (DPM/TILT 8각도/VIBE/COMM)
   - 종합 판정 PASS 표시

3. **DB 이력**
   - 발행 후 `certificates` 테이블 1행
   - cert_no, revision=0, template, lot_no, customer, issuer, issued_at, status='유효'
   - 시리얼 CSV 정상

4. **재발행 (Rev.)**
   - 같은 LOT으로 재발행
   - 이전 row status='폐기'로 변경
   - 새 row revision=1, status='유효', cert_no는 같음

5. **CSV 내보내기**
   - 발행 이력 → CSV 다운로드
   - UTF-8 BOM 포함, 엑셀에서 한글 정상
