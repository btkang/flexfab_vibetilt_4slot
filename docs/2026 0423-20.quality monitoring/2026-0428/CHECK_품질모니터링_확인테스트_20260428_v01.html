streamlit run app.py -- --result-dir "..\..\docs\2026 0423-20.quality monitoring\output_backup"

2-1. 사이드바

  • "Result 경로" 입력란에 경로 표시
  • "기간 (최근)" 드롭다운: 전체 / 1 / 7 / 30 / 90일
  • "범위" 드롭다운: 전체 / motion / board
  • "자동 새로고침 (60초)" 체크박스 (streamlit-autorefresh 설치 시)

  • "데이터 소스: JSON" 표시 (DB 파일 없을 때)
  • "DB 캐시 만들기" 버튼 보임

2-2. 메인 탭

  • 상단 KPI 5개: 총 시리얼 / 오늘 시리얼 / 오늘 FAIL / 측정 이벤트 / 마지막 검사
  • 알람 영역 (연속 FAIL / Cpk<1.33 그룹 카운트) — 데이터에 따라 표시
  • 최근 7일 막대그래프 — PASS(녹) / FAIL(적) 분리 (백업 데이터는 옛날이라 비어있을 수 있음)
  • 프로젝트별 시리얼 수 표 (모션 232/485, 보드 232/485 등)
  • 측정값 변동 요약 표 — 모션 TILT 8그룹 + 모션 VIBE 3축 + 보드 TILT 2축 + 보드 VIBE 4축 + DPM 3항목
  • 시리얼 검색 — "VL2" 입력 시 해당 시리얼들 표시

2-3. TILT 추이 / 분포

  • "범위" 라디오: motion / board 전환됨
  • motion 선택 시: 축(X/Y) + 각도(±20/±45) 멀티셀렉트, ±0.2°/±0.5° 점선 표시
  • board 선택 시: 축(X/Y), 각도 필터 없음, 절대값 데이터 표시
  • TILT 분포 탭: 히스토그램 + 박스플롯 + 통계 표

2-4. VIBE 탭

  • "범위" 라디오: motion / board
  • motion: 축간 norm 표 (X²+Y²+Z² 제곱근 ≈ 1.0)
  • board: 축별(X/Y/Z/RMS) 통계 표

2-5. DPM 탭 (신규)

  • "항목" 멀티셀렉트: 24V / 3.3V / 전류
  • 시계열 그래프 (3 항목 색상 다름)
  • 분포 히스토그램
  • 통계 표 (단위 V/mA, spec_min/spec_max 컬럼 포함)

2-6. 관리도(SPC) 탭

  • "그룹 선택" 드롭다운에 다음 모두 보임:
    • TILT MOTION X/Y × ±20/±45° (8개)
    • TILT BOARD X/Y (2개)
    • VIBE MOTION X/Y/Z (3개)
    • VIBE BOARD X/Y/Z/RMS (4개)
    • DPM 24V/3.3V/전류 (3개)
  • 샘플 20개 이상 그룹 선택 시 μ/σ/UCL/LCL/Cpk 출력
  • 관리도(이동평균 + UCL/LCL/μ 라인) 표시
  • Western Electric Rules 알람 영역

2-7. FAIL 탭 (강화)

  • "FAIL 원인별 카운트" 가로 막대그래프 (kind/scope/axis/item 조합)
  • DPM 24V / 3.3V / 전류 각 6건 막대 — 가장 높음
  • FAIL 상세 표 (sn / time / project / kind / value / spec)

2-8. 리포트 탭 (신규)

  • "오늘 이벤트 CSV" 다운로드 버튼 (오늘 데이터 없으면 안내)
  • "전체 이벤트 CSV" 다운로드 (706행)
  • "오늘 요약 HTML" 다운로드 (열어보면 측정값 변동 + FAIL 표)

2-9. 사이드바 동작 검증

  • "범위" → board 선택 → 모션 데이터 사라지고 보드만 보임 (이벤트 ≈ 327)
