# Workspace 템플릿 자동 생성 PLAN

**작업일:** 2026-02-23

---

## 진행 단계

| 단계 | 내용 | 상태 |
|------|------|------|
| 1단계 | DPM 공용 분리 + 스크립트 합성 | **현재 작업** |
| 2단계 | 검사 파라미터 공용 분리 (vibetilt_common.json) | 다음 작업 |

---

## 배경

- 232와 485는 검사항목이 같지만 송수신 명령이 다름
- DPM(24V, 3.3V, 전류)은 232/485 공용
- 현재 json을 2개 각각 만들고 있어서 DPM 수정 시 2곳 수정 필요
- DPM을 1곳에서 관리하고 자동으로 합성하는 방식으로 개선

---

## 수정 범위

### 메인 프로그램
- **수정 없음**

### JSON 파일

**새로 만들 파일 (3개):**

| 파일 | 내용 | 위치 |
|------|------|------|
| `dpm_common.json` | DPM libraries + procs (공용) | workspace_parts/ |
| `vibetilt_232.json` | 232 libraries + procs (232 전용) | workspace_parts/ |
| `vibetilt_485.json` | 485 libraries + procs (485 전용) | workspace_parts/ |

**자동 생성되는 파일 (2개):**

| 파일 | 합성 내용 | 용도 |
|------|----------|------|
| `workspace.json` | vibetilt_485 + dpm_common | 기본 로딩 |
| `workspace_232.json` | vibetilt_232 + dpm_common | 다이얼로그에서 선택 |

### 스크립트 (1개 - 새로 만듦)

| 파일 | 역할 |
|------|------|
| `build_workspace.ps1` | parts 폴더의 json을 합성하여 workspace 생성 |

## 작업 순서

### STEP 1. workspace_parts 폴더 생성

```
output/Debug/net8.0-windows/workspace_parts/
  ├── dpm_common.json
  ├── vibetilt_232.json
  └── vibetilt_485.json
```

### STEP 2. dpm_common.json 작성 (공용)

현재 485 workspace.json에서 DPM 관련 부분 추출:

```json
{
  "libraries": [
    { "id": "uart_dpm", "port": "COM12", "baudrate": 57600 },
    { "id": "dpm", "config": { "uart": "uart_dpm" } }
  ],
  "library_depencency": ["uart_dpm", "dpm"],
  "procs": [
    { "name": "24V 검사",  "id06", "error_rate": "3%", "min": "23.28",  "max": "24.72" },
    { "name": "3.3V 검사", "id09", "error_rate": "3%", "min": "0.003",  "max": "3.5"   },
    { "name": "전류 검사",  "id09",                     "min": "-0.001", "max": "0.5"   }
  ]
}
```

### STEP 3. vibetilt_485.json 작성

현재 485 workspace.json에서 VibeTilt 관련 부분 추출:

```json
{
  "libraries": [
    { "id": "uart_485", "port": "COM11", "baudrate": 115200 },
    { "id": "ctsp" },
    { "id": "vibetilt", "config": { "uart_485": "uart_485", "dpm": "dpm" } }
  ],
  "project": {
    "id": "prj-vl20-rs485",
    "name": "VL20 검사 (RS-485)",
    "library_depencency": ["uart_485", "vibetilt", "ctsp"]
  },
  "procs": [ VER_485, SENTEMP_485, APPCFG_485, VIBE_485, TILT_485 ]
}
```

### STEP 4. vibetilt_232.json 작성

기존 232 workspace에서 VibeTilt 관련 부분 추출:

```json
{
  "libraries": [
    { "id": "uart_232", "port": "COM3", "baudrate": 115200 },
    { "id": "ctsp" },
    { "id": "vibetilt", "config": { "uart_232": "uart_232", "dpm": "dpm" } }
  ],
  "project": {
    "id": "prj-vibetilt-232",
    "name": "VibeTilt 검사 (RS-232)",
    "library_depencency": ["uart_232", "vibetilt", "ctsp"]
  },
  "procs": [ VER_232, SENTEMP_232, APPCFG_232, VIBE_232, TILT_232 ]
}
```

### STEP 5. build_workspace.ps1 스크립트 작성

```
스크립트 동작:
  1. workspace_parts/ 폴더에서 파일 읽기
  2. libraries 합성 (vibetilt + dpm_common)
  3. library_depencency 합성
  4. procs 합성 (DPM을 앞에 배치)
  5. workspace.json / workspace_232.json 생성
```

### STEP 6. 검증

```
- [ ] build_workspace.ps1 실행
- [ ] workspace.json (485+DPM) 프로그램 로딩 확인
- [ ] workspace_232.json (232+DPM) 다이얼로그 선택 후 로딩 확인
- [ ] DPM 검사 3개 PASS 확인
- [ ] VibeTilt 검사 PASS 확인
```

## 2단계 PLAN (다음 작업): 검사 파라미터 공용 분리

### 배경

- 232/485의 검사내용(TIMEOUT, min/max, pass 조건 등)은 동일
- 현재 vibetilt_232.json과 vibetilt_485.json에 각각 중복 기재
- 검사 조건 변경 시 2곳 수정 필요

### 목표

검사 파라미터를 공용으로 분리하여 1곳만 수정

### 분리 기준

```
공통 (vibetilt_common.json):
  - TIMEOUT, DURATION
  - min/max, rms_min/max, one_min/max, zero_min/max
  - pass_consecutive_count
  - sampling_ms
  - alive_check, alive_min_delta_x/y
  - x_min/max, y_min/max
  - operator_prompt

차이 (vibetilt_232_diff.json / vibetilt_485_diff.json):
  - 포트: COM3 vs COM11
  - 명령: <VER> vs <VER,1>, <MODE,2> vs <MODE,1,2>
  - baudrate 설정
  - 프로젝트 id/name
```

### 파일 구조 (2단계 완성 후)

```
workspace_parts/
  dpm_common.json          ← DPM 공용 (1단계)
  vibetilt_common.json     ← 검사 파라미터 공용 (2단계)
  vibetilt_232_diff.json   ← 232 차이점만 (포트, 명령어)
  vibetilt_485_diff.json   ← 485 차이점만 (포트, 명령어)
```

### 수정 시뮬레이션 (2단계 완성 후)

```
DPM 범위 변경 시:
  dpm_common.json 1곳 수정 → 스크립트 실행 → ✅

진동검사 PASS 조건 변경 시:
  vibetilt_common.json 1곳 수정 → 스크립트 실행 → ✅

485 포트 변경 시:
  vibetilt_485_diff.json 1곳 수정 → 스크립트 실행 → ✅
```
