## 작업 순서

### STEP 1. vibetilt_common.json 생성

검사별 공통 파라미터를 proc ID 기준으로 정리:

```json
{
  "common_params": {
    "VER": {
      "TIMEOUT": 5000,
      "expected_response": "VER"
    },
    "SENTEMP": {
      "TIMEOUT": 5000,
      "min": 20,
      "max": 40
    },
    "APPCFG": {
      "TIMEOUT": 5000
    },
    "VIBE": {
      "line_ending": "lf",
      "one_min": 0.9, "one_max": 1.1,
      "zero_min": -0.1, "zero_max": 0.1,
      "rms_min": 0.5, "rms_max": 0.65,
      "sampling_ms": 10
    },
    "TILT": {
      "DURATION": 3000,
      "line_ending": "lf",
      "alive_check": true,
      "x_min": -60.0, "x_max": 60.0,
      "y_min": -60.0, "y_max": 60.0,
      "sampling_ms": 10,
      "tilt_baud": 115200,
      "normal_baud": 115200
    }
  }
}
```

### STEP 2. vibetilt_485.json 수정

procs에서 공통 파라미터 제거, 차이나는 것 + tests만 남김:

```
VER_485:  tests만 남김 (공통에 TIMEOUT, expected_response 있으므로)
SENTEMP_485: tests만 남김
APPCFG_485: tests만 남김
VIBE_485: TIMEOUT=5000, DURATION=3000, pass_consecutive_count=5, tests
TILT_485: TIMEOUT=5000, alive_min_delta_x=0.2, alive_min_delta_y=0.2, tests
```

### STEP 3. vibetilt_232.json 수정

동일하게 공통 파라미터 제거:

```
VER_232:  tests만 남김
SENTEMP_232: tests만 남김
APPCFG_232: tests만 남김
VIBE_232: TIMEOUT=10000, operator_prompt, tests
TILT_232: TIMEOUT=10000, alive_min_delta_x=40, alive_min_delta_y=25, tests
```

### STEP 4. build_workspace.ps1 수정

합성 로직 추가:

```
기존: libraries + library_depencency + procs 합성
추가: proc별 param deep merge
  1. common_params에서 해당 proc의 공통 파라미터 가져옴
  2. diff 파일의 param으로 덮어쓰기 (diff 우선)
  3. tests 배열은 diff에서만 가져옴
```

### STEP 5. 검증

```
- [ ] build_workspace.ps1 실행
- [ ] workspace.json이 기존과 동일한지 diff 확인
- [ ] workspace_232.json이 기존과 동일한지 diff 확인
- [ ] 프로그램에서 485 로딩 + 검사 PASS 확인
- [ ] 프로그램에서 232 로딩 + 검사 PASS 확인
```

## common_params 매칭 규칙

proc의 id에서 접미사 `_232`, `_485`를 제거한 키로 common_params를 찾음:

```
VER_485 → "VER" → common_params.VER
SENTEMP_232 → "SENTEMP" → common_params.SENTEMP
VIBE_485 → "VIBE" → common_params.VIBE
```
