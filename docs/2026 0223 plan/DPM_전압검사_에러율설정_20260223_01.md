# DPM 전압검사 에러율 설정

**작업일:** 2026-02-23
**담당자:** (사용자)

---

## 개요

RS-485 검사 workspace에 DPM 전압/전류 검사를 통합하고, 전압 검사에 에러율(%) 정보를 추가했습니다.

---

## 변경 사항

### 1. workspace.json 통합

**AS-IS:**
- `workspace.json` (DPM만)
- `workspace_vibetilt_b4cc79e step2 485 complete.json` (RS-485만)

**TO-BE:**
- `workspace.json` (RS-485 + DPM 통합)
  - DPM: COM12 (uart_dpm)
  - RS-485: COM11 (uart_485)

---

### 2. DPM 검사 항목 추가 (상단에 배치)

| 검사항목 | 채널ID | 에러율 | 범위 | 상태 |
|---------|--------|--------|------|------|
| 24V 검사 | id06 | ±3% | 23.28 ~ 24.72V | ✅ PASS |
| 3.3V 검사 | id09 | ±3% | 3.201 ~ 3.399V | ✅ PASS |
| 전류 검사 | id04 | - | -0.001 ~ 0.5A | ✅ PASS |

---

### 3. error_rate 필드 추가

**workspace.json 형식:**
```json
{
  "id": "id06",
  "error_rate": "3%",
  "min": "23.28",
  "max": "24.72"
}
```

**특징:**
- DPM 공용 json과 호환성 유지 (error_rate 필드 무시 가능)
- PrintLog + CSV에서 에러율 정보 표시 가능
- 다른 사용자의 기존 workspace에는 영향 없음

---

### 4. 3.3V 범위 계산

```
기본값: 3.3V
에러율: ±3%
계산: 3.3 × 0.03 = 0.099V

min: 3.3 - 0.099 = 3.201V
max: 3.3 + 0.099 = 3.399V
```

---

## 향후 작업 (H/W 설정 필요)

### 1. DPM 채널 ID 확인
- id09가 2개 채널을 가짐 (0.00364, 3.316)
- H/W 설정에서 3.3V 채널을 고유 ID로 변경 필요

### 2. 전류 채널 확인
- id04 값이 음수로 나옴 (-0.00009)
- 실제 전류값 0.0036과 불일치
- H/W 설정 확인 필요

### 3. 범위 정정
- 3.3V: 현재 0.003 ~ 3.5 (임시) → 3.201 ~ 3.399 (정정 완료 ✅)
- 전류: 현재 -0.001 ~ 0.5 (임시, 추후 정정 필요)
