사용법: 아래 표를 마우스로 드래그하여 선택 → Ctrl+C → PPT에서 Ctrl+V.
PPT에서 "원본 서식 유지" 또는 "대상 스타일 사용" 중 선택 가능.

예시 1 — 기본 스타일

#검사명판정 기준
0FW 버전 확인VER 응답
1영점 초기화 (0도)자이로센서 ±0.05
2CalibrationAN X: ±0.05
3파라미터 저장응답 확인
4기울기 (±20, ±45도)±0.2 / ±0.5
5Y축 진동 (+90도)GAC 0.98~1.02

예시 3 — 탭 구분 텍스트 (PPT 표 자동 생성용)

아래 텍스트를 복사 → PPT에서 "표 삽입" 후 셀에 붙여넣거나,
Excel에 먼저 붙여넣고 → 표를 복사 → PPT에 붙여넣으면 깔끔.
