1. 아키텍처 개요

flexfab.exe (WinForms)
  │
  ├── workspace.json (설정 파일)
  │     ├── libraries[]     → DLL 동적 로딩
  │     └── projects[].procs[]  → 검사 항목 순차 실행
  │
  ├── ff_common.dll (공통 라이브러리, 수정 금지)
  │     ├── Cantops.FlexFab.Uart    → RS-232/485 시리얼 통신
  │     ├── Cantops.FlexFab.Tcp     → EMIO TCP 통신
  │     └── Cantops.FlexFab.Ctsp    → CTSP 프로토콜 파싱
  │
  └── ff_vibetilt.dll (프로젝트 라이브러리)
        ├── Cantops.FlexFab.VibeTilt   → 보드레벨 검사 (VER, OFFSET, APPCFG, VIBE, TILT)
        └── Cantops.FlexFab.MotionJig  → 모션지그 검사 (ZERO, TILT_X/Y, VIBE_X/Y/Z)
절대 규칙:
  • ff_common.dll은 공용 라이브러리 — 프로젝트 특화 로직 추가 금지
  • 프로토콜 명령은 공통 라이브러리에 하드코딩 금지 → JSON에 작성
  • 프레임워크/아키텍처 변경 금지

2. 모듈 구성

2.1 VibeTilt.cs — 보드레벨 + 공통 검사

메서드검사 ID역할
VER()FWVER_232 / FWVER_485FW 버전 확인
UID()UID_232 / UID_485시리얼 번호 설정
OFFSET_Internal()OFFSET_232 / OFFSET_485Calibration + AN 검증
APPCFG_Internal()APPCFG_SAVE_232 / _485파라미터 저장/확인
VIBE_Internal()VIBE_232 / VIBE_485진동 측정 (보드레벨)
TILT_Internal()TILT_X/Y_232 / _485기울기 측정 (보드레벨)

2.2 MotionJig.cs — 모션지그 전용

메서드검사 ID역할
MOTION_ZERO_232()MOTION_ZERO_232 / _485영점 초기화 (홈 센서 → 0도)
MOTION_TILT_X_232()MOTION_TILT_X_232 / _485X축 기울기 측정
MOTION_TILT_Y_232()MOTION_TILT_Y_232 / _485Y축 기울기 측정
MOTION_VIBE_X_232()MOTION_VIBE_X_232 / _485X축 진동 측정
MOTION_VIBE_Y_232()MOTION_VIBE_Y_232 / _485Y축 진동 측정
MOTION_VIBE_Z_232()MOTION_VIBE_Z_232 / _485Z축 진동 측정

내부 진입점: MotionNewInternal() → isRs485 플래그로 232/485 분기

3.4 JSON 주석 규칙

spec 수치에는 반드시 _comment 또는 _xxx_comment 필드로 주석 추가. _ 접두어 필드는 프로그램에서 무시됨. 
"tilt_tolerance_20": 0.2,
"_tilt_tolerance_20_comment": "±20도 허용 오차 (사양서 ±0.2)"

4. 검사 프로세스 흐름

4.1 영점 초기화 (MOTION_ZERO)

InitMotionZero()
  ├── 자이로 방향 설정 (setdir6/setdir5)
  ├── EMIO 파라미터 설정 (PMS 시퀀스)
  ├── 홈 센서로 원점 복귀 (PMO011)
  │     └── IN1 감지 대기 (timeout: 15초)
  ├── 0도 위치로 이동 (steps_to_zero)
  ├── FineAdjust (자이로 기준 0.00도 수렴)
  ├── 소프트 리밋 설정 (±1600)
  └── _zeroInitialized = true (이후 회차에서 skip)

4.2 기울기 측정 (RunTiltMeasure)

RunTiltMeasure()
  ├── angles[] 순회 (예: [-20, -45, 20, 45])
  │     ├── MoveToAngle (coarse)
  │     ├── FineAdjust (자이로 기준 목표 각도 수렴)
  │     ├── VL 스트리밍 시작 (MODE 6 → START → AN 폴링)
  │     ├── AN 값 수집 (약 5초)
  │     ├── VL 스트리밍 정지
  │     ├── 오차 = VL각도 - 자이로각도
  │     └── 판정: |오차| ≤ tolerance
  └── 0도 복귀

4.3 진동 측정 (RunVibeMeasure)

RunVibeMeasure()
  ├── target_angle로 이동 (0도→±90도)
  ├── FineAdjust (수렴)
  ├── GAC 명령 3회 폴링
  │     └── GAC[check_axis_index] in [vibe_min, vibe_max]
  ├── 수평 복귀 (800 step)
  └── 판정: 3회 모두 범위 내

5. 통신 프로토콜

5.1 VL 센서 명령 (CTSP)

명령RS-232RS-485응답
FW 버전<VER><VER,1>[VER,...]
UID 설정<UID,VL1-xxx><UID,1,VL2-xxx>[UID,...]
OFFSET<OFFSET,1><OFFSET,1,1>[OFFSET,0,1] / [OFFSET,0,1,1]
APPCFG SAVE<APPCFG,SAVE><APPCFG,1,SAVE>[APPCFG,0,SAVE] / [APPCFG,0,1,SAVE]
MODE 설정<MODE,6><MODE,1,6>[MODE,0,06] / [MODE,0,1,06]
START<START><START,1>[START,0] / [START,0,1]
STOP<STOP><STOP,1>[STOP,0] / [STOP,0,1]
GAC 쿼리<GAC><GAC,1>[GAC,X,Y,Z,RMS] / [GAC,0,1,X,Y,Z,RMS]
AN 스트리밍(자동)(자동)[AN,X,Y] / [AN,0,1,X,Y]

5.2 EMIO 명령

명령설명응답
PPC00상태 확인ppc00
PMS04xxxx파라미터 설정pms04xxxx
PMO011홈 복귀 (원점)pmo0011 + pmp0011
PMD01x0800상대 이동 (800 step)pmd0011
PML011현재 위치 조회pml01xxxxxx
PIN1IN1 센서 상태pin10 (OFF) / pin11 (ON)
PIN2IN2 센서 상태 (과회전)pin20 / pin21

5.3 자이로 명령 (SOLAR-360-420)

명령설명응답
setdir5Y축 방향 설정(없음)
setdir6X축 방향 설정(없음)
angle현재 각도 조회angle=XX.XXX

6. RS-232 vs RS-485 차이

항목RS-232 (VL10)RS-485 (VL20)
제품VL10VL20
baudrate115200115200
포트COM13(X), COM14(Y) — 2포트단일 포트 — 1포트
명령 접미<VER><VER,1> (ID 포함)
응답 파싱[AN,X,Y] (offset=1)[AN,0,1,X,Y] (offset=3)
GAC 파싱[GAC,X,Y,Z,RMS] (5개)[GAC,0,1,X,Y,Z,RMS] (7개)
Y축 uart_iduart_232_y (별도 포트)불필요 (동일 포트)
코드 분기isRs485 = falseisRs485 = true
isRs485 판별: proc ID에 _485 포함 여부로 자동 결정. MotionNewInternal()에서 분기.

8. 에러 테이블

error_table.json에 정의. FAIL 시 에러 코드와 조치 방법 로그 출력.

에러 코드설명로그 출력 내용
ZERO_HOME_FAIL영점 초기화 실패홈 센서 LED / 원판 테이프 / EMIO IN1 / 모터 확인
COMM_TCPEMIO TCP 연결 실패파워서플라이 / LAN 케이블 확인
COMM_UART시리얼 포트 없음COM 포트 / 제품 장착 확인
COMM_GYRO자이로 통신 실패자이로 전원 / COM15 확인
OVERROTATION과회전 감지 (IN2)원판 위치 수동 조정
