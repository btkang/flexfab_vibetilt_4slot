슬라이드 7
검사 흐름 — 싱글 모드
  1. X축에 제품 장착 → START
  2. 작업자 확인 팝업 → 확인 클릭
  3. X축 검사 자동 진행 (약 1분 30초)
  4. "Y축에 제품을 장착해주세요" 팝업
  5. 제품을 Y축으로 이동 → 확인 클릭
  6. Y축 검사 자동 진행 (약 1분 20초)
  7. 결과 표시: PASS / FAIL
[사진] 작업자 확인 팝업 화면
슬라이드 8
검사 흐름 — 듀얼 모드
  1. X축: 새 제품 / Y축: 이전 제품 장착
  2. START → 확인 팝업 → 확인
  3. X축(#0~#5) → Y축(#0-Y~#11) 연속 자동 진행
  4. 전체 완료 → 결과 표시
  5. 다음 반복 시 제품 교체 팝업

소요 시간: 회당 약 2분 50초 (13개 항목)

듀얼 모드: X축(COM13), Y축(COM14)에 각각 다른 제품이 동시 장착됨
