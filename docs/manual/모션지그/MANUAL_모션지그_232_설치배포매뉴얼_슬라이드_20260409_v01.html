슬라이드 3
빌드 방법 A — Release (런타임 미포함)

대상 PC에 .NET 8 Desktop Runtime 설치 필요

  1. VS2022 → 빌드 구성: Release
  2. 빌드 (Ctrl+B)
  3. 결과물: output\Release\net8.0-windows\
대상 PC에 .NET 8이 이미 설치되어 있을 때 사용
슬라이드 4
빌드 방법 B — Self-Contained (런타임 포함, 권장)

대상 PC에 .NET 설치 불필요 (깡통 PC OK)

  1. 프로젝트 루트에서 명령 프롬프트 실행
  2. 아래 명령 실행:
dotnet publish flexfab_mini/flexfab.csproj -c Release -r win-x64 --self-contained true
  1. 결과물: flexfab_mini\output\Release\net8.0-windows\win-x64\publish\
깡통 미니PC에서 정상 실행 검증 완료 (2026-04-08, 13회 ALL PASS)
슬라이드 5
수동 복사 ① — DLL (Self-Contained만)

Self-Contained 빌드는 동적 로딩 DLL이 포함되지 않음

파일소스 (복사 원본)대상 (붙여넣기)
ff_vibetilt.dlloutput\Release\net8.0-windows\publish\
이 파일을 복사하지 않으면 검사 프로그램이 실행되지 않음!
슬라이드 6

소스: output\Debug\net8.0-windows\ → 배포 폴더로 복사

파일용도
workspace_motion_232.json양산 검사 (232)
longrun_motion_232_dual.json롱런 (232 듀얼)
longrun_motion_232_x.json롱런 (X축만)
longrun_motion_232_y.json롱런 (Y축만)
error_table.json에러 코드 테이블

배포 전 삭제: Result\, Log\ 폴더 (자동 생성됨)

슬라이드 10
설치 검증 체크리스트
  1. flexfab.exe 실행 → 정상 기동 확인
  2. 워크스페이스 로드 → 오류 없음 확인
  3. EMIO TCP 연결 확인 (로그: "TCP 연결 성공")
  4. 장치관리자에서 COM13/14/15 확인
  5. VL10 장착 → 싱글 1회 검사 → ALL PASS
  6. 듀얼 3회 반복 → 안정성 확인
