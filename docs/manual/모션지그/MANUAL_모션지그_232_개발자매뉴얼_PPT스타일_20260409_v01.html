I. 아키텍처 시스템 아키텍처

IV. 검사 흐름 영점 초기화 / 기울기 / 진동 
InitMotionZero()
 ├── 자이로 방향 (setdir6/5)
 ├── EMIO PMS 파라미터
 ├── PMO011 홈 복귀
 ├── 0도 이동 (1250 step)
 ├── FineAdjust (0.00도)
 └── 소프트 리밋 ±1600
RunTiltMeasure()
 ├── angles[] 순회
 │  ├── MoveToAngle
 │  ├── FineAdjust
 │  ├── VL AN 스트리밍
 │  └── 오차 판정
 └── 0도 복귀

RunVibeMeasure()
 ├── target 이동
 ├── GAC 3회 폴링
 └── 수평 복귀

V. 프로토콜 VL 센서 명령 — RS-232 vs RS-485
기능RS-232RS-485
FW 버전<VER><VER,1>
OFFSET<OFFSET,1><OFFSET,1,1>
SAVE<APPCFG,SAVE><APPCFG,1,SAVE>
MODE<MODE,6><MODE,1,6>
START/STOP<START> / <STOP><START,1> / <STOP,1>
GAC[GAC,X,Y,Z,RMS][GAC,0,1,X,Y,Z,RMS]
AN[AN,X,Y][AN,0,1,X,Y]
485는 응답에 에러코드(0)와 ID(1) 필드가 추가됨 → offset 차이로 파싱

VI. 232 vs 485 RS-232 vs RS-485 차이 요약
항목RS-232 (VL10)RS-485 (VL20)
baudrate115200115200
포트COM13(X), COM14(Y)단일 포트
명령 접미<VER><VER,1>
AN 파싱offset=1 (3필드)offset=3 (5필드)

코드 분기isRs485=falseisRs485=true
