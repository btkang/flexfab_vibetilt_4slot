1. 시스템 요구사항

항목요구사항
OSWindows 10/11 (x64)
.NET Runtime.NET 8 Desktop Runtime (런타임 미포함 빌드 시) 또는 불필요 (런타임 포함 빌드 시)
USB 포트최소 3개 (COM13, COM14, COM15용 USB-시리얼)
LAN 포트1개 (EMIO 보드 연결, 고정 IP)
디스크500MB 이상 (런타임 포함 빌드 시)

2. 빌드 방법

방법 A: Release 빌드 (대상 PC에 .NET 8 설치 필요)

1 VS2022 → 빌드 구성: Release → 빌드 (Ctrl+B)
2 결과물: output\Release\net8.0-windows\

방법 B: Self-Contained 빌드 (.NET 설치 불필요, 권장)

1 프로젝트 루트에서 명령 프롬프트 실행: 
dotnet publish flexfab_mini/flexfab.csproj -c Release -r win-x64 --self-contained true
2 결과물: flexfab_mini\output\Release\net8.0-windows\win-x64\publish\
권장: 깡통 미니PC에는 방법 B (Self-Contained) 사용. .NET 런타임 설치 없이 바로 실행 가능. 13회 ALL PASS 검증 완료 (2026-04-08).

3. 수동 복사 파일 (빌드에 포함 안 됨)

3.1 DLL (Self-Contained 빌드만 해당)

파일소스대상
ff_vibetilt.dlloutput\Release\net8.0-windows\publish\
주의: ff_vibetilt.dll은 동적 로딩 DLL이라 Self-Contained publish에 자동 포함되지 않음. Release 빌드 후 수동 복사 필수.

3.2 JSON (모든 빌드 공통)

소스: output\Debug\net8.0-windows\ → 배포 폴더로 복사

longrun_motion_485_x.json롱런 테스트 (485 X축)향후

5. 네트워크 설정 (EMIO 연결)

미니PC LAN 포트에 고정 IP 설정:

항목값
IP 주소100.100.100.xxx (70 제외, 예: 100.100.100.10)
서브넷 마스크255.255.255.0
게이트웨이(비워둠)
1 제어판 → 네트워크 → 이더넷 속성 → TCP/IPv4 → 고정 IP 입력
2 확인: ping 100.100.100.70 응답 확인

6. 미니PC 초기 설정

설정값이유
전원 → 화면 끄기10분 (기본값 OK)화면만 꺼짐, 프로그램 영향 없음
전원 → 절전 모드안 함절전 시 TCP 끊김 → EMIO FAIL 발생
Windows 업데이트자동 재시작 비활성화 권장롱런 중 재시작 방지
필수: 절전 모드 반드시 안 함으로 설정! 절전 30분 설정으로 인해 롱런 13회 만에 FAIL 발생한 사례 있음 (2026-04-08).

7. 설치 검증

  1. flexfab.exe 실행 → 프로그램 정상 기동 확인
  2. workspace_motion_232.json 로드 → 오류 없이 로드 확인
  3. EMIO TCP 연결 확인 (tcp TCP 연결 성공 로그)
  4. COM 포트 확인 (장치관리자에서 COM13/14/15 존재 확인)
  5. VL10 제품 장착 → 싱글 1회 검사 → ALL PASS 확인
  6. 듀얼 모드 3회 반복 → 안정성 확인

8. 업데이트 방법

DLL만 업데이트 (검사 로직 변경 시)

  1. 프로그램 종료
  2. 새 ff_vibetilt.dll을 배포 폴더에 덮어쓰기
  3. 프로그램 재실행

JSON만 업데이트 (설정/Spec 변경 시)

  1. 프로그램 종료
  2. 새 JSON 파일을 배포 폴더에 덮어쓰기
  3. 프로그램 재실행 → 워크스페이스 다시 선택

전체 업데이트

  1. 프로그램 종료
  2. 기존 Result\, Log\ 폴더 백업 (필요 시)
  3. 새 배포 폴더로 전체 교체
