2. 케이블 연결

1 LAN 케이블 — EMIO 보드 ↔ 미니PC (고정 IP: 100.100.100.70)
2 COM13 — X축 안착지그 ↔ 미니PC (VL10 제품, RS-232)
3 COM14 — Y축 안착지그 ↔ 미니PC (VL10 제품, RS-232, 듀얼 시)
4 COM15 — 자이로 센서 ↔ 미니PC (레퍼런스)
5 파워서플라이 — EMIO 보드 + 모터 전원 (DC 24V)
주의: COM 포트 번호는 미니PC USB 포트 위치에 따라 다를 수 있음. 장치관리자에서 확인 필요.

3. 전원 ON 순서

  1. 파워서플라이 ON — EMIO + 모터 전원 먼저
  2. 미니PC ON
  3. 자이로 센서 전원 확인 (LED 점등)
  4. 홈 센서 LED 확인 (원판 홈 위치에서 점등)
중요: 파워서플라이를 먼저 켜야 EMIO TCP 연결이 됩니다. 미니PC를 먼저 켜면 TCP 연결 실패합니다.

4. 프로그램 실행

1 flexfab.exe 실행
2 워크스페이스 선택:
용도파일명설명
양산 검사workspace_motion_232.json듀얼 모드, 1회
롱런 (듀얼)longrun_motion_232_dual.jsonX+Y 동시, 350회
롱런 (X축만)longrun_motion_232_x.jsonX축만 반복
롱런 (Y축만)longrun_motion_232_y.jsonY축만 반복
3 시리얼 번호 입력 (또는 자동 채번)
4 START 버튼 클릭

5. 싱글 모드 검사

  1. X축 안착지그에 VL10 제품 장착
  2. START → 작업자 확인 팝업 → 확인 버튼
  3. X축 검사 자동 진행 (#0~#5)
  4. X축 완료 후 "Y축에 제품을 장착해주세요" 팝업
  5. 제품을 Y축 안착지그로 이동 후 확인 버튼
  6. Y축 검사 자동 진행 (#7~#11)
  7. 결과 표시

6. 듀얼 모드 검사

  1. X축 안착지그에 새 제품, Y축 안착지그에 이전 제품(또는 비워둠) 장착
  2. START → 작업자 확인 팝업 → 확인 버튼
  3. X축 검사 (#0~#5) → Y축 검사 (#0-Y~#11) 연속 자동 진행
  4. 완료 후 다음 반복에서 제품 교체 팝업
듀얼 모드: X축(COM13)과 Y축(COM14)에 각각 다른 제품이 장착됩니다. X축 검사 동안 Y축 제품은 대기, Y축 검사 동안 X축 제품은 대기합니다.

7. 검사 항목 (회당 13개)

X축 (COM13)

#검사명내용판정 기준
0FW 버전 확인VL10 펌웨어 응답 확인VER 응답 수신
1X축 영점 초기화홈 센서(IN1) → 0도 이동 → 자이로 확인자이로 0.00도 수렴
2X축 CalibrationOFFSET 명령 → AN X값 검증AN X: ±0.05 이내
3X축 파라미터 저장APPCFG SAVE응답 확인
4X축 기울기 측정-20, -45, +20, +45도 이동 → VL vs 자이로 비교±20도: ±0.2 / ±45도: ±0.5
5Y축 진동 측정+90도 이동 → GAC Y값 확인GAC: 0.99~1.01

Y축 (COM14, 듀얼 시)

#검사명내용판정 기준
0-YFW 버전 확인Y축 제품 펌웨어 확인VER 응답 수신
7Y축 영점 초기화홈 센서 → 0도 이동자이로 0.00도 수렴
8Y축 CalibrationOFFSET → AN Y값 검증AN Y: ±0.05 이내
9Y축 파라미터 저장APPCFG SAVE응답 확인
12Z축 진동 측정0도 상태에서 GAC Z 확인GAC: 0.99~1.01
10Y축 기울기 측정+20, +45, -20, -45도 이동 → VL vs 자이로 비교±20도: ±0.2 / ±45도: ±0.5
11X축 진동 측정-90도 이동 → GAC X값 확인GAC: 0.99~1.01
소요 시간: 회당 약 2분 50초 (13개 항목 전부)

8. 결과 확인

결과의미조치
PASS (OK)모든 항목 합격다음 제품 진행
FAIL1개 이상 항목 불합격로그 확인 → 제품 불량 또는 지그 이상 확인

결과 파일 위치:

  • 로그: Log\모션지그검사(RS-232)\YYYY-MM-DD.log
  • 검사 결과: Result\모션지그검사(RS-232)\YYYY-MM-DD\시리얼번호.json

9. 문제 해결

증상원인조치
TCP 연결 실패EMIO 전원 OFF / LAN 미연결파워서플라이 ON 확인, LAN 케이블 확인
영점 초기화 FAIL (PMO011 timeout)홈 센서 미감지홈 센서 LED 확인, 원판 홈 테이프 상태, EMIO IN1 배선
FW 버전 FAIL (VER timeout)제품 미장착 / COM 포트 오류제품 장착 확인, 장치관리자에서 COM 포트 확인
기울기 FAIL제품 불량 / 자이로 이상오차값 확인 → Spec 경계면 재시도, 크면 제품 불량
진동 FAIL (GAC 범위 이탈)제품 불량 / 제품 미정위제품 장착 상태 확인, 재시도
과회전 감지 (IN2)원판 과회전프로그램 재시작, 원판 수동 위치 조정
절전 후 FAIL미니PC 절전 → TCP 끊김전원 설정 → 절전: 안 함

10. 종료 순서

  1. 프로그램에서 STOP (검사 중이면)
  2. 프로그램 종료
  3. 미니PC 종료
  4. 파워서플라이 OFF (마지막에)
퇴근 시 롱런 돌릴 때:
  • 미니PC 전원 설정 → 절전: 안 함 (필수!)
  • 화면 끄기: 10분 (상관없음)
  • 파워서플라이 ON 유지
