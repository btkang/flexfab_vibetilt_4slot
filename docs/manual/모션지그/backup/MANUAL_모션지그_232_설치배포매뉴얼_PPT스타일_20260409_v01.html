II. 빌드 빌드 방법 A — Release (런타임 미포함)
[캡처] VS2022 빌드 구성: Release
→ Ctrl+B
  • 대상 PC에 .NET 8 Desktop Runtime 필요
  • VS2022 → 빌드 구성: Release → 빌드
  • 결과물: output\Release\net8.0-windows\
3
II. 빌드 빌드 방법 B — Self-Contained (런타임 포함, 권장)
[캡처] 명령 프롬프트에서 dotnet publish 실행
  • 대상 PC에 .NET 설치 불필요
  • 깡통 미니PC에서 바로 실행 가능
dotnet publish flexfab_mini/flexfab.csproj -c Release -r win-x64 --self-contained true
  • 결과물: flexfab_mini\output\...\publish\
깡통 미니PC 검증 완료 (2026-04-08)
