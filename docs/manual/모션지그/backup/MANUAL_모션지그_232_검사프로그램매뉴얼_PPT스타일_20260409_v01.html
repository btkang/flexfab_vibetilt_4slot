II. 사용 방법 검사 흐름 — 싱글 모드
[캡처] 검사 진행 중 화면
  • ① X축에 제품 장착 → START
  • ② 작업자 확인 팝업 → 확인
  • ③ X축 검사 자동 진행 (~1분 30초)
  • ④ "Y축에 제품을 장착해주세요" 팝업
  • ⑤ 제품을 Y축으로 이동 → 확인
  • ⑥ Y축 검사 자동 진행 (~1분 20초)
  • ⑦ 결과: PASS / FAIL

II. 사용 방법 검사 흐름 — 듀얼 모드
[캡처] 듀얼 모드 검사 화면
(X축/Y축 동시 표시)
  • ① X축: 새 제품 / Y축: 이전 제품 장착
  • ② START → 확인 팝업 → 확인
  • ③ X축(#0~#5) → Y축(#0-Y~#11) 연속 자동
  • ④ 결과 표시
  • ⑤ 다음 반복 시 제품 교체 팝업

소요 시간: 회당 약 2분 50초

IV. 결과 확인 결과 확인 — PASS / FAIL
[캡처] PASS 결과 화면

V. 문제 해결 문제 해결 (Troubleshooting)
증상원인조치

영점 초기화 FAIL홈 센서 미감지홈 센서 LED, 원판 테이프, IN1 배선
FW 버전 FAIL제품 미장착 / COM 오류제품 장착, 장치관리자 확인
기울기 FAIL제품 불량오차값 확인, Spec 경계면 재시도

과회전 (IN2)원판 과회전프로그램 재시작, 수동 조정
