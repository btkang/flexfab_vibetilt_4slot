# 코드 추가 내용 - MotionJig 모션지그 검사 이식
작성일: 2026-02-24
브랜치: `step4-motion-jig`

---

## 1. 개요

BG01 MFC 코드(BoardLevelMo_BG01.cpp)의 모션지그 검사 시퀀스를 C# ff_vibetilt 프로젝트에 이식했다.
기존 보드레벨 검사(VibeTilt.cs)는 변경하지 않고 `MotionJig.cs`를 신규 추가했다.

---

## 2. 추가 파일 목록

| 파일 | 위치 | 설명 |
|------|------|------|
| `MotionJig.cs` | `ff_vibetilt/` | 모션지그 검사 모듈 (신규) |

| `VlSend()` | VL 센서 UART 송신 (`<CMD>`) |

| `VlClear()` | VL 센서 수신 버퍼 비우기 |

| `EvaluateAngle()` | 축별 임계값 판정 |

## 4. 12단계 모션 시퀀스

| 단계 | 이름 | 내용 |
|------|------|------|
| 0 | JIG_INIT | PMS×15 파라미터 설정 → PMO011 원점복귀 → PMD 초기 이동 |
| 1 | OPEN | msclose → msopen → deviceconnected 확인 |
| 2 | DEGREE_0_CHECK | 자이로 setzcur → get---x 기준각 저장 |
| 3 | ANGLE_p_10_5_0 | PMD+1500 → PML=17500 확인 (REPEAT_MOVE=2) |
| 4 | MEASURE_ANGLE_p_10_5 | mstest×3 → 판정(signX=-1, signY=-1) |
| 5 | ANGLE_m_10_5_0 | PMD-1500 → PML=16000 확인 |
| 6 | ANGLE_INIT_0 | PMD-1500 반복 → 자이로 ±0.005° 수렴 → PML=14500 |
| 7 | pCOM_INIT | msclose → msopen 재오픈 |
| 8 | ANGLE_m_10_5_1 | PMD-1500 → PML=14500 확인 |
| 9 | MEASURE_ANGLE_m_10_5 | mstest×3 → 판정(signZ=-1) |
| 10 | ANGLE_p_10_5_1 | PMD+1500 → PML=16000 확인 |
| 11 | ANGLE_INIT_1 | PMD+1500 반복 → 자이로 수렴 → PML=17500 |
| 12 | END | PASS 반환 |

## 5. EMIO 수신 정책

pmd0011 이외의 특정 응답은 무시하고 계속 대기한다:

| 응답 | 처리 |
|------|------|
| `pmd5011` / `pmd4011` | 무시 (SW 리밋 일시 충돌) |
| `pmp0011` | 무시 (원점복귀 자동 통보) |
| `ppc6...` | 무시 (HW 자동 정보) |

| library key | 클래스 | 역할 | Baudrate | Sampling |

| `uart_232_y` | `Cantops.FlexFab.Uart` | VL10 Y축 Master | **115200** | 10ms |
| `uart_232_z` | `Cantops.FlexFab.Uart` | VL10 Z축 UM | **115200** | 10ms |
| `uart_485` | `Cantops.FlexFab.Uart` | VL20 X/Y/Z RS-485 버스 | **460800** (115200×4) | 1ms |
| `uart_gyro` | `Cantops.FlexFab.Uart` | SOLAR-360-420 자이로 | **38400** 8N1 | - |

## 8. Workspace JSON 설정

### workspace_motion_232.json (VL10 RS-232)
- COM 포트 수정 필요: uart_232=COM3, uart_232_y=COM4, uart_232_z=COM5, uart_gyro=COM6
- `longrun: false` → 전체 판정 항목 적용

### workspace_motion_485.json (VL20 RS-485)
- COM 포트 수정 필요: uart_485=COM3, uart_gyro=COM6
- `longrun: false`
