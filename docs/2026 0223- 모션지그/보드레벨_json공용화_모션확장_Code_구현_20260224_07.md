# 보드레벨 JSON 공용화 모션확장 코드구현
작성일: 2026-02-24  
연계 Plan: `보드레벨_json공용화_모션확장_Plan_20260224_06.md`  
브랜치: `step4-motion-jig`

## 1. 구현 목적
- 보드 VIBE/TILT 파라미터를 모션 JSON에 공용 적용
- 모션 워크스페이스도 `workspace_parts + build_workspace.ps1` 합성 구조로 확장
- 로그 간격(`sample_log_interval_ms`)을 보드/모션 공통 500ms 기준으로 정리

## 2. 코드 구현 요약

### A. 모션 템플릿 분리
- 신규 파일 추가:
  - `output/Debug/net8.0-windows/workspace_parts/motion_232.json`
  - `output/Debug/net8.0-windows/workspace_parts/motion_485.json`
- 역할:
  - 모션 전용 라이브러리/프로세스 뼈대 정의
  - `longrun` 등 모션 전용 override 값 유지

### B. build_workspace.ps1 확장
- 추가 함수:
  - `Find-ProcById`
  - `Merge-Params`
  - `Build-MotionWorkspace`
- 동작:
  - 보드 proc(`VIBE_232/485`, `TILT_232/485`) param을 소스로 취득
  - 모션 proc param으로 override 병합
  - `workspace_motion_232.json`, `workspace_motion_485.json` 자동 생성
- 기존 중복검사(`Assert-UniqueValues`) 체계 유지

### C. 로그 간격 공통 적용
- `ff_vibetilt/VibeTilt.cs`
  - VIBE/TILT 샘플 로그 쓰로틀 추가
  - PASS 후보 로그 쓰로틀 추가
  - 기본값: `sample_log_interval_ms=500`, `pass_candidate_log_interval_ms=500`
- `ff_vibetilt/MotionJig.cs`
  - VIBE/TILT 샘플 로그 쓰로틀 추가(기본 500ms)
  - 루프 내부 `VlRecv(..., logRx: false)`로 원문 RX 스팸 로그 억제

## 3. JSON 반영 상태
- 보드 파트 JSON:
  - `vibetilt_232.json`, `vibetilt_485.json`에 `sample_log_interval_ms: 500` 반영
- 생성물 JSON:
  - `workspace.json`, `workspace_232.json`에 반영
  - `workspace_motion_232.json`, `workspace_motion_485.json`에 공용 파라미터 반영
