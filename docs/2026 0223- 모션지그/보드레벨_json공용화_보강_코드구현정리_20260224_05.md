# 보드레벨 JSON 공용화 보강 코드 구현 정리
작성일: 2026-02-24  
기준 문서: `보드레벨_json공용화_보강_Plan_20260224_04.md`  
대상 브랜치: `step4-motion-jig`

## 1. 개요
- 보드레벨 JSON 공용화(`workspace_parts` + `build_workspace.ps1`) 구조를 유지하면서 런타임 충돌 리스크를 줄이기 위한 보강 코드를 반영했다.
- 본 정리는 Plan의 A/B/C 항목 기준으로 실제 코드 반영 내용을 기록한다.

## 2. 구현 항목별 반영 내용

### A. DPM proc ID 고유화
- 파일: `output/Debug/net8.0-windows/workspace_parts/dpm_common.json`
- 변경 전: DPM 3개 항목 모두 `id = Powertest00`
- 변경 후:
  - `DPM_24V`
  - `DPM_3V3`
  - `DPM_CURR`

추가 반영:
- 생성 결과물에도 동일 ID 반영
  - `output/Debug/net8.0-windows/workspace.json`
  - `output/Debug/net8.0-windows/workspace_232.json`

### B. 232 ctsp commlib 보강
- 파일: `output/Debug/net8.0-windows/workspace_parts/vibetilt_232.json`
- 변경 내용:
  - `ctsp.config.commlib = "uart_232"` 명시

추가 반영:
- 생성 결과물 `workspace_232.json`에도 동일 설정 반영

### C. build_workspace.ps1 중복 검증 추가
- 파일: `output/Debug/net8.0-windows/build_workspace.ps1`
- 변경 내용:
  - `Assert-UniqueValues` 함수 추가
  - 아래 항목 중복 검사 추가
    - `libraries.id`
    - `project.procs.id`
  - 중복 발생 시 `throw`로 합성 즉시 중단

## 3. 런타임 연동 보강
- 파일: `ff_vibetilt/VibeTilt.cs`
- 변경 내용:
  - JSON의 신규 proc ID 호출을 수용하기 위해 메서드 추가
    - `DPM_24V(...) => Powertest00(...)`
    - `DPM_3V3(...) => Powertest00(...)`
    - `DPM_CURR(...) => Powertest00(...)`
- 목적:
  - 기존 측정 로직(`Powertest00`) 재사용
  - JSON ID 변경으로 인한 메서드 매핑 실패 방지
