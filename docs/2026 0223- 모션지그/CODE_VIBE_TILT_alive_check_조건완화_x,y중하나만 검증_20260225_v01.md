## 변경 배경

보드레벨 검사는 센서 정확도 검증이 아닌 **동작 여부 확인**이 목적.
기존 VIBE는 정밀 범위 체크(0.9~1.1G 등)로 인해 작업자가 특정 방향으로
정확히 흔들어야만 PASS되는 비직관적인 동작을 유발했음.
→ TILT와 동일하게 "움직임 감지" 방식으로 단순화.

## PASS 조건 요약

| 검사 | 적용 파일 | 모션 감지 조건 | 값 범위 조건 | 연속 횟수 | PASS 흐름 |
|------|----------|--------------|------------|---------|----------|
| 진동검사 (VIBE_232) | workspace_232.json | X 또는 Y > 0.13G | Z: 0.5~1.5G, X/Y: ±0.1G | 3회 연속 | 움직임 감지 → 정지 후 3샘플 통과 |
| 진동검사 (VIBE_485) | workspace.json | X 또는 Y > 0.13G | Z: 0.5~1.5G, X/Y: ±0.1G | 3회 연속 | 움직임 감지 → 정지 후 3샘플 통과 |
| 기울기검사 (TILT_232) | workspace_232.json | ΔX 또는 ΔY > 0.2° | — | 1회 | 0.5° 변화 감지 → 즉시 PASS |
| 기울기검사 (TILT_485) | workspace.json | ΔX 또는 ΔY > 0.2° | — | 1회 | 0.5° 변화 감지 → 즉시 PASS |

> 232 / 485 동일 조건 적용. TILT는 값 범위 체크 없이 변화폭(0.5°)만 확인.

### 연속 횟수 차이 이유

| | VIBE (3회) | TILT (1회) |
|---|---|---|
| 측정값 특성 | 순간값 — 샘플마다 오르내림 | 누적 span — 한번 커지면 줄어들지 않음 |
| 노이즈 위험 | 있음 (잔진동, 순간 이탈 가능) | 없음 (span은 단조 증가) |
| 결론 | 3회 연속으로 안정 상태 확인 필요 | 0.5° 초과 순간부터 영구 유지 → 1회 충분 |

```
VIBE Z값:  0.98 → 1.02 → 0.95 → 1.01 → ...  (오르내림 → 3회 연속 필요)
TILT span: 0.1  → 0.3  → 0.5  → 0.6  → ...  (단조 증가 → 1회면 충분)
```

## 동작 원리

### VIBE PASS 조건
```
motionZeroThreshold = 0.1 + 0.03 = 0.13G
→ X 또는 Y가 0.13G 초과 시 모션 감지
→ EvaluateVibeSample: Z 0.5~1.5G, X/Y ±0.1G 이내 → 3회 연속 → PASS
```
작동 흐름: 살짝 움직임 → 0.13G 초과 → 모션 감지 → 움직임 멈춤 →
Z 중력 범위 안에서 3샘플 연속 → PASS

### TILT PASS 조건
```
spanX = maxX - minX, spanY = maxY - minY
→ spanX >= 0.5° OR spanY >= 0.5° → PASS (passConsecutiveCount=1)
```
작동 흐름: 살짝 기울임 → 0.5° 변화 감지 → 즉시 PASS

## 불량 판별 범위 및 한계

| 고장 유형 | VIBE | TILT |
|---------|------|------|
| 센서 완전 불통 | FAIL ✅ | FAIL ✅ |
| Z축 고장 (0 반환) | FAIL ✅ (0.5~1.5G 범위 벗어남) | 미확인 (TILT 모드 미출력) |
| X 또는 Y 한 축 고장 | 조건부 감지 ⚠️ | 미감지 ⚠️ |

**결론:** 보드레벨 검사 목적(완전 동작 불량 감지)에 부합.
센서가 완전히 죽으면 X/Y/Z 모두 응답 없음 → FAIL.
축별 부분 불량은 이 단계에서는 판별하지 않음.
