# SOLAR-360-4/20 PDF 검토 요약 (2026-02-24)

원문: `SOLAR-360-420_Inclinometer_Sensor_4-20mA_Output.pdf`

## 1. 핵심 스펙 (문서에서 확인됨)
- 단축명: `SOLAR-360-4/20`
- 기능: 단일축 경사 센서, `RS232` + `4-20mA` 동시 출력
- 측정 범위: 기본 360도 계열, 아날로그 출력 범위는 `±1° ~ ±180°` 사용자 설정 가능
- 기본 시리얼 설정: `38.4kbps`, `8 data bits`, `1 stop bit`, `no parity` (8N1)
- 하우징: `IP67` (하우징/글랜드 기준)
- 커넥터/케이블: `M12 5-pin male`, 약 `2m` 케이블
- 전원/온도/정확도/드리프트 항목 존재: 상세 수치는 성능표(테이블) 참조 필요

## 2. 통신/제어 관련 포인트
- RS232는 Full Duplex로 동작
- 제어 명령은 소문자 기반, 고정 길이 명령 체계(문서상 7-byte 명령 설명)
- 명령 문자 간 간격 제한 존재: 문자 간격이 너무 길면 명령 폐기됨(문서상 `<100ms`)
- 출력 응답 주기, 필터 응답(주파수/시간상수), Baud rate, 4-20mA 풀스케일 범위를 명령으로 변경 가능

## 3. VibeTilt 프로젝트 적용 시 권장 설정
- 인터페이스 혼선 방지:
- `BG01 지그 매뉴얼`에서 RS232/RS485 표기가 섞여 있으므로, 본 센서는 우선 `RS232 38400 8N1` 기준으로 1차 검증 권장
- 로그 검증 항목:
- 부팅 직후 1회 응답 확인
- 연속 출력 모드(주기) 설정 후 10초 이상 수신 안정성 확인
- 문자 간격 제한 조건을 깨는 송신(딜레이/분할 write) 금지
- 아날로그 검증 항목:
- 4mA/20mA 끝점과 중간점(예: 12mA)의 각도 환산 일치 여부 확인
- 출력 범위(±30/±90/±180 등) 변경 후 즉시 반영 여부 확인

## 4. 확인 필요 항목 (실험 전 체크)
- 성능표 수치 확정:
- 정확도(20°C), 온도 드리프트(보정 전/후), 해상도, 장기 안정성 수치
- 전기 사양 수치 확정:
- 공급전압 범위, 소비전류(4mA/20mA 출력시), 허용 온도 범위
- 핀맵 최종 확정:
- M12 5핀의 `+V`, `GND`, `RS232 TX/RX`, `4-20mA` 배선 방향을 실제 하네스와 대조

## 5. 결론
- 이 센서는 `RS232 디지털`과 `4-20mA 아날로그`를 함께 제공하므로, 지그 검증에 유연하게 적용 가능
- 현재 프로젝트에서 가장 중요한 리스크는 성능표 수치 누락보다도 `인터페이스/배선/시리얼 설정 불일치`이므로, 우선 RS232 링크 안정화와 핀맵 확정부터 진행하는 것이 안전함
