7. 이식 시 재사용 가능한 핵심 요소

EMIO 통신 명령은 그대로 재사용 예정
구분 재사용 대상 비고
EMIO 통신 모듈 PortControl() 함수 + OnRcv() 수신 처리 STX/ETX 프로토콜 그대로 사용
모션 명령어 세트 초기화 14개 + 동작 명령 전체 명령어/파라미터 동일 적용
센서 시리얼 통신 CommThread 클래스 (Overlapped I/O) COM 포트/속도 설정 포함
상태머신 구조 13단계 순차 처리 패턴 스레드 기반 비동기 실행
이식 시 주의사항:
  • 소켓 연결 정보 (IP: 100.100.100.70, 포트: 2233) 확인 필요
  • 센서 COM 포트 번호는 대상 PC 환경에 맞게 조정
  • processdelay() 타이밍은 실제 하드웨어 응답 속도에 따라 조정 가능
  • 반복 테스트(Longrun) 기능 이식 여부 확인 필요
