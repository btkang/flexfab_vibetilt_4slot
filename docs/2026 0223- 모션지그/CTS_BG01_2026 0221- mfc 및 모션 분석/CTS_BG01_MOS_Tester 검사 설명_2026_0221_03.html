CTS_BG01_MOS_Tester 검사 설명

1. 이게 뭐하는 장비인가?

BG01 IMU 센서 보드의 불량 검사기입니다.

생산된 IMU 센서 보드를 지그에 꽂으면, 기계가 자동으로 기울여서 센서가 제대로 동작하는지 합격/불합격을 판정합니다.

스마트폰을 기울이면 화면이 돌아가는 것처럼, 그 안에 들어가는 기울기 센서 칩을 생산라인에서 실제로 기울여보고 규격에 맞게 동작하는지 확인하는 장비입니다.

2. 검사 동작 순서

① 원점 복귀  (왼쪽으로 크게 이동 ~80도 · 기계가 자기 위치를 찾는 동작, 검사 아님)
    ↓
② 검사 기준 0도 위치로 이동
    ↓
③ 오른쪽 +10.5도 이동 → 멈춤 → 센서값 측정
    ↓
④ 0도 복귀
    ↓
⑤ 왼쪽 −10.5도 이동 → 멈춤 → 센서값 측정
    ↓
⑥ 0도 복귀 → 검사 완료  PASS / FAIL 판정
상황원점 복귀(큰 이동)검사
Start 버튼 누를 때O (매번 실행)O
Longrun 반복 시X (생략)O (±10.5도만 반복)

3. 측정 항목

측정은 이동 중이 아니라 완전히 멈춘 상태에서 합니다.

센서측정값설명
기울기 (Angle)X, Y, Z 축 각도실제 기울인 각도와 센서가 읽은 값이 맞는지
가속도 (ACC)X, Y, Z 축기울인 방향으로 중력이 제대로 감지되는지
자이로 (Gyro)X, Y, Z 축 회전 속도기울이는 동작 중 회전 속도가 제대로 잡히는지

※ 진동 측정은 없음  |  X·Y·Z 3축 센서 보드를 동시에 검사 (최대 3채널)
