4.1 양수 방향 보정 (x y z.txt 기준)

보정 루프 특성:
  • 매 반복마다 모터가 미세 이동 (pmd0011 응답 확인)
  • 기울기 센서로 현재 각도를 읽어 0도 수렴 여부 판단
  • 첫 1~2회에서 큰 폭으로 감소 (±0.3~0.4 → ±0.1)
  • 이후 서서히 0에 수렴 (총 15~17회 반복)
  • 종료 조건: 절대값이 약 0.01~0.02 이하

7. 분석 요약

프로그램 핵심 동작 확인:
  • 이 프로그램은 센서 교정 테스터임을 확인
  • 모션보드가 정확히 ±10.5도로 기울이고, 각 센서가 올바르게 측정하는지 검증
  • 기울기(레퍼런스) 센서로 0점을 잡아 정밀 보정 (0도 수렴 루프 15~18회)
  • X축 센서는 roll 방향, Y/Z축 센서는 pitch 방향 측정
  • 보정 종료 조건: 기울기 센서 값의 절대값이 약 0.01~0.02 이하
  • 측정 정확도: 목표 10.5도 대비 실제 10.42~10.50도 범위 (오차 < 0.1도)
이식 시 참고사항:
  • 0점 보정 루프는 모터 미세 이동 + 기울기 센서 피드백 구조 → 동일하게 구현 필요
  • 센서별 개별 테스트(x/y/z)와 전체 테스트(xyz)를 모두 지원해야 함
  • 센서가 연결되지 않은 경우 해당 Rcv 응답이 비어있음 → 예외 처리 필요
  • 보정 루프 반복 횟수가 15~18회이므로 최대 반복 제한(timeout) 설정 권장
