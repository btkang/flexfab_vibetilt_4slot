# REF: VL10 / VL20 폴링 방식 프로토콜 정리

- 작성일: 2026-02-26
- 출처: 진동기울기센서(CTS-IOTS-VL10) 통신사양서 R8_251124
- 대상: RS-232 (VL10) / RS-485 (VL20) 공통

---

## 1. 핵심 명령어 정의

| 명령 | 역할 | 비고 |
|------|------|------|
| `<MODE,X>` | 센서 측정 모드 설정 | X: 00~09 |
| `<START>` | 센서 데이터 측정 시작 (측정 상태 진입) | 폴링/스트리밍 공통 필수 |
| `<STOP>` | 센서 데이터 측정 중지 (측정 상태 종료) | 폴링/스트리밍 공통 필수 |
| `<SAM,X>` | 자동 출력 주기 설정 (Xms마다 출력) | 스트리밍 전용, 폴링 불필요 |
| `<ATIM,ID,X>` | 자동 출력 지속 시간 설정 (X초 동안 출력) | **RS-485(VL20) 전용**, X=0이면 비활성화 |
| `<GAC>` | 가속도 데이터 1회 요청 (VIBE 폴링) | |
| `<AN>` | 기울기 데이터 1회 요청 (TILT 폴링) | |

---

## 2. MODE 설정값

| X | 데이터 종류 | 사용처 |
|---|-----------|--------|
| 00 | 기본값 (측정 안 함) | 초기화 / 종료 후 복귀 |
| 02 | G scale Accel Data | VIBE 진동검사 |
| 06 | Angle Data | TILT 기울기검사 |

---

## 3. 폴링 vs 스트리밍 비교

| 항목 | 스트리밍 | 폴링 |
|------|---------|------|
| 데이터 취득 | START 후 자동으로 계속 밀어줌 | GAC/AN 명령 1회 → 응답 1회 |
| SAM | ✅ 필요 (출력 주기 설정) | 불필요 |
| ATIM (485만) | ✅ 필요 (출력 지속 시간 설정) | `ATIM,ID,0` 으로 비활성화 |
| START | ✅ 필요 | ✅ 필요 |
| STOP | ✅ 필요 | ✅ 필요 |

> **START는 폴링에서도 필수.** 측정 상태로 진입해야 GAC/AN 응답이 가능하다.
> ATIM=0 설정이 폴링 전환의 핵심 (RS-485만 해당).

---

## 4. 현재 구현 시퀀스

### 4.1 VIBE (진동검사)

```
[RS-232 / VL10]
MODE,2  →  START
  ↓ (loop until PASS or timeout)
  <GAC>  →  [GAC, X, Y, Z, RMS]
  ↓
STOP  →  MODE,0

[RS-485 / VL20]
MODE,1,0  →  ATIM,1,0  →  MODE,1,2  →  START,1
  ↓ (loop until PASS or timeout)
  <GAC,1>  →  [GAC, 0, 1, X, Y, Z, RMS]
  ↓
STOP,1  →  MODE,1,0
```

### 4.2 TILT (기울기검사)

```
[RS-232 / VL10]
MODE,6  →  START
  ↓ (loop until PASS or timeout)
  <AN>  →  [AN, X, Y]
  ↓
STOP

[RS-485 / VL20]
ATIM,1,0  →  STOP,1  →  MODE,1,6  →  START,1
  ↓ (loop until PASS or timeout)
  <AN,1>  →  [AN, 0, 1, X, Y]
  ↓
STOP,1  →  MODE,1,0
```

---

## 5. 응답 포맷

| 명령 | RS-232 (VL10) | RS-485 (VL20) |
|------|---------------|---------------|
| GAC | `[GAC, X, Y, Z, RMS]` | `[GAC, 0, ID, X, Y, Z, RMS]` |
| AN  | `[AN, X, Y]`           | `[AN, 0, ID, X, Y]`          |

> RS-485 폴링 응답에는 `errcode(0)` 필드가 앞에 추가됨 → 파싱 offset 차이

---

## 6. RS-232 vs RS-485 차이 요약

| 항목 | RS-232 (VL10) | RS-485 (VL20) |
|------|---------------|---------------|
| ATIM | **없음** | ✅ 있음 (`ATIM,ID,X`, 단위: 초) |
| 명령 ID | 없음 (`<GAC>`) | 있음 (`<GAC,1>`) |
| 응답 포맷 | `[GAC,X,Y,Z,RMS]` | `[GAC,0,ID,X,Y,Z,RMS]` |
| 폴링 전환 방법 | START/STOP 구조만으로 충분 | `ATIM,1,0` 으로 자동출력 명시적 차단 |

---

## 7. SAM 잔류 현황

현재 workspace_232.json / workspace.json 양쪽에 `SAM,10` 항목이 잔류 중.
폴링 모드에서는 동작에 영향 없음 (자동 출력이 없으므로 SAM 설정값 무의미).
추후 정리 가능.
