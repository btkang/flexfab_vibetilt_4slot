# BG01 양산테스트 모션지그 메뉴얼 (요약)

본 문서는 `BG01_양산테스트_모션지그_메뉴얼.pptx` 및 실행 로그(`BG01_Log__2026-02-11_09H_42M_18S.txt`)를 바탕으로 재구성된 검사 가이드입니다.

## 1. 개요
*   **대상 장비:** CTS-OHTH-BG01 Tester (진동기울기센서 양산 검사용 모션 지그)
*   **핵심 컨트롤러:** EMIO 스텝모터 컨트롤러 (TCP/IP 통신, 포트 2233)
*   **검사 항목:** 센서 통신, 온도 측정, 각도 측정 (X/Y/Z), 진동 측정

## 2. 하드웨어 구성 및 연결
*   **모션 컨트롤러:** EMIO 보드 (IP: 100.100.100.70)
*   **센서 채널:**
    *   Target: 주 검사 대상 센서
    *   Master/Ref: 비교용 기준 센서
    *   U.M (Under/Main): 추가 하부 센서
*   **통신 방식:** 
    *   지그 제어: TCP/IP
    *   센서 측정: RS-485 (UART)

## 3. 검사 시퀀스 (Operation Sequence)

### 3.1 초기화 단계 (JIG_INIT)
1.  **컨트롤러 확인:** `PPC00` 명령으로 EMIO 상태 확인.
2.  **파라미터 설정 (PMS):** 가속도, 속도, 리밋 설정 등을 순차적으로 전송.
    *   예: `PMS041480`, `PMS0510550`, `PMS071212000` 등.
3.  **원점 복귀 (Move Origin):** `PMO011` 전송 후 `pmo0011` 응답 대기.
    *   *주의:* `pmp0011` 자동 알림 메시지가 뒤따라오므로 처리 필요.
4.  **위치 확인:** `PML011`을 통해 현재 펄스 위치가 원점인지 검증.

### 3.2 검사 수행 단계
1.  **센서 활성화:** `<msopen>`, `<msclose>` 명령으로 센서 통신 상태 확인.
2.  **모션 이동:** `PMD` 명령을 사용하여 특정 각도로 지그 이동.
    *   이동 완료 응답: `pmd0011`.
3.  **데이터 측정:** 센서에 `<mstest>` 명령 송신.
    *   응답 포맷: `A=각도, ACC=가속도, T=온도, GA=GA값`.
4.  **판정:** 측정된 값이 설정된 오차 범위 이내인지 확인.

## 4. 소프트웨어 설정 (config.ini)
*   `IDC_IPADDRESS1`: EMIO 보드 IP (기본 100.100.100.70)
*   `IDC_EDT_COND_VOL`: 전압 조건 설정
*   `IDC_EDT_COND_CUR`: 전류 조건 설정
*   `IDC_CMB_BAUD_RATE`: 통신 속도 설정 (각 채널별)

## 5. 주요 문제 해결 (Troubleshooting)

### 5.1 pmd5011 발생 패턴
*   **현상:** 원점 복귀 후 첫 이동 시 `pmd5011` 응답 수신.
*   **원인:** 소프트웨어 리밋(Limit) 충돌 감지.
*   **조치:** MFC 원본 로직에서는 이를 즉시 실패로 처리하지 않음. `ppc606138000` 자동 응답을 무시하고 최종적으로 `pmd0011`이 오는지 대기하여 판단함.

### 5.2 통신 타임아웃
*   EMIO 보드와 PC 간의 네트워크 상태 확인 (Ping 테스트).
*   RS-485 라인의 종단 저항 및 연결 상태 확인.
