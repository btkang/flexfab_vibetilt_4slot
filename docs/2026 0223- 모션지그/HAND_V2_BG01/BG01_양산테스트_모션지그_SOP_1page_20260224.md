# BG01 양산테스트 모션지그 SOP (1 Page)

목적: 작업자가 현장에서 빠르게 동일 절차로 검사하고 Pass/Fail을 일관되게 판정한다.

적용 대상:
- 지그: BG01 Motion Sensor JIG
- 프로그램: `CTS_BG01_MOS_Tester_Ver_1.0.0.6.exe`
- 참조: `BG01_양산테스트_모션지그_메뉴얼.pptx`

## 1) 시작 전 체크 (필수)
- [ ] 전원: 24V 공급 정상
- [ ] PC-EMIO TCP/IP 연결 정상 (기본 `100.100.100.70:2233`)
- [ ] COM 포트 연결 확인
- [ ] 보드 장착 방향 확인 (역삽입 금지)
- [ ] 지그 수평 상태 확인 (수평계로 조정)
- [ ] 통신 타입 확정: `SOLAR RS232(38400)` vs 시스템 설정(`RS-485`) 불일치 여부 확인 후 당일 기준값 기록

당일 기준값 기록:
- Sensor Interface: `__________`
- Sensor Baudrate: `__________`
- Tester COM Port: `__________`
- 작업자/시간: `__________`

## 2) 검사 운전 순서
- [ ] 프로그램 실행
- [ ] COM Port 설정
- [ ] 장착 위치 1에 1개 보드 장착 후 TEST
- [ ] 2개 운전: 위치2/위치1 장착 후 TEST
- [ ] 3개 운전: 위치3/위치2/위치1 장착 후 TEST
- [ ] 이후 Shift 방식 반복

Shift 규칙:
- Pass 보드: 다음 위치로 Shift
- Fail 보드: 해당 보드만 분리

## 3) 판정 기준 (현장 요약)
- Angle +X/-X, +Y/-Y, +Z/-Z: 기준값 대비 `±0.3`
- Acceleration X/Y: `±5`
- Acceleration Z: `±8` (기준 980/990/1000 계열)
- Gyro X/Y/Z: 기준값 대비 `±100` (기준 1050/-1050)

주의:
- 단위(각도/가속도/자이로)는 장비 설정 기준으로 통일해 기록한다.

## 4) Fail 대응 체크리스트
- Communication Fail:
- [ ] 케이블/커넥터 체결 상태
- [ ] COM 포트/보드레이트 재확인
- [ ] EMIO IP/PORT 재확인

- Move Fail:
- [ ] 모터 케이블/구동축 간섭 확인
- [ ] Software Limit(레지스터 28/29) 확인
- [ ] Origin/Home 관련 설정(10~14, 17~19) 확인

- Measurement Fail:
- [ ] 보드 장착 방향/체결 재확인
- [ ] 센서 응답 데이터 형식 확인
- [ ] 기준 보드와 비교 측정
