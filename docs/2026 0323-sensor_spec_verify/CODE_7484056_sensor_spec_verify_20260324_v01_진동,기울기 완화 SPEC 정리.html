보드레벨 검사 SPEC — 진동/기울기 센서

날짜: 2026-03-24  |  브랜치: step5-board-sensor_spec_verify  |  RS-485 / RS-232 공통

목적: 보드레벨 검사는 센서 동작 여부 확인이 목적. 양산 스펙 항목은 모두 검사하되, 수치는 완화.
원칙: 센서가 망가지지 않았으면 PASS, 고장(무응답/한축 불량)이면 FAIL.

1. 진동검사 (VIBE)

응답: [GAC, X, Y, Z, RMS]
판정: X, Y, Z 3축 개별 판정. 값 크기에 따라 1축/0축 자동 분류. 3축 + RMS 전부 만족해야 PASS.
동작: 어떤 방향이든 한번 기울였다 돌아오면 → 모션 감지 + 정지 상태 3축 판정 완료.

양산 vs 보드레벨 스펙 비교

항목양산 스펙보드레벨 스펙비고
1축 (one)0.9 ~ 1.10.5 ~ 1.5중력축(Z≈1.0) 확인
0축 (zero)-0.1 ~ 0.1-0.3 ~ 0.3비중력축(X,Y≈0) 확인
RMS0.5 ~ 0.650.1 ~ 2.0완전 불량(0) 감지 목적

보드레벨 전용 파라미터

항목값설명
require_motiontrue모션 감지 필수 (센서 살아있는지 확인)
motion_threshold0.050축 값이 0.05 초과하면 움직임 감지
pass_consecutive_count11회 범위 안에 들면 즉시 PASS
TIMEOUT10000ms485/232 통일

2. 기울기검사 (TILT)

응답: [AN, X, Y] (각도, 단위: 도)
판정: X, Y 각각 절대값이 범위 안이면 PASS. 양방향(+/-) 모두 허용.
동작: TILT_X(좌우 기울임) + TILT_Y(앞뒤 기울임) 2단계 분리 검사.
수평 정지: X≈-0.71도, Y≈0.67도 (1도 이하)

양산 vs 보드레벨 스펙 비교

항목양산 스펙보드레벨 스펙비고
X축85 ~ 90도|X| ≥ 5도 (5 ~ 95)좌우 어느 방향이든 5도 이상
Y축-85 ~ -90도|Y| ≥ 5도 (5 ~ 95)앞뒤 어느 방향이든 5도 이상

보드레벨 전용 파라미터

항목값설명
alive_checkfalse절대값 범위 모드 (기존 alive_check OR 로직 제거)
check_axis"x" / "y"축별 분리 검사 (해당 축만 판정)
pass_consecutive_count11회 범위 안에 들면 즉시 PASS
TIMEOUT10000ms485/232 통일

기존 대비 개선점

232 특이사항:
- 232는 스트리밍 모드라 데이터가 대량 수신됨 (485 폴링 대비)
- 진동검사: 책상 탁 치는 것만으로도 PASS (미세 진동 감지)
- 기울기검사 FAIL: 완제품 손으로 들고 하다 보니 X축 방향 미달 발생 (지그 사용 시 해소 예상)
- DPM: 232 전용 지그 미연결로 미테스트 (추후 확인 필요)
