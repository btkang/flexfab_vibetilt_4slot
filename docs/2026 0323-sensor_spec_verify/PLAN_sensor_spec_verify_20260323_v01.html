1. 진동검사 (VIBE_485 / VIBE_232) — 완료

GAC 응답: [GAC, X, Y, Z, RMS]
X, Y, Z 3축 모두 개별 판정. 각 축은 값 크기에 따라 1축/0축으로 자동 분류.
3축 모두 + 1값 범위 + 0값 범위 + RMS 범위 = 전부 만족해야 PASS
어떤 방향이든 한번 기울였다 돌아오면 모션 감지 + 정지 상태 3축 판정 완료

양산 스펙 기준 응답 예시

측정 방향응답 포맷응답 예시설명
X축[GAC, X, Y, Z, RMS][GAC, 1, 0, 0, 0.58]X=1, Y,Z=0
Y축[GAC, X, Y, Z, RMS][GAC, 0, 1, 0, 0.58]Y=1, X,Z=0
Z축[GAC, X, Y, Z, RMS][GAC, 0, 0, 1, 0.58]Z=1, X,Y=0

2. 기울기검사 (TILT_485 / TILT_232) — 미완료

AN 응답: [AN, X, Y]
X, Y 각각 범위 안에 들어야 PASS
기울기검사는 앞뒤 + 좌우 2단계 필요 (X축, Y축 각각 확인)
