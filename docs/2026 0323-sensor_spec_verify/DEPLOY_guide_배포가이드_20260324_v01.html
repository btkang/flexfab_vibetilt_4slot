방식 1: 런타임 별도 설치

1단계: 대상 PC에 .NET 8 데스크톱 런타임 설치 (1회)

다운로드: https://dotnet.microsoft.com/download/dotnet/8.0
파일: windowsdesktop-runtime-8.0.x-win-x64.exe
항목: ".NET 데스크톱 런타임 8.0.x" 선택 (Windows x64)
주의: 파일명 구분
windowsdesktop-runtime- → 데스크톱 런타임 (WinForms 실행, 이거 필요)
dotnet-runtime- → 콘솔용 런타임 (WinForms 실행 안 됨)
dotnet-sdk- → SDK (개발용, 대상 PC에 불필요)

2단계: VS2022에서 빌드

  1. 구성: Release, 플랫폼: Any CPU
  2. 빌드 → 솔루션 빌드

3단계: 배포

output\Release\net8.0-windows\

이 폴더 전체를 대상 PC에 복사.

포함 항목: exe, dll, workspace.json, Config 폴더, runtimes 폴더
Result 폴더: 빈 폴더로 복사 (검사 결과는 프로그램이 자동 생성)

방식 2: 자체 포함 배포 (Self-Contained)

1단계: 빌드 (터미널)

cd D:\03.Code\60.VL01\01.Flexfab_VL01\12.flexfab_VibeTilt\01.Flexfab_TEST\flexfab_VibeTilt
dotnet publish flexfab_mini/flexfab.csproj -c Release -r win-x64 --self-contained true

2단계: 생성 경로

flexfab_mini\output\Release\net8.0-windows\win-x64\publish\

3단계: 추가 파일 복사

publish 폴더에 다음 파일들을 output\Release\net8.0-windows\에서 복사:

파일설명
workspace.json검사 설정 (COM 포트, log_level, mongodb_uri 등)
workspace_232.jsonRS-232용 검사 설정 (필요 시)
ff_vibetilt.dll진동/기울기 검사 라이브러리
ff_common.dllUART/TCP 통신 라이브러리
ff_dpm.dllDPM 전압/전류 검사 라이브러리
Config\config.ini설정 파일
