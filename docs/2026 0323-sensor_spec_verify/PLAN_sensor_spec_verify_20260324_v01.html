Step 2: VibeTilt.cs — samplePass 로직 수정 (lines 1659-1661)

기존

bool samplePass = aliveCheck
    ? (spanX >= aliveMinDeltaX || spanY >= aliveMinDeltaY)
    : (x >= xMin && x <= xMax && y >= yMin && y <= yMax);

변경

bool samplePass;
if (aliveCheck)
{
    samplePass = (spanX >= aliveMinDeltaX || spanY >= aliveMinDeltaY);
}
else if (checkAxis == "x")
{
    samplePass = (x >= xMin && x <= xMax);
}
else if (checkAxis == "y")
{
    samplePass = (y >= yMin && y <= yMax);
}
else
{
    samplePass = (x >= xMin && x <= xMax && y >= yMin && y <= yMax);
}
핵심: check_axis: "x"이면 Y값 무시, "y"이면 X값 무시.
alive_check 모드는 기존 그대로 유지 (하위호환).
