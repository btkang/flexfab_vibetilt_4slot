진동기울기센서 자료

개발팀 담당자와 얘기했다.

VL10 : 232
VL20 : 485
VL30 : 485

크게 rs232와 rs485 명령이 다르다.

232와 485 명령이 별도이다.
보드레벨검사는 간단하게 진동검사, 기울기 검사를 한다.
: 살짝 지그를 기울인다.
모션 검사는 정밀하게 진동검사, 기울기 검사를 한다.
- 정밀하게 EMIO를 사용한다. 0도, 20도, 90도를 측정한다.
- 진동은 각을 돌릴 필요없다.(평지만한다.)
- 진동검사는 모드2, START, X,Y,Z 측정, 10ms, 115200
- 기울기검사는 모드6, X,Y 측정, 1ms -> 115200 x 4배 = 460800
- 순서: 모드0(기본) -> 모드2 -> START -> 계속 Read -> STOP -> 모드6 -> STOP

통신검사는 버전읽기로 한다. : VER 명령


flexfab(c#) 기본프로젝트 기반 
1. 보드레벨검사와 모션 검사는 workspace(json파일)을 각각만든다. 프로그램시 workspace를 로드해서 사용한다.
 : 예. workspace_board.json, workspace_motion.json 을 만든다.
2. 개별 프로젝트인 ff_vibetile.cs를 만든다. 여기에 232, 485 검사항목을 모두 넣는다. 동일 기능이라도 232와 485 명령이 다를수 있다.
  이때는 검사이름에 portfix에 _232, _485를 붙여 구분한다.
