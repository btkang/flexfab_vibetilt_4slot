## 1. 배경 / 목적

- 검사 판정(#4/#6)은 전부 "VL − 자이로" 상대 비교 → **자이로 자체가 틀어지면
  공통모드 오차로 상쇄되어 검출 불가.** 전 제품이 같은 바이어스로 전부 PASS하는 위험.
- VL cal(#11)도 자이로가 만든 지그 자세를 영점으로 물려받으므로, 자이로 오차는
  출하 제품의 영점 바이어스로 그대로 전파됨.
- → 자이로(지그 수평 기준)의 건전성을 **주기적으로, 자동으로** 확인하는 수단 필요.

## 2. 원리

골든 샘플 = 자이로가 정상임이 확인된 시점에 cal(#11) + 저장(#12)까지 마친 VL 센서를
출하하지 않고 점검 기준기로 보관한 것.

- 골든 샘플의 영점은 "과거의 올바른 수평"에 고정되어 있음
- 점검 시 지그 영점(#10)만 수행하고 **OFFSET 명령 없이** 골든 샘플의 AN을 읽으면:
  - 자이로 정상 → AN ≈ 0 (cal 시점과 동일한 수평)
  - 자이로 틀어짐 → AN = 틀어진 양이 그대로 출력 (부호 포함)
- 즉 기존 #11의 verify_an 측정을 "OFFSET 없이" 수행하는 것과 동일한 동작

## 3. 운영 방안

| 항목 | 내용 |
|---|---|
| 주기 | 매일 시업 점검 시 1회 (라인 가동 전) |
| 샘플 수 | **2개 이상** (판별용: 둘 다 이탈=지그/자이로 문제, 1개만 이탈=해당 샘플 교체) |
| 대상 축 | X결합 지그, Y결합 지그 각각 수행 (자이로/기구가 축별로 다름) |
| 판정(안) | AN 1초 평균: \|AN\| ≤ 0.03 정상 / 0.03~0.05 경고(추세 관찰) / > 0.05 NG(라인 정지, 정밀 레벨로 직접 확인) |
| 기록 | 결과 JSON 저장 → 품질모니터링에서 일자별 추세 그래프 (드리프트 조기 발견) |
| 샘플 관리 | 라벨(UID) 고정, 충격 금지 보관함, 6개월~1년마다 기준 갱신(정밀 레벨 확인 후 재cal) |

판정 한계값은 초안임. 실측 분포(현재 verify_an 실적 0.00x대) 기준으로 확정 필요.
