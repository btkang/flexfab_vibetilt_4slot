# VibeTilt 모션 튜닝 구현 계획서

- 작성일: 2026-04-25
- 작성자: 강병택
- 기준 버전: ff_vibetilt 0.6.9.60423
- 기준 데이터: 롱런 250회 ALL PASS (2026-04-07~08, RS-232 듀얼)

## 1. 배경

### 개발 단계
- **1단계 (완료)**: 모션 동작 구현 확인 → 누적 482회 ALL PASS 검증
- **2단계 (예정)**: 튜닝 → 사이클 시간 단축 + 코드 완성도 향상

### 현재 성능 (베이스라인)
| 항목 | 시간 | 비중 |
|------|------|------|
| 기울기 X + Y | 100초 (각 50초) | 60% |
| 영점 초기화 X + Y | 37초 (각 18~19초) | 22% |
| Calibration X + Y | 15초 (각 7.7초) | 9% |
| 진동 X + Y + Z | 12초 | 7% |
| **합계 (1사이클)** | **167초 (2분 47초)** | 100% |

### 목표
- 1사이클 167초 → **90초 이내**

## 2. 현재 코드 문제점

### 2-1. 타임아웃 버그 (MotionJig.cs)
```csharp
// 현재 (버그): 큰 이동도 최대 5000ms로 clamp
int timeoutMs = Math.Clamp(steps * 5 + 3000, 3000, 5000);
```
- 고속으로 올리면 이 문제가 실제로 발생할 수 있음
- Phase 1 (속도 올리기) 전에 반드시 수정 필요

### 2-2. FineAdjust 방향반전 로직 (MotionJig.cs)
```csharp
// 현재: prevAbsDelta가 루프 안에 있어 이전 반복 오차를 추적 못함
for (int i = 0; i < maxSteps; i++)
{
    double prevAbsDelta = Math.Abs(delta);  // ← 매 루프마다 초기화됨 (버그)
    // ...이동...
    double newAbsDelta = Math.Abs(targetAngle - currentAngle);
    if ((newAbsDelta - prevAbsDelta) > reverseThreshold ...)
        stepDirectionFactor *= -1;
}
```
- 방향반전 판단이 부정확 → 고속에서 진동(oscillation) 유발 가능

### 2-3. 속도/가속도 하드코딩 (Emio.cs)
```csharp
// 현재: 저속(Low) 고정
"PMS071231000"  // 저속 1000
"PMS0512664"    // 저가속도 64
```
- 파라미터 없이 코드에 고정 → 튜닝 시마다 코드 수정 필요

### 2-4. 소프트 리밋 하드코딩 (MotionJig.cs)
```csharp
EmioSend(emio, "PMS071288000", log);   // +8000 고정
EmioSend(emio, "PMS08129-8000", log);  // -8000 고정
```

## 3. 구현 플랜

### Phase 5 - 타임아웃 버그 수정 (선행 필수)
**파일:** `MotionJig.cs` - `MoveSteps()` 함수
**작업 시간:** 30분

```csharp
// 현재 (버그)
int timeoutMs = Math.Clamp(Math.Abs(steps) * 5 + _moveTimeoutMin, _moveTimeoutMin, _moveTimeoutMax);

// 수정
int timeoutMs = Math.Max(Math.Abs(steps) * 10 + _moveTimeoutMin, _moveTimeoutMin);
// 상한(_moveTimeoutMax) clamp 제거 또는 충분히 크게 설정
```

---

### Phase 3 - FineAdjust 안정화
**파일:** `MotionJig.cs` - `FineAdjust()` 함수
**작업 시간:** 1시간

```csharp
// 수정: prevAbsDelta를 루프 밖으로 이동
double prevAbsDelta = double.MaxValue;  // 루프 시작 전 선언

for (int i = 0; i < maxSteps; i++)
{
    // ... 이동 실행 ...
    double newAbsDelta = Math.Abs(targetAngle - currentAngle);

    if ((newAbsDelta - prevAbsDelta) > reverseThreshold && prevAbsDelta > tolerance)
        stepDirectionFactor *= -1;

    prevAbsDelta = newAbsDelta;  // ← 다음 반복을 위해 업데이트 (추가)
}
```

### Phase 1 - 속도/가속도 올리기
**파일:** `Emio.cs` - 초기화 시퀀스
**작업 시간:** 2시간 (실측 포함)

```csharp
// 현재 → 변경
"PMS071231000"  →  "PMS071212000"  // 저속 1000 → 고속 2000
"PMS071221000"  →  "PMS071222000"  // (중속도 동일하게 맞춤)
"PMS0512664"    →  "PMS06124256"   // 저가속도 64 → 고가속도 256
```

**실측 체크리스트:**
- [ ] 속도 올린 후 영점 초기화 정상 동작 확인
- [ ] 기울기 4각도 (-45, -20, +20, +45) FineAdjust 수렴 확인
- [ ] 리트라이 발생 여부 확인 (retry_used = 0 유지)
- [ ] 롱런 10회 이상 안정성 확인 후 250회 진행

---

### Phase 2 - Wait 시간 조정
**파일:** `MotionJig.cs` - LoadParams() 및 필드 초기값
**작업 시간:** 1시간 (실측 포함)

| 파라미터 | 현재 | 목표 | 설명 |
|---------|------|------|------|
| `tilt_move_wait` | 500ms | 200ms | 이동 후 안정화 대기 |
| `zero_settle_wait` | 1500ms | 800ms | 영점 후 안정화 대기 |
| `fine_step_wait` | 500ms | 200ms | FineAdjust 스텝 대기 |
| `fine_confirm_wait` | 500ms | 300ms | 수렴 확인 대기 |
| `level_return_wait` | 1500ms | 800ms | 수평 복귀 대기 |

**주의:** 너무 줄이면 자이로 안정화 전에 읽어 오차 증가 → 실측 필수

### Phase 4 - 파라미터화
**파일:** `Emio.cs`, `MotionJig.cs`, workspace JSON
**작업 시간:** 2~3시간

#### 현재 파라미터화 현황

**이미 JSON으로 빠진 것 (잘 된 것):**

| 파라미터명 | 기본값 | 설명 |
|-----------|--------|------|
| tilt_move_wait | 500ms | 이동 후 안정화 대기 |
| zero_settle_wait | 1500ms | 영점 후 안정화 대기 |
| fine_step_wait | 500ms | FineAdjust 스텝 대기 |
| fine_confirm_wait | 500ms | 수렴 확인 대기 |
| move_timeout_min | 3000ms | 타임아웃 최소 |
| move_timeout_max | 5000ms | 타임아웃 최대 |
| step_resolution | 0.1125 | 스텝당 각도 |
| reverse_threshold | 0.02 | 방향반전 임계값 |

**아직 하드코딩된 것 (이번에 수정 대상):**

| 항목 | 위치 | 현재값 |
|------|------|--------|
| 고속/중속/저속 | Emio.cs | 2000/2000/1000 |
| 가속도 (고/중/저) | Emio.cs | 256/128/64 |
| 소프트 리밋 | Emio.cs + MotionJig.cs | ±8000 |
| 모터 해상도 | Emio.cs | 480 pulse/rev |
| 토크 | Emio.cs | 550/650 |

#### 수정 방법

**Emio.cs**: 기본 stepList를 JSON steps 배열로 교체

```csharp
// 현재: 코드에 하드코딩
stepList = new List<object?>
{
    new Dictionary<string, object?> { { "command", "PMS071231000" }, ... },  // 저속 고정
    ...
};

// 수정: JSON에서 읽어오거나 파라미터로 명령어 생성
int velocityHigh  = GetParamInt(param, "velocity_high",  2000);
int velocityMid   = GetParamInt(param, "velocity_mid",   2000);
int velocityLow   = GetParamInt(param, "velocity_low",   1000);
int accelHigh     = GetParamInt(param, "accel_high",     256);
int accelMid      = GetParamInt(param, "accel_mid",      128);
int accelLow      = GetParamInt(param, "accel_low",      64);
int softLimitPlus = GetParamInt(param, "soft_limit_plus", 8000);
int softLimitMinus= GetParamInt(param, "soft_limit_minus",-8000);
```

**workspace JSON에 추가할 파라미터:**
```json
{
  "velocity_high": 2000,
  "velocity_mid": 2000,
  "velocity_low": 1000,
  "accel_high": 256,
  "accel_mid": 128,
  "accel_low": 64,
  "soft_limit_plus": 1600,
  "soft_limit_minus": -1600,
  "motor_resolution": 480,
  "torque_move": 550,
  "torque_hold": 650
}
```

**효과:** 코드 수정/빌드/배포 없이 JSON만 바꿔서 속도·가속도·리밋 튜닝 가능
