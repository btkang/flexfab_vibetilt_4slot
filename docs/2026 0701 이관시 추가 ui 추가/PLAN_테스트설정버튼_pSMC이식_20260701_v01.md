## 1. 기능 개요 (pSMC)

메인폼 **[테스트 설정]** 버튼 → 다이얼로그로 워크스페이스 설정을 **런타임 오버라이드**(파일 안 건드림) 또는 **파일 저장**.
- **적용**: 메모리(workspace)만 바꿔 즉시 반영. 재로드 시 파일값으로 초기화.
- **저장**: 현재 워크스페이스 JSON 파일에 영구 기록(top-level 플래그 + repeat_all_count만, spec/proc.param 제외).
- **재로드(F1)**: 파일 다시 읽어 오버라이드 초기화 — **VibeTilt엔 이미 우클릭 재로드 메뉴 있음(재사용)**.
- 오버라이드 활성 시 요약 라벨(`label_overrides`) 표시.

## 3. 오버라이드 대상 필드 (VibeTilt)

`_작업자_변경가능` 파싱 (없으면 기본셋). VibeTilt 워크스페이스 값:
```
log_level | show_log | serial_duplicate_check | serial_auto_increment | fail_continue | test_mode | repeat_all_count | expected_fw_version
```
- **pSMC 전용 필드 `electronic_load_mode` / `electronic_load_device` 는 제외** (VibeTilt 해당없음).
- 에디터 매핑:
  - `log_level` → 콤보(MP_LOG/TEST_LOG)
  - `serial_duplicate_check` → 콤보(0/1/2)
  - `test_mode` → 콤보(0 dual / 1 single)  ← VibeTilt 추가 케이스
  - `repeat_all_count` → NumericUpDown(1~9999, projects[0])
  - `serial_auto_increment` → 체크박스(bool)
  - `fail_continue` / `show_log` → 체크박스(0/1)
  - `expected_fw_version` → 텍스트박스(문자열, default)
  - (`fail_detail` 도 있으면 체크박스 — 목록에 없으면 생략)

| 메서드 | 어댑트 |

| `UpdateOverrideSummary` | 그대로 |
| `ToIntSafe` / `ToBoolSafe` | 그대로 |
| `ApplyWorkspaceCachedUI()` | **VibeTilt 어댑트**: fail_continue→checkBox_Process, fail_detail→_failDetailPopup, **log_level→`LogConfig.LogLevel`**, show_log→VibeTilt 창크기/토글, repeat_all_count→label_cycle |
| `SaveTestSettings()` | 그대로 (_currentWorkspacePath 사용, 있는 키만 갱신) |

### 4.4 재로드 연동
- VibeTilt 기존 우클릭 재로드에 `_settingsOverridden=false; ApplyWorkspaceCachedUI();` 추가(오버라이드 초기화). 새 F1 단축키는 선택.

## 5. 비파괴 / 주의

- **spec(판정기준)·proc.param은 대상 아님** — top-level 플래그 + repeat_all_count만. 판정 로직 불변.
- **적용=런타임(파일 불변)** 이 기본. 저장은 명시적 [저장] 버튼일 때만 파일 기록.
- 저장 시 CLAUDE.md JSON 규칙: 저장은 **현재 로드된 1개 파일**만 갱신(사용자가 연 것). Debug/Release 동시수정 규칙은 "코드가 JSON 생성" 케이스 대상이고, 이건 런타임 사용자 편집이라 해당 파일만. (양산 운영 시 유의 — 저장은 그 워크스페이스에만 반영됨)
- `log_level` 오버라이드는 `LogConfig.LogLevel` 직접 세팅으로 어댑트(가장 큰 차이점).
- window 크기(show_log)는 pSMC 수치(1541/941×851)가 아니라 **VibeTilt 값** 사용.
