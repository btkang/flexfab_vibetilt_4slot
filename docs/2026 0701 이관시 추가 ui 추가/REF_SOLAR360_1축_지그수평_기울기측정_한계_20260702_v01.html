SOLAR-360 1축 경사계 — 지그 수평 / 기울기 측정 한계 정리

작성: 2026-07-02 · 용도: 팀 회의 브리핑 · 대상: 모션 기울기 검사지그 (VibeTilt)

0. 한 줄 결론 (회의 핵심)

SOLAR-360은 1축(피치)만 본다. 지그 수평이 틀어지면 롤·피치가 동시에 틀어지는데, 피치 성분은 센서가 보고 보정되지만 롤(직교) 성분은 센서 사각지대라 못 잡는다. 따라서 "SOLAR-360으로 지그 수평까지 맞춘다"는 성립하지 않으며, 물리적 수평(특히 롤)은 버블 수평계 + 손으로 잡아야 한다.

1. 팀의 현재 이해 (전제 점검)

팀 인식 실제
"SOLAR-360으로 수평을 맞춰서 측정한다" ⚠️ 부분만 맞음 — 아래 2·3 참조
SOLAR-360 = 자이로 ❌ 자이로(각속도) 아님 → 경사계(inclinometer), 중력 기준 절대각
1축이라 피치는 보고 롤(직교)은 못 봄 ✅ 맞음

핵심 오해: SOLAR-360이 하는 일은 ① 소프트웨어 0도 영점과 ② 측정 판정 기준(마스터 자) 이다. 지그를 물리적으로 수평으로 "세우는" 일은 SOLAR-360이 하지 않는다.

2. 센서 사실 (Fact)

  • 종류: 경사계(inclinometer). 중력 방향 기준으로 정지 상태에서도 절대 기울기를 직접 출력. (각속도 적분·드리프트 개념 아님)
  • 축: 1축 — 한 평면(피치)만 감지. 직교축(롤)은 물리적으로 감지 불가.
  • 스펙: ±180° 범위 / 정확도 ±0.03° / 분해능 0.002° / 내부 DSP 선형화(90°도 측정).
  • DUT 대비: DUT(VL센서) 판정 분해능 0.2~0.5°급 → SOLAR-360이 약 10배 이상 세밀 → "마스터 자" 자격 성립.

3. 핵심 질문과 답 (회의에서 나온 논점)

Q. "피치가 기울어지면 기울기 측정은 맞아야 되냐?"

A. 지그 수평이 틀어진다 = 롤·피치가 동시에 틀어진다. 두 성분을 나눠서 봐야 한다.

틀어진 방향 센서가 보나? 어떻게 처리되나 측정 신뢰
피치 (센서 감지축) ✅ 봄 FineAdjust 폐루프가 실제 각도를 목표로 서보 + DUT↔레퍼런스 상대판정으로 공통분 상쇄 유지됨
롤 (직교, 사각지대) ❌ 못 봄 피드백·판정 어디에도 안 들어옴 → 회전축이 수평에서 벗어남 깨질 수 있음

→ 답: "피치 쪽으로만 살짝 틀어진 것"은 센서가 보고 보정하므로 측정이 맞을 수 있다. 그러나 지그 수평 틀어짐에는 반드시 롤 성분이 섞이고, 롤이 틀어지면 센서가 못 봐서 수평이 안 맞아질 수 있다. (= 회의에서 답한 내용 그대로)

4. 왜 피치는 괜찮은가 (자기보정 원리)

측정 흐름 (각 목표각도마다):

coarse 이동(펄스 카운트, 대충)
   → FineAdjust(SOLAR-360 피드백, 목표각 ±0.05°까지 펄스 재조정)   ← 폐루프
   → DUT(VL센서) 스트리밍 → tilt_spec 판정
  • 판정을 펄스 카운트로 하지 않음. 펄스는 근처까지만, 최종 각도는 경사계 피드백으로 재보정.
  • 피치 방향으로 축이 조금 기울어 "펄스 ≠ 실제각"이 되어도, FineAdjust가 경사계로 실제 각도를 목표에 맞춤 → 기하오차 흡수.
  • 레퍼런스와 DUT가 같은 플랫폼에 있어 공통 피치 오프셋은 상대비교에서 상쇄.

5. 왜 롤은 문제인가 (1축 사각지대)

  • 1축이라 롤 방향 기울기는 피드백에도, 판정 기준에도 안 들어옴.
  • 지그가 롤로 기울면 회전축 자체가 수평에서 벗어남 → 두 가지 문제: 1. 측정 오차: 측정면이 기울어 cosine(투영)·cross-axis 오차. 센서가 못 보므로 자기보정 불가. 2. 물리 정지(측정 이전 문제): 회전축이 기울면 중력 토크가 부하로 추가 → ±45° 큰 각도에서 모터 stall → [EMIO] TIMEOUT: 'pmd0011' → 해당 항목 FAIL. (2026-06-09 실측 확인, 0.7.1 양산본 재현)

즉 롤이 크게 틀어지면 "측정값이 슬쩍 오차 나는" 게 아니라, stall로 검사 자체가 FAIL 나서 애매하게 통과할 여지가 없다.

6. 그래서 "SOLAR-360으로 수평까지 커버" 는?

기능 SOLAR-360(1축)이 담당?
소프트웨어 0도 영점 (피치축) ✅ FineAdjust로 함
측정 판정 기준(마스터 자) ✅ 함
지그 물리 수평 — 피치 △ 판단 일부만 (감지축)
지그 물리 수평 — 롤(직교) ❌ 원리적으로 불가
수평을 물리적으로 "만드는" 행위 ❌ 센서는 측정만, 조정은 손/액추에이터

결론: 1축 센서로는 롤을 못 보므로 지그 수평을 커버할 수 없다. 버블 수평계 + 손 조정(특히 롤)이 필수이며, 이것은 코드로 대체 불가한 셋업 작업이다.

7. 권고 (회의 결정 사항 후보)

  1. [필수/현행 유지] 지그 물리 수평은 버블 수평계로 롤·피치 둘 다 맞춘다. 양산 셋업 체크리스트 필수 항목으로 명문화.
  2. [개선안 A — 가성비] 지그 프레임(회전 안 하는 곳)에 2축 절대경사계 1개 부착 → 검사 시작 전 "지그 수평 X°/Y° 임계 초과 시 START 차단" 팝업. 버블 눈대중을 SW 자동판정+로그로 대체. 손 조정은 유지, HW 최소 변경.
  3. [개선안 B — 오버스펙] 2축 센서 + 액추에이터 자동 수평 스테이지. 손 조정까지 제거하나 HW 대공사·비용 → 양산 검사지그엔 과함, 보류 권고.

부록. 용어 한 장 요약

  • 경사계(inclinometer): 중력 기준 절대 기울기. 정지해도 각도 나옴. (≠ 자이로/각속도)
  • 피치(pitch): SOLAR-360 감지축. 우리가 측정·판정하는 기울기 축.
  • 롤(roll): 직교축. 1축 SOLAR-360 사각지대.
  • FineAdjust: coarse 이동 후 경사계 피드백으로 목표각 ±0.05°까지 펄스 재조정하는 폐루프.
  • DUT: 검사 대상 VL센서. 레퍼런스(SOLAR-360)에 대고 상대 비교당하는 쪽.
