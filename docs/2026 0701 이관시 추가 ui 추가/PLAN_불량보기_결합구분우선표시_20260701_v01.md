## 2. ① 요구 상세

- 지그에 **시료 2개**를 넣고 검사: **X결합 위치 시료**(#1~#7) → **Y결합 위치 시료**(#8~#16) 순차.
- FAIL 시 작업자가 **어느 시료(X결합/Y결합)** 가 불량인지 **제일 먼저** 알아야 다음 조치가 됨.
- 정보원: proc.name에 **`[X결합]`/`[Y결합]` 태그 이미 존재** (실측 확인).
  - 예: `#6 [X결합] X축 기울기값 측정`, `#14 [Y결합] Y축 기울기값 측정`
- `fail_continue=0`(즉시중단)이라 **FAIL 발생 시 그 시점 1건**이 대표 → 결합 구분 명확(모호성 없음).

## 3. 현황 (코드 근거)

- **빨강 FailForm**(제일 먼저 뜨는 팝업): 큰 "FAIL" 글자 + `label_result`(작은 라벨 (11,227)).
  - ⚠️ **현재 label_result에 아무것도 안 뜸**: `ShowFailForm()`은 로컬 `dlg=new FailForm()`을 띄우는데, 호출부의 `mainForm.failForm.SetResult(...)`는 **안 띄운 멤버 인스턴스**에 세팅 (FlexfabForm.cs:3047~3048 등 4곳). 즉 카운트 텍스트가 화면에 안 나오는 상태.
  - `ShowFailForm(string? message)` 파라미터 경로는 살아있음 → **여기로 넘기면 실제로 표시됨** (3406 리플렉션 SetResult).
- **FailInfoForm**(불량보기 창): 그리드 [시간/시리얼/항목/사유] + 상세. `FailRecord.Item = proc.name`.
- **AddFailRecord**(FlexfabForm.cs:3421): proc.name → `Item`. **여기서 결합 태그 추출 추가 가능.**

## 4. 설계 (권장안: 빨강팝업 우선 + 불량보기 열 추가)

### A. 결합 추출 (공용 헬퍼 1개)
- `FailInfoForm`에 static `ExtractCoupling(string name)` 추가:
  - name에 `[X결합]` 포함 → `"X결합"`, `[Y결합]` 포함 → `"Y결합"`, 없으면 `""`.
  - 하드코딩 최소화: 대괄호 태그 파싱(`[..결합]`) 일반화.

### B. `FailRecord`에 `Coupling` 필드 추가
- `AddFailRecord`에서 `Coupling = ExtractCoupling(item)` 세팅.

### C. 빨강 FailForm — 결합을 **제일 먼저** 크게 (핵심)
- `ShowFailForm()`이 message 없이 불릴 때, **_failRecords에서 마지막(대표) 결합을 계산**해 message 앞에 붙임:
  - 예 message = `"▶ X결합\n#6 [X결합] X축 기울기값 측정"`.
- `ShowFailForm` 내부에서 계산 → **호출부 4곳(3047/3091/3188/3210) 수정 불필요.**
- `FailForm.Designer.cs`: `label_result` **폰트 확대(예 20~28pt Bold)** + 위치/크기 조정 → 빨강 배경에 결합구분이 큼직하게. (컨트롤 신규 없음, 속성만)
  - ※ FailForm은 `flexfab_mini`(공통) — fork 수정 승인됨(불량보기창 PLAN §3).

### D. 불량보기 FailInfoForm — 맨 왼쪽 "결합" 열
- 그리드 첫 열에 `결합`(X결합/Y결합) 추가, `FillWeight` 소폭, **Bold/색 강조**.
- `PopulateGrid`에서 `r.Coupling` 바인딩.
- 상세 텍스트 맨 위에도 `【X결합】` 헤더 1줄 prepend(선택).

### 표시 흐름
```
FAIL 발생(즉시중단)
   ↓
빨강 FailForm  →  "▶ X결합" (큰 글씨) + 항목명      ← 제일 먼저
   ↓ OK
불량보기 창    →  [결합|시간|시리얼|항목|사유]         ← 결합 열 최좌측
```

## 6. 비파괴 / 리스크

- ②(fail_continue) 미변경 → 검사 흐름 그대로.
- FailForm은 지금도 label_result가 화면에 안 뜨는 상태였으므로, message 경로로 채우는 건 **기존 기능 손상 아님**(오히려 죽어있던 표시 복구 + 결합 추가).
- 결합 태그 없는 항목(태그 미부여 proc)은 `""` → 기존과 동일하게 항목명만 표시(무해 폴백).
- 시료 1개만 넣는 부분사이클(시작/마감)에서도 태그대로 표시되어 혼선 없음.

## 7. 검증 (Debug 빌드 후 실기)

1. 빌드 성공(오류 0).
2. **X결합 시료 FAIL**(예 #6 기울기 강제 이탈) → 빨강 팝업 **"▶ X결합" 큰 글씨** 확인 → 불량보기 첫 열 `X결합`.
3. **Y결합 시료 FAIL**(예 #14) → **"▶ Y결합"** 확인.
4. 결합 태그 없는 항목 FAIL(보드검사 등) → 결합 빈칸, 항목명 정상.
5. PASS 회귀: 정상품 PassForm만, 불량보기 안 뜸.
6. ② 동작: X FAIL 시 즉시 중단(Y 미검사) 유지 확인.
