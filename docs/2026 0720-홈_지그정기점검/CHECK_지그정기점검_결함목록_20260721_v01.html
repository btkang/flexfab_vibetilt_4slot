# 결정 근거
D1 판정은 X 영점, 홈 수행 사이클만 (10사이클 중 1회, home_every_n: 10 현행 유지) 홈 생략 사이클의 r_pre는 복귀 잔차라 감시 무의미. 지그 틀어짐은 느린 현상이라 1/10 주기로 충분
D2 Y축 감시 삭제 하드웨어 확정: 레퍼런스 경사계는 1축(피치)이고 피치=경사 방향. X/Y 검사가 같은 지그·같은 센서·같은 측정축 → 감시 필요한 모든 변화는 피치 판독에 나타나고 X r_pre가 커버. Y r_pre는 새 정보 없음
D3 알림은 팝업 유지 (라벨 기각) 라벨은 모듈에서 쓸 UI 훅이 없음 — libraries에는 confirmCallback/confirmCallbackYesNo(팝업)뿐. 라벨 추가 = flexfab_mini(공통 라이브러리) 수정 필요라 기각
D4 PASS 경로 추가 시간 0 확인 r_pre는 기존 판독(MotionJig.cs:1509) 재활용. 추가는 계산+로그 1줄. 통신·모터·대기 추가 없음. 시간이 드는 건 팝업(이상 시)뿐

기록 경로 확인 결과: 로그는 Log/{프로젝트명}/YYYY-MM-DD.log 자동 저장(FlexfabForm.cs:1213-1220). 결과 details는 시리얼별 JSON. DB는 직접 기록 없음 — 품질모니터링이 결과 JSON 수집(간접).
