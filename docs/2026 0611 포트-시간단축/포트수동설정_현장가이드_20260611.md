# 포트 수동 설정 — 현장 가이드 (인터넷 불필요)

- 작성일: 2026-06-11
- 대상: 양산 현장 작업자 / 정비
- 전제: **인터넷 없어도 전부 동작** (장치 정보는 PC 로컬에서 읽음)

---

## 먼저 — 상황 판단 (어떤 경우인지)

| 상황 | 증상 | 대처 |
|---|---|---|
| ① 케이블 그대로, USB 위치만 바뀜 | COM 번호만 드리프트 | **[자동(FTDI)] 한 번** → 끝 (3장) |
| ② FTDI 케이블(485 X/Y) 교체 | [자동] 눌러도 "미발견" | 새 COM 입력 → [적용] (serial 자동 저장, JSON 손편집 X) (5장) |
| ③ Prolific(232) 위치 바뀜 | 232 X/Y/자이로 안 맞음 | 장치관리자로 확인 후 손입력 (4장) |

> 485 X/Y(FTDI)는 시리얼이 있어 ①이면 자동으로 해결. 232(Prolific)는 시리얼이 없어 항상 수동.

---

## 1. 장치관리자에서 COM 확인하는 법 (공통)

1. `Win + X` → **장치 관리자** → **포트(COM & LPT)** 펼치기
2. 목록 예시:
   ```
   Prolific PL2303GC USB Serial COM Port (COM13)   ← 232 계열 (시리얼 없음)
   USB Serial Port (COM17)                          ← FTDI (485 계열, 시리얼 있음)
   ```
3. **칩 구분**:
   - `Prolific PL2303...` → **232 X/Y/자이로** (시리얼 없음 → 위치로만 구분)
   - `USB Serial Port` → **FTDI = 485 X/Y** (시리얼 있음)

### FTDI 시리얼 보는 법
- 해당 `USB Serial Port (COMxx)` **더블클릭** → **자세히** 탭 → 속성 드롭다운 **장치 인스턴스 경로** 선택
- 값 예: `FTDIBUS\VID_0403+PID_6001+A93OWJK3A\0000`
- 마지막 `+` 뒤가 시리얼 → **`A93OWJK3A`**

> 💡 **장치관리자 안 열어도 됨**: 프로그램 **포트 변경** 창 상단 "현재 꽂힌 포트" 목록에 이 정보가 그대로 나옴.

## 2. 현재 설정된 기준값 (2026-06-11)

| 라이브러리 | 축 | COM | FTDI 시리얼 |
|---|---|---|---|
| `uart_485` | 485 X | COM17 | **A93OWJK3A** |
| `uart_485_y` | 485 Y | COM4 | **A947PITEA** |
| `uart_gyro` | 485 자이로 | COM16 | (Prolific, 시리얼 없음) |

---

## 3. [자동(FTDI)] 사용 (상황 ① — 가장 쉬움)

1. 프로그램 메뉴 → **포트 변경**
2. **[자동(FTDI)]** 클릭
3. `uart_485`·`uart_485_y` 칸이 현재 COM으로 자동 채워짐 (시리얼로 추적)
4. **[적용]** → 재시작

> COM 번호가 바뀌어도 시리얼이 같으면 항상 올바른 COM을 찾아줌.

---

## 4. 손으로 직접 입력 (상황 ③ / 임시 대처)

1. 1장 방법으로 어떤 COM이 어느 축인지 확인
2. **포트 변경** 창에서 해당 줄 칸에 `COMxx` 입력 (또는 −/+ 버튼)
   - 칸 오른쪽에 `← FTDI A93OWJK3A` 식으로 **실제 장치가 표시**되니 대조하며 입력
3. **[적용]** → 재시작

---

## 5. FTDI 케이블 교체 시 (상황 ②) — JSON 손편집 불필요

새 케이블은 **시리얼이 다름** → [자동]은 옛 시리얼을 못 찾아 "미발견" 뜸.
하지만 **[적용] 시 시리얼이 자동 저장**되므로 JSON을 손으로 고칠 필요가 없다.

1. 새 컨버터 꽂기
2. 포트변경 창 "현재 꽂힌 포트" 목록에서 **새 FTDI의 COM 번호** 확인 (예: `COM23 FTDI B12XYZ99A`)
3. 해당 줄(uart_485_x 또는 _y) 칸에 **새 COM 입력** → 칸 옆 `← FTDI B12XYZ99A` 로 대조
4. **[적용]** → 프로그램이 `port`(COM23) + `serial`(B12XYZ99A)을 **둘 다 자동 저장**
5. 재시작 → 다음부터 [자동(FTDI)]도 새 시리얼로 정상 추적

> 동작 조건: 그 줄에 원래 `serial` 필드가 있어야 자동 저장됨(485 X/Y는 이미 있음).
> 시리얼이 바뀌면 로그에 `[INFO] serial 갱신: uart_485 A93OWJK3A → B12XYZ99A` 가 찍힘 — 확인용.
> (구버전처럼 JSON 메모장 편집도 가능하나, 이제 불필요)

---

## 6. X / Y 어느 게 어느 건지 헷갈릴 때

- 자동채움/손입력 후 **485 기울기검사 X축**을 돌려서, 실제 X 방향이 맞게 움직이는지 1회 확인.
- 반대로 동작하면 X와 Y **시리얼(또는 COM)만 서로 바꿔서** 다시 적용.

---

## 7. X/Y 어긋남은 모션검사에서 FAIL로 걸린다 (2026-06-11 실증)

X/Y가 어긋나는 두 경우 — **둘 다 검사에서 FAIL로 잡힘** (조용히 통과 안 함):

| 경우 | 증상 |
|---|---|
| ① **485 컨버터를 반대로 꽂음** (X↔Y 센서 교차) | 통신/버전/정지 PASS → **#7 Y 진동에서 `GAC Y=0.0000` FAIL** |
| ② **제품을 X/Y 장착위치에 반대로 올림** | 위와 동일 (#7 등 모션에서 FAIL) |

**원리:** 모션검사는 "위치를 기울이고 → 그 축 채널 센서를 읽음". X/Y가 어긋나면 90도로 기울인 위치의 센서가 안 따라 기울어 → **측정값 0 → FAIL.**

**주의 (검출 조건):**
- **모션 측정 항목(#7 Y, #15 X 등)이 켜져 있어야** 걸림.
- **통신/버전/정지검사(#0/#1/#5-1)만으론 못 잡음** — 0도에선 X/Y 둘 다 평평해 구분 불가.
- "어느 쪽이 틀렸는지"까진 안 알려줌 — `GAC=0.0000 FAIL`로만 표시.

**조치:** #7 등에서 `GAC=0.0000` FAIL 나면 → ① 컨버터 X/Y 연결 확인 ② 제품 장착위치 X/Y 확인. 바로잡고 재검하면 PASS.

> 실증: 컨버터 반대로 → #7 `GAC Y=0.0000` FAIL / 원복 → #7 `GAC Y=0.99` PASS (2026-06-11 실기 확인).

## 요약 (현장 한 줄)
1. 보통은 **[자동(FTDI)] → 적용** 으로 끝.
2. 안 되면(새 컨버터 등) **창 상단 목록** 보고 새 COM 손입력 → **적용**.
3. **JSON 손편집 불필요** — 적용 시 port+serial 자동 저장.
