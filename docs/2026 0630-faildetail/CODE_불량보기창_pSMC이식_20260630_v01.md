## 2. FailInfoForm.cs (신규)

- pSMC `flexfab_mini/FailInfoForm.cs` UI를 그대로 이식 (`namespace flexfab`).
  - DataGridView(시간/시리얼/항목/사유) + 상세 TextBox(맑은고딕 13pt Bold) + 복사/지우기/닫기.
  - `FailRecord`(Time/Serial/Item/Summary/Detail) 동일.
- **파서만 VibeTilt 전용으로 교체** — `BuildFailSummaryDetail()`:
  - VibeTilt `MakeResult` 구조 `{Name,id,data:[{item|command,value,min?,max?,result}],result}` 파싱.
  - `data[]` 중 `result == NG/FAIL` 항목만 골라 `"{항목}: 측정 {value} (기준 {min}~{max})"` 포맷.
  - NG 마커 없고 top-level result만 NG면 전체 data 폴백 표시.
  - pSMC 형식(`Exp/Rsp`, `Item/Measure`)도 `FormatItem()`에서 폴백 처리.
  - 비JSON/빈 retmsg → `fail_tag` 또는 "상세 없음" 폴백.
- Newtonsoft.Json(JObject/JToken) 사용 — `flexfab.csproj`에 이미 참조.

## 5. 동작

- **fail_detail=1(기본)**: FAIL 시 빨강 FailForm → OK → 불량보기 창 자동 표시(해당 회차 NG 항목 측정값/기준).
- **fail_detail=0**: 자동표시 OFF, "불량보기" 버튼으로만 수동 확인.
- 빨강 FAIL 팝업 자체는 이 값과 무관하게 항상 표시(기존 동작 유지).
- 불량 목록은 **회차 단위**로 리셋(검사 시작·반복 라운드 초기화 시 Clear).
