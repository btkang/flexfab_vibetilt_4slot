## 1. 현황
- `#3 X영점`: skip_home 없음 → 매번 홈센서(PMO011) + 1250 step → **22~25s**
- `#10 Y영점`: 이미 `skip_home: true` → FineAdjust만 → ~14s (홈 안 함)
- 즉 매 사이클 #3에서만 홈복귀 22s를 반복 → 여기가 단축 포인트.
- 사이클 끝(#15)마다 **수평복귀 800step → 원판 ~0도**로 돌아옴 → 다음 #3 시작 시 원판이 0도 근처에 있음(skip_home FineAdjust 가능 전제).

## 2. 설계 — "최초1회 + N회마다" 홈복귀 (절충)
연속 생산에서 첫 대(또는 N대마다 1회)만 홈복귀, 나머지는 skip_home(FineAdjust)으로 0도 정렬.

### 2.1 코드 (`ff_vibetilt/MotionJig.cs`, InitMotionZero)
- static 카운터 신설: `private static int _motionZeroCount = 0;`
- 파라미터: `home_every_n`(int, default 1=매번=현동작). 0 또는 음수면 "최초1회만".
- 분기 로직(기존 `skip_home` 분기 앞에 삽입):
  ```
  bool autoSkip = false;
  int homeEveryN = GetParamInt(param, "home_every_n", 1);
  _motionZeroCount++;
  if (!skipHome && homeEveryN != 1) {
      bool mustHome = (_motionZeroCount == 1)                    // 최초 1회 필수
                   || (homeEveryN > 1 && (_motionZeroCount-1) % homeEveryN == 0);
      if (!mustHome) autoSkip = true;
  }
  ```
- `autoSkip || skipHome` 이면 홈 생략 경로(goto SkipToFineAdjust).
- 로그: `[ZERO] 홈복귀 생략 (N회마다, count=K/N) → FineAdjust`

### 2.2 안전장치 (재현성 리스크 흡수) ★중요
- skip 사이클 진입 직전 자이로 각도 확인 → **0도에서 임계 초과면 강제 홈복귀**.
  - `if (autoSkip && GyroGetAngle(...) && Math.Abs(angle) > home_skip_max_deg) { autoSkip=false; log("[ZERO] 0도 이탈 → 안전 홈복귀"); }`
  - 파라미터 `home_skip_max_deg`(default 5~10도). FineAdjust 범위(max_steps 250 ≈ ±28도)보다 보수적으로.
- 목적: 시료 교체 시 작업자가 원판 건드림 / 직전 사이클 중단으로 원판이 0도에서 멀 때 → FineAdjust 실패 방지.

## 3. 리스크 / 미결
- **원판 드리프트(누적)**: skip만 반복 시 영점 미세 누적 오차 → N회마다 홈복귀로 재동기화. N값은 실측으로 확정(예 10).
- **FineAdjust 도달성**: 원판이 0도에서 멀면 skip 실패 → 2.2 안전장치로 강제 홈.
- **검증 지표**: skip 사이클에서도 `#4 verify_an`(0도 AN X ±0.05)·`#13 Z=1G`가 PASS 유지되는지 = 영점 정확도 확인.
- 첫 대는 반드시 홈복귀(원판 위치 미지) → `_motionZeroCount==1` 보장.

## 4. 검증 방법
1. `home_every_n: 3` 같은 짧은 N으로 연속 5~6대 풀런 → 홈/skip 사이클 섞이게.
2. 확인: 전 대 OK, **skip 대의 #4 verify_an·#13 Z 정상**(영점 정확), skip 대 시간 ~14s(홈 대비 -8s+).
3. 시료 교체 중 원판 일부러 틀어서 → 안전 홈복귀 발동 확인.
4. 문제없으면 N=10 등 양산값 확정.
