1.2.1 PC 네트워크 설정 (신규 PC 최초 1회)

EMIO와 통신하려면 PC의 LAN 어댑터를 같은 IP 대역으로 설정해야 합니다.

단계설명
1Win+R → ncpa.cpl 입력 → 확인 (네트워크 연결 창 바로 열림)
2EMIO와 연결된 이더넷 어댑터 우클릭 → 속성
3인터넷 프로토콜 버전 4 (TCP/IPv4) 선택 → 속성
4"다음 IP 주소 사용" 선택
항목값비고
IP 주소100.100.100.1070 제외, 같은 대역이면 됨
서브넷 마스크255.255.255.0
기본 게이트웨이(비워둠)

설정 후 확인: cmd → ping 100.100.100.70 → 응답 오면 정상

주의: EMIO 전용 LAN 포트에만 설정. 인터넷용 LAN과 혼동 금지.
