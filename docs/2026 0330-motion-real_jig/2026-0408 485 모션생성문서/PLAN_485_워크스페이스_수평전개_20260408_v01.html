PLAN: 485 워크스페이스 수평전개 (VL20)

날짜: 2026-04-08  |  상태: 검토 대기

배경

  • 232 듀얼 워크스페이스 250회 ALL PASS 안정화 완료
  • 지금 485를 만들어야 이후 232 수정 시 485도 같이 반영 가능
  • 기존 workspace_motion_485.json 있지만 구버전 (듀얼 구조, 최신 파라미터 미반영)

SPEC (동일)

  • TILT: ±20도=±0.2, ±45도=±0.5
  • VIBE: GAC 0.99~1.01
  • OFFSET 검증: AN ±0.05

485 특성

  • baudrate: 460800 (232는 115200)
  • 단일 포트 (COM3) — 232는 X:COM13, Y:COM14 듀얼
  • 자이로: COM6 (232는 COM15)

구현 방식

232 듀얼 JSON (longrun_motion_232_dual.json)을 복사 후 485용으로 변경.
코드 변경 없음 — MotionJig.cs의 isRs485 분기가 이미 485 명령어 처리함.

485 듀얼 특이사항

  • 485는 단일 포트 → Y축 항목의 uart_id: uart_232_y 전부 제거
  • Y축 전환 시 제품 교체 필요 → operator_prompt 추가 (#7 Y축 영점에)
  • 232에서 Y축은 uart_id로 COM14 지정했지만, 485는 같은 포트이므로 불필요

확인 필요 사항

  1. COM 포트: uart_485=COM3, uart_gyro=COM6 맞는지?
  2. 듀얼 구조로 만들지 싱글로 만들지?
  3. UID 설정 항목 추가 여부? (사양서에는 있음, 232 롱런에는 없었음)
  4. 롱런 반복 횟수?
