NOTE: 485 통신 이슈 (2026-04-08)

보류 — 하드웨어 담당자 확인 필요

증상

  • longrun_motion_485_x.json으로 실행 시 VL20과 통신 안 됨
  • <VER,1> 명령에 응답 없음 (TIMEOUT → FAIL)
  • 포트몬에서 직접 송신해도 응답 없음

시도한 것

1차: 기존 지그 COM13 사용

  • PC COM13 → 232-to-485 컨버터 → VL20 시료
  • baudrate: 115200 (보드레벨 workspace_485.json 기준)
  • 결과: 응답 없음

2차: USB 485 컨버터 (COM11) 사용

  • PC USB → 485 컨버터(COM11) → 9핀 D-SUB → 지그 보드 → VL20 시료
  • baudrate: 115200
  • 결과: 응답 없음

원인 추정

  • 지그의 9핀 중간 보드가 232 전용 배선일 가능성
    • 232: TX/RX (2번, 3번 핀)
    • 485: A/B (다른 핀)
  • 보드레벨 검사 때 어떤 케이블/보드로 연결했는지 미확인

확인 필요 사항 (하드웨어 담당자)

  1. 보드레벨 485 검사 시 사용한 케이블/연결 구성
  2. 지그 9핀 보드가 485 지원하는지
  3. 485 컨버터 A/B 극성 확인
  4. VL20 시료 정상 여부 (보드레벨 PASS 이력 확인)
