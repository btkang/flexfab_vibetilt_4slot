### 3.1 검사 순서 (procs)

**X축 (COM13):**
`#0 FW버전 → #1 영점 → #2 CAL → #3 저장 → #4 기울기 → #5 Y축진동`

**Y축 (COM14):**
`#0-Y FW버전 → #7 영점 → #8 CAL → #9 저장 → #12 Z축진동(0도) → #10 기울기 → #11 X축진동`

> Z축 진동은 CAL/저장 직후 배치 (0도 상태 유지, 이동 불필요)
