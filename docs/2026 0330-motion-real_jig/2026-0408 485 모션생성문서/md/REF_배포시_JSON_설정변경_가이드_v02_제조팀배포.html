검사 프로그램 설정 가이드 (제조팀 배포)

새 PC에 프로그램을 설치하거나 장비를 변경했을 때 확인할 사항입니다.

1. PC에 프로그램 복사

닷넷런타임포함 폴더의 publish 내용물을 PC에 복사합니다.
별도 설치 없이 바로 실행 가능합니다.

1.5 시리얼 포트 드라이버 설치 (신규 PC 최초 1회)

멀티포트 어댑터: NEXT RS232 4P (PL2303GC 칩)

1. Prolific 공식 홈페이지에서 드라이버 다운로드
   https://www.prolific.com.tw/portfolio-item/pl2303gc/
   파일명: PL23XX-M_LogoDriver_Setup_4900_20260306.exe
2. 설치 파일 실행 (자동 설치)
3. 장치 관리자에서 Prolific PL2303GC USB Serial COM으로 4포트 인식 확인
⚠ 드라이버 미설치 시 장치 관리자에 ? 또는 "USB Serial Port"로 표시되며 통신 불가

2. COM 포트 확인

장치 관리자 → 포트(COM & LPT) 에서 번호를 확인합니다.
장비용도JSON에서 찾을 키워드기본값
VL 센서 X축제품 통신"port": "COM13"COM13
VL 센서 Y축제품 통신"port": "COM14"COM14
자이로 센서레퍼런스"port": "COM15"COM15
⚠ COM 포트 번호가 다르면 JSON 파일을 메모장으로 열어서 해당 숫자를 변경해야 합니다.

3. EMIO 모터 연결 (LAN)

장비JSON에서 찾을 키워드기본값
EMIO 보드"ip": "100.100.100.70"100.100.100.70

3.1 PC 네트워크 설정 (최초 1회)

1. Win+R → ncpa.cpl 입력 → 확인 (네트워크 연결 창 바로 열림)
2. EMIO와 연결된 이더넷 어댑터 우클릭 → 속성
3. 인터넷 프로토콜 버전 4 (TCP/IPv4) 선택 → 속성
4. "다음 IP 주소 사용" 선택 후 입력:
항목값
IP 주소100.100.100.10 (70 제외, 아무 숫자)
서브넷 마스크255.255.255.0
기본 게이트웨이(비워둠)
5. 확인 → 닫기
6. cmd 열고 ping 100.100.100.70 → 응답 오면 정상
⚠ EMIO와 연결된 LAN 포트에만 설정합니다. 인터넷용 LAN과 혼동하지 마세요.
⚠ LAN 케이블을 먼저 물리적으로 연결한 후 설정하세요.

4. Workspace 파일 선택

프로그램 실행 후 워크스페이스 열기 버튼으로 JSON 파일을 선택합니다.

파일명용도
workspace_motion_232.json양산 검사용 (RS-232)
workspace_motion_485.json양산 검사용 (RS-485)
⚠ longrun_으로 시작하는 파일은 테스트용입니다. 양산에서는 사용하지 마세요.

5. 검사 실행

1. 프로그램 실행 → workspace 선택
2. X축에 새 제품, Y축에 이전 제품 장착
3. 시리얼번호 입력
4. 시작 버튼 클릭
5. 13항목 ALL PASS 확인

6. 문제 발생 시

증상확인할 것
포트 연결 실패장치 관리자에서 COM 번호 확인 → JSON 수정
TCP 연결 실패EMIO 보드 전원, LAN 케이블 확인
영점 초기화 실패모터 전원, 홈 센서 확인
자이로 응답 없음자이로 전원, COM 포트 번호 확인

7. 에러 코드 (FAIL 시 로그에 표시)

7.1 통신 에러

에러의미확인할 것
COMM_TCPTCP 연결 실패 (EMIO)LAN 케이블, EMIO 전원, IP 주소 확인
COMM_UARTCOM 포트 연결 실패USB 케이블, COM 번호, 장치관리자 확인
COMM_GYRO자이로 센서 연결 실패COM15 연결, 자이로 전원, 케이블 점검

7.2 모터/이동 에러

에러의미확인할 것
MOVE_TIMEOUT모터 이동 2회 연속 실패모터 케이블, EMIO 에러(PPC00), 소프트 리밋
MOVE_HOME_TIMEOUT홈 센서 감지 실패홈 센서 LED, 원판 홈 이물질/테이프, 센서 배선
ZERO_HOME_FAIL영점 홈 복귀 실패홈 센서, 원판 테이프, EMIO IN1 배선
ZERO_MOVE_FAIL영점 0도 이동 실패모터 케이블, 소프트 리밋, EMIO 에러 클리어

7.3 측정 에러

에러의미확인할 것
TILT_SPEC_OUT기울기 Spec 초과제품 불량 (±20도: ±0.2 / ±45도: ±0.5)
TILT_SENSOR_DIFF자이로-VL 차이 > 10도COM 포트 불일치, 제품 장착 방향, 제품 불량
VIBE_GAC_FAIL진동 GAC Spec 초과제품 불량 (Spec: 0.99~1.01)
TILT_AN_PARSE_FAILAN 데이터 파싱 실패제품 장착, VL 센서 통신 확인
VIBE_GAC_PARSE_FAILGAC 응답 파싱 실패제품 장착, VL 센서 통신 확인

7.4 EMIO 에러 코드

코드의미조치
pmd0011정상 완료없음
pmd4011명령 수행 불가 (동작 중)재시도
pmd5011소프트 리밋 충돌자동 복구 대기
ppc006에러 있었음 (클리어됨)자동 처리

체크리스트

  • ☐ 프로그램 폴더 복사 완료
  • ☐ 시리얼 포트 드라이버 설치 (PL2303GC)
  • ☐ COM 포트 번호 확인 (장치 관리자)
  • ☐ COM 포트 번호 다르면 JSON 수정
  • ☐ EMIO LAN 케이블 연결
  • ☐ PC 네트워크 IP 설정 (100.100.100.10 / 255.255.255.0)
  • ☐ ping 100.100.100.70 응답 확인
  • ☐ 양산용 workspace 선택 (workspace_motion_xxx.json)
  • ☐ 테스트 1회 실행 → ALL PASS 확인
