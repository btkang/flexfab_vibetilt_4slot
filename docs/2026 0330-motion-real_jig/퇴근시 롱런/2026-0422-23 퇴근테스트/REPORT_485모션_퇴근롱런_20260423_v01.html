10. 후속 권장 사항

10.1 검출 변별력 검증 (필수)

  • NG 샘플 테스트 (1~3건) — 의도적 불량 보드(자이로 결선 단선 / FW 응답 누락 / 센서 편향 강제 주입 등)를 만들어 각 검사 스텝(#0~#16)에서 정확히 FAIL 처리되는지 확인. False-Pass 0 확인.
  • 경계값 샘플 (있을 경우) — 스펙 ±0.5도 근처(예: 0.4도) 오차를 가진 샘플로 PASS/FAIL 판정 경계가 합리적으로 동작하는지 검증.

10.2 양품 다대수 산포 검증 (권장)

  • 5~10대 양품 1회씩 검사 실행 → 디바이스 간 측정값 산포(특히 ±45도 TILT, GAC) 확인. 1대 결과의 일반화 가능성 검증.

10.3 측정 정밀도 향상 (선택)

  • 한쪽 편향 큰 케이스 분석 — 과거 ±45도에서 한쪽만 0.25도(스펙 50%) 오차 사례가 있었음. 가장 유력한 원인은 모터 백래시 + 측정 시퀀스 효과(영점에서 +쪽으로 먼저 회전 후 -쪽으로 방향 전환할 때 백래시 빠짐). 검증 방법: ① 영점 actual 잔류오차와 ±45도 오차 부호의 상관관계, ② 측정 순서 뒤집어서(-부터) 재현 테스트, ③ 양방향 접근 히스테리시스 측정.
  • 다중점 캘리브레이션 — OFFSET이 0도에서만 수행되므로 ±20, ±45 별도 OFFSET 측정해 보정 테이블 추가하면 시스템 편향 0.13도 → 0.05도 수준까지 줄일 여지.
  • Burn-in 사이클 폐기 — 첫 5~10 사이클은 기구 settling/온도 안정화 중이므로 통계 산입 제외.

10.4 추가 데이터 수집 (참고)

  • 나머지 30 사이클(271~300) 추가 진행 시 RS-232 라인과 동일 환경 비교 데이터 확보.
