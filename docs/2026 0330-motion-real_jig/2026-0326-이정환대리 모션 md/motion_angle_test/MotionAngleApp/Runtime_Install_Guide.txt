[.NET 8 Desktop Runtime 설치 안내]

이 프로그램은 .NET 8 Desktop Runtime이 필요합니다.
실행 시 아래와 같은 오류가 나오면 런타임을 설치해야 합니다.
- "The code execution cannot proceed because ... was not found"
- "You must install or update .NET"

설치 방법 (Windows, GUI)
1) 아래 공식 다운로드 페이지 접속
2) .NET 8 Desktop Runtime (Windows x64) 설치

다운로드 페이지
https://dotnet.microsoft.com/download/dotnet/8.0

설치 확인
- PowerShell에서 아래 명령 실행
  dotnet --list-runtimes
- "Microsoft.WindowsDesktop.App 8.x" 항목이 있으면 정상입니다.

명령줄 설치 (옵션, winget)
- PowerShell에서 아래 명령 실행
  winget install Microsoft.DotNet.DesktopRuntime.8
