# Motion Angle Test 운영 가이드

## 1. 개요
- 본 프로그램은 모터를 제어해 각도를 변경하면서 센서 2종 데이터를 동시 측정/저장하는 도구입니다.
- 측정 범위: `0 -> +10 -> ... -> +90 -> 0 -> -10 -> ... -> -90 -> 0`
- 축별 테스트: `X TEST START`, `Y TEST START`를 각각 실행

## 2. 장비/포트 구성
- 센서 1(상용센서): 시리얼 포트 1
- 센서 2(진동기울기센서): 시리얼 포트 2
- 모터 드라이버: 이더넷 (기본 `100.100.100.70`)
- 모든 포트(Open/Connect) 완료 전 테스트 시작 불가

## 3. UI 핵심
- 상태 표시:
- `현재 각도`: 센서 1 기준
- `현재 작업 상태`: 작업 준비 / 작업 중
- `모터 분해능`: 고정값 `0.1125`
- 모터 수동 버튼:
- `Error Clear` -> `PPC00`
- `Move Origin` -> `PMO011`
- `Move 0 Degree` -> `+1250 step`
- `Move Step` -> 입력 step 이동
- 테스트 실행 중(`TEST START`)에도 아래 Send 버튼은 사용 가능:
- 상용센서 `Send`
- 진동기울기센서 `Send`
- 모터 `Send`

## 4. 테스트 실행 플로우
1. X축 시작 시 `setdir6`, Y축 시작 시 `setdir5` 송신 후 `OK` 확인
2. 모터 스캔 `PMO011` 송신 후 10초 대기
3. `1250 step` 이동 후 1초 대기
4. 0도 미세조정 수행
5. 진동기울기센서 OFFSET 송신 (`<OFFSET,1,1>`) → MODE 설정 → SAM 설정 → ATIM(485만) → START (각 명령 간 100ms 대기)
6. 각도별 측정 수행
7. 정상 종료 시 `X축 측정을 완료했습니다.` 또는 `Y축 측정을 완료했습니다.` 팝업 표시
8. 테스트 종료 시 진동기울기센서 측정 STOP 명령

## 5. 각도 이동 규칙
- Y축:
- `+10` 단계: `+88 step`
- `-10` 단계: `-88 step`
- X축(극성 반전):
- `+10` 단계: `-88 step`
- `-10` 단계: `+88 step`
- 중간 복귀(`±800`)도 축 극성 규칙 동일 적용
- 각 각도의 coarse 이동 후 보정 시작 전 `1초` 대기

## 6. 기준각 보정 규칙
- 공통 루프:
- `±1 step 이동(모터 응답 수신까지 대기)` -> `1초 대기` -> 센서1(`get---x`) 읽기 -> `100ms 대기` -> 반복
- 허용오차:
- 시작 후 10초: `±0.05`
- 10초 초과: `±0.1` (완화)
- 종료 판정:
- 오차 만족 시 `1초 후` 1회 재확인
- 재확인도 만족 시 보정 종료
- 오차 증가가 유의미하면(step 반응 역방향으로 판단) 보정 step 방향 반전

## 7. 센서 수신/파싱 규칙
- 센서 1:
- 구분자 `\r`
- 방향 설정 응답은 개행 없는 `OK`도 처리
- 센서 2:
- 0도 미세조정 후 OFFSET → START 명령 1회 → 이후 스트리밍 수신
- `BaseStream.ReadAsync` 사용으로 최대 1ms 주기 데이터 수신 가능
- 패킷 단위 `[...]` 완성 후 파싱
- X 테스트: `[AN,0,X,Y]`의 `X` 저장
- Y 테스트: `[AN,0,X,Y]`의 `Y` 저장
- 수신된 모든 패킷을 `ConcurrentQueue`에 적재 (측정 구간에서만)

## 8. CSV 저장 규칙
- 저장 루트: 실행 경로 기준 `net8.0-windows\\csv` (즉 `AppContext.BaseDirectory\\csv`)
- 테스트 시작 시마다 폴더 생성:
- `yyyyMMdd_HHmmss`
- 동일 초 중복 시 `yyyyMMdd_HHmmss_1`, `_2`...
- 해당 테스트의 모든 CSV는 같은 폴더에 저장
- 파일명:
- `상용센서_축_각도도_yyyyMMdd_HHmmss.csv`
- `진동기울기센서_축_각도도_yyyyMMdd_HHmmss.csv`
- 파일 형식:
- 헤더 `시간,측정값`
- 데이터 시간 `yyyyMMdd HH:mm:ss:fff`
- 값 소수점 둘째 자리
- 샘플링 방식:
- 센서1(상용센서): `500ms` 간격으로 고정 수집, 샘플 수 = `round(측정시간(초) * 1000 / 500)`
  - 예: `30초 -> 60개`, `120초 -> 240개`
- 센서2(진동기울기센서): 스트리밍으로 수신된 **모든 데이터** 저장 (전송주기에 따라 데이터 수 결정)
  - 예: 전송주기 1ms, 120초 측정 → 최대 120,000개
- 파일 분할: 행 수가 `1,000,000`개 초과 시 `_2`, `_3`... 접미사로 새 파일 자동 생성

## 9. 안전/예외 처리
- 측정 중 센서1/센서2 차이 절대값 `>= 10도`면 에러 팝업 후 테스트 종료
- `STOP` 클릭 시 즉시 테스트 중단 후 작업 준비 상태 복귀
- 로그 시간 형식: `[yy-MM-dd HH:mm:ss:fff]`

## 10. 명령어 요약
- 센서1 읽기: `get---x` (예: `+030.364#0D`)
- 센서2 OFFSET: 0도 미세조정 완료 후 `<OFFSET,1,1>` 송신
- 센서2 스트리밍 시작: OFFSET 후 MODE 설정 → SAM 설정 → ATIM(485만) → START
- 232 mode : `<MODE,6>` → `<SAM,1>` → `<START>` (예: `[AN,0,0.35,29.99]`)
- 485 mode : `<MODE,1,6>` → `<SAM,1,1>` → `<ATIM,1,0>` → `<START,1>` (예: `[AN,0,1,0.35,29.99]`)
- 모터 스캔: `PMO011`
- 모터 에러 클리어: `PPC00`
- 모터 step 패킷: `(02)PMD0(len)1ML(step)(03)`
- 상용센서 방향: `setdir5`(Y), `setdir6`(X)
- 센서2 측정 종료 : 정상 종료 및 예기치 못한 상황 종료 시 STOP 송신
- 232 mode : '<STOP>'
- 485 mode : '<STOP,1>'
