3. judge_mode 방향별 검사 구현 FEAT

개요

JSON judge_mode 파라미터로 판정 모드 전환. 설정만으로 1/2 전환 가능.

mode동작
1 (기본)값 변화만 확인, 방향 무시 (Math.Abs)
2방향별 각각 확인, +/- 부호 포함 판정

방향 매핑 (포트 모니터로 확정)

축+ 방향- 방향확인 방법
X우측좌측우측 기울임 → X=+22도
Y뒤앞앞으로 기울임 → Y=-66도

judge_mode=2 팝업 및 PASS 조건
