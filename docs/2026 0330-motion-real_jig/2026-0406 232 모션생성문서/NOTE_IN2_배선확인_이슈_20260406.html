문제: PII00 값이 항상 03 — LED 상태와 무관

초기 추정 원인

  • IN2 센서 신호가 EMIO 보드까지 전달되지 않음
  • PII00의 bit 1이 홈 센서가 아닌 다른 I/O

해결 과정

하드웨어 담당자 확인: EMIO 보드 LED로 연결 상태 확인

  • EMIO 보드에서 IN1, IN2 LED 둘 다 켜짐 → 배선 정상
  • IN1 분리 후 PII00 → 02 (IN2만) → 비트 매핑 확인
  • 둘 다 분리 후 PII00 → 00 → 기준값 확인

원인: 원판 홈이 1개만 열려있고, 영점(0도) 위치에서 IN1/IN2 둘 다 같은 홈을 감지하고 있었음. 배선 문제가 아니라 원판 홈 구조 때문이었음.
