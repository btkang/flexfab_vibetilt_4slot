# NOTE: IN2 센서 EMIO 연결 이슈

## 날짜: 2026-04-06

## 현상
- IN2 센서 LED: 정상 동작 (홈 만나면 ON, 벗어나면 OFF)
- PII00 응답: 항상 `pii01400000000030000` (IN1=1, IN2=1)
- 원판 어느 위치에서든 값 변화 없음
- IN1/IN2 커넥터 바꿔 꽂아도 값 변화 없음

## 테스트 내용
1. 수평(0도) 위치 PII00 → `03`
2. 원판 45도 회전 후 PII00 → `03`
3. IN2 LED ON 상태에서 PII00 → `03`
4. IN2 LED OFF 상태에서 PII00 → `03`
5. IN1/IN2 커넥터 교체 후 PII00 → `03`

## 추정 원인
- IN2 센서 자체는 정상 (LED 동작 확인)
- **IN2 센서 신호가 EMIO 보드까지 전달되지 않음**
- PII00 응답의 `03` bit 1이 홈 센서 IN2가 아닌 다른 I/O일 가능성
- 또는 Axis 번호 불일치 (PII00=Axis1, 실제 모터=Axis2)

## 확인 필요 사항
1. IN2 신호선이 EMIO 보드 IN2 단자에 제대로 연결되었는지 확인
2. IN1 커넥터만 빼고 PII00 조회 → bit 0 변화 확인
3. `PII01` (Axis 2) 명령 테스트
4. EMIO 프로토콜 문서에서 PII 응답 비트 매핑 확인

## 대응
- IN2 폴링(PII00) 과회전 감지: **보류** (HW 확인 후 진행)
- 소프트 리밋(PMS): **구현 완료** (영점 후 ±8000 펄스 설정)
