## IN2 과회전 감지 리스크 정리

### 현재 상태
- IN2 센서: 정상 동작 (LED 확인)
- EMIO 배선: 정상 (PII00 비트 매핑 확인: bit1=IN2)
- 원판 홈: 1개만 열림 (IN1 영점용)
- 소프트 리밋(PMS): 구현 완료, 정상 동작 확인

### IN2 홈 추가 시 리스크
| 리스크 | 설명 | 심각도 |
|--------|------|--------|
| **IN1 영점 오동작** | 홈 추가 시 PMO011이 새 홈에서 잘못 정지 | **높음** |
| **원판 360도 회전** | 어디에 홈을 열어도 IN1이 지나감 | **높음** |
| **홈 크기 구분 불가** | IN1/IN2 센서가 같은 종류라 홈 크기로 구분 안 됨 | **중간** |

### 결론
- **소프트 리밋(PMS)**: 영점 후 ±8000 펄스 제한 → **채택 (구현 완료)**
- **IN2 폴링**: 코드 준비 완료, **원판 구조 변경(커스텀 제작) 또는 별도 원판 추가 시 활성화**
- IN2 홈 추가는 IN1 영점 오동작 리스크로 **현재 보류**

### IN2 배선 이슈 (해결)
- 초기 PII00 테스트 시 항상 `03` → IN2 위치에 홈이 열려있었음
- EMIO 보드 LED 확인 + IN1/IN2 개별 분리 테스트로 비트 매핑 확인 완료
- `00`/`01`/`02`/`03`/`05` 모든 조합 실측 확인
