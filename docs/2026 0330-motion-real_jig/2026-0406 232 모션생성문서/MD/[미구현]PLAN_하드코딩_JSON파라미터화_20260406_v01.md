# [미구현] PLAN: 하드코딩 → JSON 파라미터화

## 날짜: 2026-04-06

## 목적
MotionJig.cs의 하드코딩된 상수/대기시간을 workspace JSON의 param으로 이동.
양산 현장에서 코드 수정 없이 값 조절 가능하게.

## 대상 파라미터

## 구현 방식
- `GetParamInt(param, "key", default)` / `GetParamDouble(param, "key", default)` 사용
- 기존 헬퍼 그대로 활용
- JSON에 없으면 기본값 사용 (하위 호환)
- `const` → `GetParam` 호출로 변경

## 수정 파일
- `ff_vibetilt/MotionJig.cs` — 메인 수정
- workspace JSON — `_comment` 주석 추가

## 검증
1. 빌드 확인
2. JSON에 값 없이 실행 → 기본값으로 정상 동작
3. JSON에 값 넣고 실행 → 반영 확인
