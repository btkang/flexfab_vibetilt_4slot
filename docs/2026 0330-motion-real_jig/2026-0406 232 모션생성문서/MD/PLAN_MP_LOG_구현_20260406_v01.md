# PLAN: MP_LOG 구현 (양산용 로그 숨김)

## 목적
- `log_level: MP_LOG`일 때 양산에 불필요한 상세 로그(TX/RX, FINE step 등)를 숨긴다
- 검사 로직에는 영향 없음 (로그 출력만 조건부 처리)

## 방법
- `Cantops.FlexFab.LogConfig.IsTest` 가드로 상세 로그만 감싸기
- `IsTest == true` (TEST_LOG): 기존처럼 전부 출력
- `IsTest == false` (MP_LOG): 핵심 판정 결과만 출력

## 수정 대상 파일
- `ff_vibetilt/MotionJig.cs`
- `ff_vibetilt/VibeTilt.cs`

## 숨길 대상 (MP_LOG에서 안 보임)

| 태그 | 내용 | 비고 |
|------|------|------|
| `[EMIO] TX/RX` | 모터 명령 송수신 전부 | |
| `[GYRO] TX/RX` | 자이로 명령 송수신 전부 | |
| `[VL] TX/RX` | VL 센서 TX/RX + AN 스트리밍 | |
| `[VibeTilt] TX/RX` | VL 보드 명령 전부 | |
| `[FINE] 시작:` | 미세조정 시작 | |
| `[FINE] step N:` | 미세조정 매 스텝 | |
| `[FINE] 오차 증가` | 방향 반전 디버그 | |
| `[TILT] CSV 저장` | CSV 파일 저장 로그 | |
| `[VIBE] step 이동만` | 디버그 정보 | |
| `[VIBE] GAC NG` (재시도 중) | 중간 NG | 최종 OK만 남김 |

## 남길 대상 (MP_LOG에서도 보임)

| 태그 | 내용 |
|------|------|
| `[ZERO] 영점 초기화 시작/완료` | 작업 진행 상태 |
| `[ZERO] 홈 센서: IN1...` | 설정 확인 |
| `[FINE] 수렴 완료:` | 최종 수렴 결과 |
| `[CAL] OFFSET 검증:` | 캘리브레이션 판정 |
| `[TILT] === X축 -20도 측정 시작 ===` | 항목 시작 |
| `[TILT] -20도: 자이로=..., VL=..., OK/NG` | 기울기 판정 결과 |
| `[VIBE] === Y축 진동 측정 ===` | 항목 시작 |
| `[VIBE] GAC Y=1.0000 OK` | 진동 최종 판정 |
| 모든 FAIL 로그 | 실패 시 원인 파악 필요 |
| 검사 시작/결과/총 결과 | FlexfabForm.cs (변경 없음) |

## 구현 방식
로그 출력 함수를 감싸는 방식:

```csharp
// MotionJig.cs 내부 TX/RX 로그
if (Cantops.FlexFab.LogConfig.IsTest) log($"[EMIO] TX: {cmd}");

// FINE step 로그
if (Cantops.FlexFab.LogConfig.IsTest) log($"[FINE] step {i}: ...");

// FINE 수렴 완료는 항상 출력
log($"[FINE] 수렴 완료: ...");
```

1. workspace_motion_232.json에서 `log_level: "MP_LOG"` 변경
2. 실행하여 로그 확인 (상세 TX/RX 숨겨지는지)
