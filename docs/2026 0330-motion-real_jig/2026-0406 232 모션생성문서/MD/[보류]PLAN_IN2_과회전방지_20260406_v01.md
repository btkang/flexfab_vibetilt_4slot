# [보류] PLAN: IN2 과회전 방지 (케이블 꼬임 방지)
# 소프트 리밋(PMS) → 구현 완료 / IN2 폴링 → 코드 준비, HW 보류

## 날짜: 2026-04-06

## 목적
자이로 센서 케이블이 모터 회전 시 꼬이는 것을 방지.
영점(IN1)과 별도로 IN2를 과회전 감지 전용으로 사용.

## 현재 상태
- IN1: 영점 전용 (PMO011) — 정상 동작 중
- IN2: EMIO에 배선 완료, SW 미구현
- 원판 홈: 1개만 열림 (IN1용), IN2용 홈은 테이프로 가림 상태
- pcom/BG01 모두 IN1만 사용했음 (IN2 활용 전례 없음)

## 구현 방식: IN2 폴링 (1차)

### 동작
1. 검사 항목 시작 전 PII00 명령으로 IN2 센서 상태 확인
2. IN2가 감지되면 → "과회전" 경고 로그 + 검사 중단
3. IN2가 미감지면 → 정상 진행

### 구현 위치
- `ff_vibetilt/MotionJig.cs` — PII00 조회 + IN2 상태 파싱 헬퍼
- `flexfab_mini/FlexfabForm.cs` — 검사 루프에서 항목 사이 체크 (또는 MotionJig 내부)

### PII00 응답 형식
- 송신: `PII00`
- 응답: `pii01400000000010000` (BG01 소스 참고)
- IN2 비트 위치 확인 필요 (실측 테스트)

### 체크 시점
- 각 검사 항목(proc) 시작 전

### HW 준비
- IN2 배선: 완료
- 원판 IN2용 홈: 테이프 제거 필요 (또는 IN2 센서 위치에 맞게 조정)

## 2차 (예정): 소프트 리밋(PMS) 보조
- PMO011 영점 완료 후 PMS07/PMS08로 ±N 펄스 리밋 설정
- IN2가 놓치는 구간의 최후 방어

## 비교표

| 방식 | 센서 | PMO011 충돌 | 전원 리셋 | 실시간 정지 | 신뢰성 |
|------|------|-------------|-----------|------------|--------|
| PMO011 영점 (현재) | IN1 | - | 없음 | HW 자동 | 높음 |
| 소프트 리밋 (PMS) | 없음 | 있음 | 있음 | HW 자동 | 낮음 |
| IN2 폴링 (PII00) | IN2 | 없음 | 없음 | SW 지연 | 높음 |

## 검증
1. PII00 명령 송수신 테스트
2. IN2 센서 감지 시 응답 값 확인
3. 정상 검사 → 과회전 없이 통과
4. 과회전 유도 → 감지 + 경고 확인
