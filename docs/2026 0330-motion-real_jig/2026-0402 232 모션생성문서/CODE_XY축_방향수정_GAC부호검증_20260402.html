6. 수정 전 문제 원인 분석

6.1 근본 원인

AngleToSteps() 함수는 move_axis 파라미터로 step 부호를 결정:

private static int AngleToSteps(double angleDelta, string axis)
{
    int axisSign = (axis == "X") ? -1 : 1;
    return (int)Math.Round(angleDelta / STEP_RESOLUTION) * axisSign;
}
항목axis/move_axisAngleToSteps 입력axisSign결과 step
#4 X축 기울기 -20도axis="X"-20-1+178 (왼쪽) ✓
#5 Y축 진동 (수정 전)move_axis="Y"90+1+800 (왼쪽) — X축결합에서 반시계!
#5 Y축 진동 (수정 후)move_axis="Y"-90+1-800 (오른쪽) — X축결합에서 시계!
#11 X축 진동move_axis="Y"-90+1-800 (오른쪽) ✓

기울기는 axis 파라미터를 사용하고, 진동은 move_axis를 사용. X축 결합에서 기울기는 axis="X" (axisSign=-1)이지만, 진동은 move_axis="Y" (axisSign=+1)로 부호가 반대. 따라서 target_angle을 -90으로 설정하여 step 방향을 보정.

6.2 Math.Abs() 제거

// Before:
double absCheckVal = Math.Abs(checkVal);
bool samplePass = absCheckVal >= vibeMin && absCheckVal <= vibeMax;

// After:
bool samplePass = checkVal >= vibeMin && checkVal <= vibeMax;

사양서 SPEC이 양수(+) 기준이므로 절대값 비교는 부호 오류를 숨김. raw 값으로 직접 비교하도록 변경.
