## 1. MotionJig.cs 수정

### 1-1. 기존 12단계 시퀀스 → 새 구조로 교체

**기존 구조 (삭제):**
- RunMotionSequence() 12단계 고정 시퀀스
- ±10.5도 하드코딩 pulse
- BG01 PMS 15개 초기화 명령
- msopen/msclose 시퀀스

**새 구조 (참조 코드 기반):**

```
영점 시퀀스 (1회, #4 시작 전):
  1. PPC00 에러 클리어
  2. PMO011 원점복귀 → 10초 대기
  3. MoveSteps(1250) → 0도 위치
  4. FineAdjust(0도) — 자이로 ±1step 수렴 루프
  5. <OFFSET,1,1> (VL 센서 캘리브레이션)
  6. StartStreaming (MODE→SAM→ATIM(485)→START)

각 검사항목:
  1. MoveSteps(목표각도 step) — coarse 이동
  2. FineAdjust(목표각도) — 자이로 미세조정
  3. 측정 (AN 또는 GAC 읽기)
  4. 자이로 값 vs VL 값 비교 → 오차 SPEC 내 PASS
  5. 안전 체크: 차이 ≥ 10도 → 에러
```

### 1-3. 핵심 상수/메서드

```csharp
// 참조 코드에서 가져올 값
const double STEP_RESOLUTION = 0.1125;  // 도/step
const int STEPS_PER_10DEG = 88;
const int STEPS_TO_ZERO = 1250;         // 원점→0도
const int SENSOR_DIFF_ERROR = 10;       // 자이로-VL 차이 에러 임계값

// 각도→step 변환
int AngleToSteps(double angle) => (int)Math.Round(angle / STEP_RESOLUTION);

// X축 극성 반전
int GetAxisSign(string axis) => axis == "X" ? -1 : 1;
```

```csharp
// #4: X축 기울기 — 각도 순서: -20, -45, +20, +45
```

```csharp
// #5: +90도 이동 → GAC Y값 = 0.99~1.01
```

### 1-8. 재사용할 기존 코드
- `EmioSend()`, `EmioRecvUntil()`, `EmioFlush()` — EMIO TCP 통신
- `VlSend()`, `VlRecv()`, `VlClear()` — VL 센서 통신
- `GyroSetZero()`, `GyroGetAngle()` — 자이로 통신
- `TryParseGacSample()`, `TryParseAnSample()` — 응답 파싱
- `MakeResult()`, `GetParam*()` — 유틸리티
- `EvaluateVibeSample()` — 진동 판정 (SPEC만 변경)

### 1-9. 삭제/교체할 코드
- `RunMotionSequence()` 12단계 — 새 시퀀스로 교체
- `AngleInitLoop()` — `FineAdjust()`로 교체
- BG01 PMS 15개 초기화 — 참조 코드 방식으로 간소화
- `msopen/msclose` — 필요시 유지, 사양서에 없으면 제거
