5. BG01 vs VL10 센서 비교

5.4 오차 원인 분석

VL10이 큰 각도에서 오차가 큰 근본 원인:

VL10은 가속도 기반 기울기 센서입니다. 가속도계는 중력 벡터의 성분(sin/cos)으로 기울기를 계산하는데, 이 원리상 각도가 커질수록 감도가 떨어집니다.

  • 0도 근처: sin 변화율이 크고 → 감도 높음 → 오차 작음
  • 45도: sin/cos 변화율 감소 → 감도 저하 → 오차 증가
  • 90도: cos 변화율 최소 → 감도 최저 → 오차 최대
BG01은 자이로 센서가 포함된 IMU라 자체 보정이 가능하고, 측정 범위가 ±10.5도로 좁아서 이 문제가 발생하지 않았습니다.

VL10은 자이로 없이 가속도만으로 ±45도를 측정하므로, 구조적으로 큰 각도에서 오차가 커지는 특성이 있습니다. 이는 센서 불량이 아니라 가속도 기반 기울기 센서의 물리적 한계입니다.

5.3 기울기 측정 방식

  1. 자이로 FineAdjust로 목표 각도 수렴 (허용 0.05도)
  2. VL 센서: MODE,06 → SAM,1 → START → AN 스트리밍
  3. 1초 안정화 → 초기 데이터 버림 → 0.5초 대기 → 3초 수집
  4. 마지막 샘플 값 사용
  5. 자이로-VL 차이를 SPEC과 비교 (OK/NG)

7. 개발팀 확인 필요 사항

  1. SPEC 재검토: 현재 SPEC이 VL 센서 특성 대비 너무 엄격한지 확인. 이대리 데이터에서도 20도 0.4~0.6도 오차.
  2. 이대리 데이터 해석: 이대리 측정 데이터를 기반으로 SPEC이 확정된 것인지, 아니면 SPEC 확정 전 데이터인지.
  3. 소프트웨어 보정(gain correction) 허용 여부: 센서별 보정 계수 적용이 양산에서 가능한지.
  4. 센서 장착 정렬 확인: VL 센서 X축과 지그 회전축의 정렬 상태.
