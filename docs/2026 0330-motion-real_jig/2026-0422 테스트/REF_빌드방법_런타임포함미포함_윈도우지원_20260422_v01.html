빌드 방법 및 Windows 지원 범위

프로젝트: flexfab_mini (net8.0-windows)  |  작성일: 2026-04-22

1. 빌드 방법

구분 방법 결과물 경로 특징
런타임 미포함
(Framework-dependent)		 VS2022 → 빌드 구성 Release → 솔루션 다시 빌드 output/Release/net8.0-windows/ 파일 작음. 대상 PC에 .NET 8 런타임 설치 필요
런타임 포함
(Self-contained)		 cmd 명령어 (아래 참조) flexfab_mini/output/Release/
net8.0-windows/win-x64/publish/		 파일 큼(수십 MB). 런타임 설치 불필요. 깡통 PC 배포용

2. 런타임 포함 빌드 명령어

64비트 PC용 (win-x64)

dotnet publish flexfab_mini/flexfab.csproj -c Release -r win-x64 --self-contained true

32비트 PC용 (win-x86)

dotnet publish flexfab_mini/flexfab.csproj -c Release -r win-x86 --self-contained true
※ AnyCPU(미명시) 빌드는 Self-contained 불가. 런타임 포함 배포 시 반드시 RID(win-x64 또는 win-x86)를 명시해야 함.
※ 32/64비트 혼용 배포 시 각각 따로 publish → 폴더 분리 배포.

3. 배포 폴더 구조

D:\...\10.실행파일배포\26MMDD_X.Y.Z_motion_232_485\
├── X.Y.Z_6MMDD-RELEASE-미포함\          ← output/Release/net8.0-windows/ 복사
└── X.Y.Z_6MMDD-RELEASE-닷넷런타임포함\  ← flexfab_mini/.../publish/ 복사
※ workspace JSON(workspace_*.json)은 빌드 시 자동 복사되지 않음.
※ Debug / Release / publish 3곳 수동 적용 필요.

4. Windows 버전별 .NET 8 지원 범위

OS 아키텍처 .NET 8 지원 Self-contained 실행 비고
Windows 11 x64 ✅ ✅ win-x64
Windows 11 x86 (32bit) ✅ ✅ win-x86
Windows 10 x64 ✅ ✅ win-x64
Windows 10 x86 (32bit) ✅ ✅ win-x86
Windows 7 x64 / x86 ❌ ❌ 불가 .NET 8 자체 미지원. Self-contained로도 해결 불가
Windows XP x86 ❌ ❌ 불가 .NET 8 자체 미지원. .NET Framework 4.0 이하만 가능
※ .NET 8 최소 요구사항: Windows 10 이상
※ Windows 7 지원 필요 시 → .NET Framework 4.x 또는 .NET Core 3.1로 다운그레이드 필요
※ 이 프로젝트(net8.0-windows)는 Windows 10 / 11 전용
