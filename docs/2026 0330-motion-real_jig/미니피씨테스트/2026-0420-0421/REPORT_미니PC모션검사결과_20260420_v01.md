## 4. FAIL 분석

### 4.1 VL20 FAIL #1 — Y축 FW 버전 불일치

| 항목 | 내용 |
|---|---|
| 현상 | X축 보드 = `F/W ver.2.0.2.3`, Y축 보드 = `F/W ver.2.0.2` — 동일한 검사에서 FW가 서로 다름 |
| 기대값 (워크스페이스) | `F/W ver.2.0.2.3` |
| Y축 응답 | `[VER,0,1,F/W ver.2.0.2]` (addr=1 주소 필드 표기 차이 주목 — 원래 addr=2 기대, 응답은 addr=1) |
| 빈도 | 반복 1/300에서 FAIL (반복 2는 Fail stop으로 #8 판정까지 도달 못함) |

**해결 방향:**
- **A안(권장):** Y축 보드 FW를 X축과 동일한 `2.0.2.3`으로 업그레이드
- B안: 워크스페이스의 기대 FW를 `2.0.2` 계열로 완화 (2.0.2 & 2.0.2.3 모두 허용) — 단, 버전 검증 의미 약해짐

### 4.2 VL20 FAIL #2 — Y축 APPCFG 응답 없음

| 항목 | 내용 |
|---|---|
| 명령 | `<MODE,2,0>` (addr=2, mode=0) |
| 응답 | **빈 문자열 (대괄호 없음)** |
| 후속 명령 | `<APPCFG,2>` → 역시 빈 응답 |
| 특이점 | **같은 addr=2로 VIBE/TILT 측정은 정상 동작** — APPCFG 계열만 무응답 |

**원인 후보:**
- **Y축 보드 FW(2.0.2)가 addr=2 APPCFG 명령 미지원 가능성** (X축 FW 2.0.2.3에는 있지만 2.0.2엔 없음)
- 또는 APPCFG 명령 패킷 파싱 버그 (485 Y축 보드 한정)

**해결 방향:**
- Y축 FW 2.0.2.3 업그레이드 시 동시 해결 가능성 높음 (4.1 A안과 연계)
- FW 변경 없이 해결하려면: 워크스페이스 #16 검사를 X축(addr=1) 기준으로 변경 or 검사 삭제

### 4.3 VL20 첫 시도 FAIL — 제품 장착/방향 오류 (운영 이슈)

- TILT X -20° 센서 차이 20.14° → VL 센서가 지그 움직임을 인식 못함
- VIBE Y GAC=-0.01 → Z축이 있어야 할 자리에 Y축 배치
- **두 번째 시도부터는 정상** → **작업자 오조립** 확인
