8. dual 모드 JSON 저장 주의사항

완전 17항목 저장 조건: dual 모드에서 각 시리얼의 결과 JSON이 완성되려면 해당 시리얼이 X 역할 및 Y 역할을 모두 full cycle로 거쳐야 함.
  • Cycle N (X 역할): 시리얼 N의 X측 검사 (#0~#6) → pending 저장
  • Cycle N+1 (Y 역할): 시리얼 N의 Y측 검사 (#7~#16) + pending과 merge → 최종 JSON
중간에 fail-only 재검사가 섞이면 pending이 덮어씌워져 부분 저장됨. 양산 검증 시에는 clean한 연속 full cycle로 진행 권장.
