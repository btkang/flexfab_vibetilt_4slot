4. FAIL 분석 — VL20 전류 검사

4.1 현황

  • spec: 4.0 ~ 7.0 mA (MP_workspace_VL20_board_485.json:142-143, 커밋 6571f9a 기준)
  • 실측: 3.76 ~ 3.80 mA (3회 반복, 편차 ±0.02mA 이내로 매우 안정)
  • 하한 미달 폭: 약 0.2 mA (spec 하한의 약 5% 부족)

4.2 원인 후보

후보근거검증 방법
spec이 현 하드웨어와 괴리 3회 반복 측정이 3.78mA로 매우 일관적 → 실기기 편차가 아닌 구조적 차이 개발팀 사양서 원본 재확인, 실제 보드 소비전류 기준 재산정
DPM 측정 오차 / 보정 필요 scale=1000 적용 구조 (A→mA 변환) 에서 오차 가능성 별도 멀티미터로 크로스체크
보드 조립/부품 편차 1대 샘플 한정 가능 다른 개체(복수 보드) 추가 측정

4.3 조치 방향 제안

  1. 개발팀에 사양서 4.0~7.0 mA 근거 재확인 (VL20 485 보드 정격 소비전류)
  2. 필요 시 spec 하한을 3.5 mA 또는 3.0 mA로 완화 후 _comment 필드에 변경 사유 기록
  3. Debug + Release 양쪽 워크스페이스 동시 수정 (운용 규칙)
