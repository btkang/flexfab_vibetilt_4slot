2. 기울기(TILT) 검사 — PASS/FAIL 조건

측정 원리: 지그 모터로 제품을 목표 각도까지 회전 → 자이로(레퍼런스)와 VL 센서(피검체) 동시 측정 → 오차 판정

Spec (허용 오차)

목표 각도허용 오차예시
±20도±0.2도자이로 20.00도일 때 VL은 19.8~20.2도 이내
±45도±0.5도자이로 45.00도일 때 VL은 44.5~45.5도 이내

FAIL 조건

조건판정설명
tail 10개 중 1개라도 spec 벗어남FAILall_in_spec 모드 (가장 엄격)
AN 파싱 실패 (4회 연속)FAIL센서 응답 없음 or 데이터 깨짐
자이로-VL 차이 ≥ 10도FAIL센서 하드웨어 이상 (리트라이 불가)

PASS 조건

마지막 10개 샘플 전부가 spec 범위 안에 들어야 PASS.
실패 시 최대 3회 리트라이 (총 4회 시도). 1회라도 PASS 되면 최종 PASS.

Y축+20도 → +45도 → -20도 → -45도

6. 영점 초기화 — 조건과 시간

영점 초기화 흐름

소프트리밋 해제 (±8000) → 자이로 방향 설정 → 홈 센서 탐색 (PMO011) → 1,500ms 안정화 → FineAdjust (자이로 피드백) → 소프트리밋 설정 (±1600)

FineAdjust 수렴 조건

0도 (영점)비영점 (20/45도)
엄격 허용치0.03도0.05도
완화 허용치 (10초 후)0.05도0.10도
최대 스텝250250
방향 반전 임계오차 증가 0.02도 이상 시 반전

Y축 영점 — skip_home

Y축은 skip_home=true → 홈 센서 탐색 생략, FineAdjust만 수행.
이유: Y축 영점은 X축 VIBE 측정 직후 수행 — 이미 0도 근처에 있으므로 FineAdjust만으로 충분.
시간 절약: ~17초

7. 모터 홈(Home) 잡는 방식

홈 탐색 과정

┌─────────────────────────────────────────────────────────────┐ │ 원반 (슬롯 디스크) │ │ │ │ ┌──┐ ┌──┐ │ │ ─────┤IN1├───── 원반 회전축 ────────────────┤IN2├───── │ │ └──┘ 홈 센서 1 └──┘ 홈 센서 2 │ │ (주 사용) (보조) │ │ │ │ 1. 현재 위치에서 ±200 step 탈출 (슬롯 위 감지 방지) │ │ 2. PMO011 명령 → 모터 회전 시작 │ │ 3. 슬롯(파진 곳) 통과 시 센서 감지 → 모터 정지 │ │ 4. 감지 위치에서 1250 step 이동 → 0도 위치 │ │ 5. FineAdjust (자이로 피드백) → 0.03도 이내 수렴 │ └─────────────────────────────────────────────────────────────┘
단계동작시간
1. 탈출현재 위치가 슬롯 위인 경우 ±200 step 이동~1초
2. 홈 탐색PMO011 명령 → 모터 회전, 슬롯 감지까지최대 20초
3. 0도 이동IN1 기준 1250 step / IN2 기준 200 step~2초
4. 안정화기계적 진동 안정화 대기1.5초
5. FineAdjust자이로 피드백으로 0.03도 이내 수렴~5~15초

홈 센서 선택

모드사용 센서설명
in1IN1 (PMO011)주 센서 — 0도까지 1250 step
in2IN2 (PMO012)보조 센서 — 0도까지 200 step
auto번갈아 사용매 회차 IN1/IN2 교대 (내구성)

8. 원반 파진 데(슬롯) 인식 방법

원반 양쪽에 말굽자석 2개가 부착되어 있고, 각 위치에 광학 센서(IN1, IN2)가 설치됨.
원반이 회전하면서 파진 부분(슬롯)이 센서를 통과할 때 빛이 통과 → 감지 신호 발생.

인식 흐름

단계EMIO 명령응답의미
홈 탐색 시작PMO011pmo0011 (ACK3)모터 회전 시작, 슬롯 감지 대기
슬롯 감지됨-pms3010센서가 슬롯(파진 곳)을 통과 → 모터 자동 정지
이미 슬롯 위PMO011ACK4현재 슬롯 위에 있음 → ±50 step 탈출 후 재시도

왜 말굽자석 2개인가?

  • 원반 360도 중 정반대 위치에 2개 슬롯 → 최대 180도만 회전하면 홈 감지 가능
  • IN1은 EMIO에 연결, IN2는 연결 안 됨 (현재 IN1만 실제 사용)
  • 홈 센서는 영점 초기화 시에만 사용 — 측정 중에는 자이로 피드백으로 위치 제어

9. 하드웨어 리밋 없는 이유 + 소프트웨어 리밋

하드웨어 리밋이 없는 이유

구조적 제약:
  • 원반 구조: 회전축에 제품 + 케이블이 연결되어 있어 리밋 스위치 설치 공간 없음
  • 회전 범위: 검사 범위가 ±90도인데, 물리적 스토퍼를 설치하면 케이블 라우팅과 충돌
  • 정밀도: 기계적 스토퍼 충격이 자이로/센서 측정에 영향을 줄 수 있음
  • 대안:** 소프트웨어 리밋으로 충분히 안전 — EMIO 모터 컨트롤러가 SW 리밋 지원

소프트웨어 리밋 설정

상태리밋+리밋-각도 범위용도
홈 탐색 중 +8,000 step-8,000 step ±900도 홈 탐색을 위한 자유 회전 (케이블 꼬임은 자이로 감시)
영점 이후 (정상) +1,600 step-1,600 step ±180도 검사 범위 ±90도 + 안전 여유 (케이블 꼬임 방지)

소프트웨어 리밋 동작 방식

EMIO 모터 컨트롤러의 PMS07(+방향), PMS08(-방향) 레지스터에 리밋값 설정.
모터가 리밋 위치에 도달하면 EMIO 자체에서 이동 거부 → 프로그램에서 추가 보호 불필요.

이중 보호:
  • 1차: EMIO 소프트 리밋 (±1600 step)
  • 2차: 프로그램에서 이동 전 IO 상태 확인 (PII00)

10. FineAdjust 수렴 알고리즘

동작 원리

자이로 센서(SOLAR-360-420)를 기준으로, 현재 각도와 목표 각도의 차이(오차)가 허용치 이내가 될 때까지 모터를 1 step 단위로 미세 이동.

1 step = 0.1125도 (모터 분해능)

적응형 스텝 크기

오차 범위이동량설명
|오차| > 1.0도필요량의 80%오버슈트 방지
|오차| > 0.2도필요량의 50%감속 진입
|오차| ≤ 0.2도1 step미세 조정 (0.1125도/step)

수렴 예시 (로그)

[FINE] 시작: target=20.00, current=18.053, 오차=1.947
[FINE] step 0: moved=13, current=20.935, 오차=0.935    ← 80% 이동 (대폭)
[FINE] step 1: moved=-4, current=20.818, 오차=0.818    ← 방향 반전
[FINE] step 2: moved=-3, current=20.589, 오차=0.589    ← 50% 이동
...
[FINE] step 11: moved=1, current=19.957, 오차=0.043    ← 1 step 미세 조정
[FINE] 수렴 완료: target=20.00, actual=19.964, 오차=0.036  ← 0.05도 이내 수렴

방향 반전 로직

이전 스텝 대비 오차가 증가하면 → 즉시 방향 반전 (오버슈트 감지).
이를 통해 목표 각도를 사이에 두고 진동하면서 수렴.
