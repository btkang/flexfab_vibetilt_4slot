## 변경 파일
- `flexfab_mini/SerialMac.cs`
- `flexfab_mini/SerialMac.Designer.cs`
- `flexfab_mini/FlexfabForm.cs`

## 변경 내용

### 1. 보드 시리얼 팝업 +/- 버튼 위치 수정 (SerialMac.cs)
- `textBox_Serial.Width = 240` 을 버튼 생성 전으로 이동 → 버튼이 텍스트박스 바로 오른쪽에 배치
- 시리얼 최소값 0 → 1 변경 (`Math.Max(1, ...)`)

### 2. +/- 버튼 순서 변경: -(왼쪽) +(오른쪽)
- **보드 시리얼 팝업** (SerialMac.cs)
- **모션 X축/Y축** (FlexfabForm.cs ShowDualSerialDialog)

### 3. 모션 듀얼 팝업 X/Y축 시리얼 최소값 분리 (FlexfabForm.cs)
- X축: 최소 1 (00001 이하 불가)
- Y축: 최소 0 (00000 허용)
- `adjustSerial` 람다에 `minVal` 파라미터 추가

### 4. 보드검사 PASS 시리얼 표시 추가 (FlexfabForm.cs)
- 보드검사 PASS 후 `label_passSaved`에 `PASS SAVED: {시리얼}` 표시 (모션과 동일)
- `label_passSaved` 위치를 검사자 변경 버튼 위로 이동 (651, 700 → 651, 645)

### 5. PASS SAVED 라벨 우클릭 메뉴 추가 (FlexfabForm.cs)
- `결과 파일: {시리얼}.json` → 결과 JSON 파일 열기
- `폴더 열기` → 오늘 날짜 Result 폴더 열기

### 6. 시리얼 중복 체크 범위 변경 (FlexfabForm.cs)
- `Result/` 전체 → `Result/{프로젝트폴더}/` 로 범위 축소
- 다른 워크스페이스 결과에 걸리지 않음

### 7. 시리얼 중복 팝업 대형 폰트로 변경 (FlexfabForm.cs)
- `MessageBox` → `ShowLargeConfirmDialog` (dupCheck=2 차단)
- `MessageBox` → `ShowLargeYesNoDialog` 신규 추가 (dupCheck=1 경고, 예/아니오)
- 문구에서 "검사를 진행할 수 없습니다." 제거
- 폰트 16pt

### 8. 보드 시리얼 팝업 글자 크기 16pt (SerialMac.Designer.cs, SerialMac.cs)
- 폼 크기: 454x262 → 600x400
- 라벨/텍스트박스/OK 버튼: 16pt (맑은 고딕)
- +/- 버튼: 16pt Bold, 50x40
- 안내 문구: 12pt
- 창 위치: CenterScreen → CenterParent (메인 폼 기준 중앙)

### 9. 설정 JSON 열기 방식 변경 (FlexfabForm.cs)
- `notepad.exe` 하드코딩 → `UseShellExecute = true` (기본 프로그램으로 열기)

### 10. workspace JSON 파일명 변경 (Debug + Release)
- `workspace_board_232_MP.json` → `MP_workspace_VL10_board_232.json`
- `workspace_board_232_TEST.json` → `TEST_workspace_VL10_board_232.json`
- 232계열: `VL10_`, 485계열: `VL20_` 접두사
- MP/TEST를 파일명 앞으로 이동 (정렬 편의)
