## 변경 내용

### 1. 보드 시리얼 팝업 +/- 버튼 위치 수정 (SerialMac.cs)
- `textBox_Serial.Width` 설정을 버튼 생성 전으로 이동 → 버튼이 텍스트박스 바로 오른쪽에 배치
- 시리얼 최소값 0 → 1 변경 (`Math.Max(1, ...)`)

### 2. +/- 버튼 순서 변경: -(왼쪽) +(오른쪽)
- **보드 시리얼 팝업** (SerialMac.cs)
- **모션 X축/Y축** (FlexfabForm.cs ShowDualSerialDialog)

### 3. 모션 듀얼 팝업 X/Y축 시리얼 최소값 분리 (FlexfabForm.cs)
- X축: 최소 1 (00001 이하 불가)
- Y축: 최소 0 (00000 허용)
- `adjustSerial` 람다에 `minVal` 파라미터 추가

### 4. 보드검사 PASS 시리얼 표시 추가 (FlexfabForm.cs)
- 보드검사 PASS 후 `label_passSaved`에 `PASS SAVED: {시리얼}` 표시 (모션과 동일)
- `label_passSaved` 위치: 검사자 변경 버튼 위 (639, 645), 폰트 9pt

### 5. PASS SAVED 라벨 우클릭 메뉴 추가 (FlexfabForm.cs)
- `결과 파일: {시리얼}.json` → 결과 JSON 파일 열기 (파일명 표시)
- `폴더 열기` → 오늘 날짜 Result 폴더 열기

### 6. 시리얼 중복 체크 범위 변경 (FlexfabForm.cs)
- `Result/` 전체 → `Result/{프로젝트폴더}/` 로 범위 축소
- 다른 워크스페이스 결과에 걸리지 않음

### 7. 시리얼 중복 팝업 대형 폰트로 변경 (FlexfabForm.cs)
- `MessageBox` → `ShowLargeConfirmDialog` (dupCheck=2 차단)
- `MessageBox` → `ShowLargeYesNoDialog` 신규 추가 (dupCheck=1 경고, 예/아니오)
- 문구에서 "검사를 진행할 수 없습니다." 제거
- 폰트 16pt

### 8. 시리얼 접두사 팝업 대형 폰트로 변경 (FlexfabForm.cs)
- `MessageBox` → `ShowLargeConfirmDialog` (차단) / `ShowLargeYesNoDialog` (경고)
- 문구 간결화: "시리얼 접두사를 확인하세요 (VL1- 필요)"

### 9. 보드 시리얼 팝업 글자 크기 16pt (SerialMac.Designer.cs, SerialMac.cs)
- 폼 크기: 454x262 → 600x400
- 라벨/텍스트박스/OK 버튼: 16pt (맑은 고딕)

- 안내 문구: 12pt
- 창 위치: CenterScreen → CenterParent (메인 폼 기준 중앙)
- 초기화 버튼 추가 (OK 오른쪽, 접두사 유지 + 00001 리셋)

### 10. 모션 듀얼 시리얼 팝업 글자 크기 16pt (FlexfabForm.cs)

- `workspace_board_232_TEST.json` → `TEST_workspace_VL10_board_232.json`

### 13. 시리얼 표시 X/Y 2줄 + pending 표시 (FlexfabForm.cs)
- `label_Serial`: "X축: {시리얼} / Y축: {시리얼}" → 2줄로 분리
- 검사 완료 시: "X축: VL1-00004 PASS\nY축: VL1-00003 PASS"
- X축 pending 저장 후: label_Serial에 "펜딩(X축완료): {시리얼}" 추가 (3줄째)

### 15. JSON 설정값 숫자화 (FlexfabForm.cs + JSON 16개)
- `show_log`: true/false → 1/0
- `fail_continue`: true/false → 1/0
- `test_mode`: "dual"/"single" → 0/1
- 코드: `Convert.ToInt32`로 파싱 변경
- `log_level`은 공통 라이브러리 영향으로 문자열 유지
- JSON _comment도 숫자 기준으로 업데이트
