배경: 개발팀 — "마지막 OFFSET SAVE된 축은 스펙인, 다른 축은 스펙아웃 예상"

3. X축 OFFSET 없이 X축 기울기 재측정 → FAIL (13:59) — Y축 OFFSET이 덮어씌움

결론

1. OFFSET SAVE 후 재측정 시 보정값 유지 — X축/Y축 모두 SAVE 후 OFFSET 없이 PASS 확인

2. 마지막 OFFSET SAVE된 축만 유효 — Y축 OFFSET 후 Y축 PASS, X축 FAIL (덮어씌움)

3. 양산 검사에서의 의미
  • 검사 순서: X축 OFFSET → X축 측정 → Y축 OFFSET → Y축 측정 (현행 유지)
  • X축은 OFFSET 직후 측정하므로 PASS
  • Y축은 마지막 OFFSET이므로 제품에 저장됨
  • 고객은 Y축 보정값 기준으로 사용 (설치 방향에 따라 재 OFFSET 필요)

4. 검사 순서가 중요 — 반드시 X축 먼저 OFFSET+측정, Y축 나중에 OFFSET+측정
