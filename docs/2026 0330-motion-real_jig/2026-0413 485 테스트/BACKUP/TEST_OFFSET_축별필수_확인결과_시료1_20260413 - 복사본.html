최종 결론: OFFSET은 축별로 필수 — X축 1회로 Y축 커버 불가
OFFSET 없으면 센서 원시 오프셋(0.25~0.48도)이 측정값에 그대로 반영되어 SPEC 초과

진동(GAC) 3항목 전부 OFFSET 없어도 PASS.
진동은 가속도(G) 측정이므로 0.25~0.48도 오프셋의 영향이 무시할 수준 (cos(0.48°) ≈ 0.99996).
OFFSET은 기울기(AN) 측정에만 영향을 미침. 진동(GAC)은 무관.

최종 결론

1. OFFSET은 축별로 필수 — X축 OFFSET 1회로 Y축 커버 불가

2. OFFSET 없으면 X축도 FAIL — 센서 원시 오프셋(이 개체: X=0.25도, Y=0.48도)이 측정값에 반영

3. 개체마다 원시 오프셋이 다를 수 있음 — 일부 개체는 우연히 PASS 가능하나 품질 보장 불가

4. 고객 사용 vs 공장 검사 구분 필요
  • 고객: 1회 설치 → OFFSET 1회 → 양축 보정됨 (맞음)
  • 공장 지그: X결합 → Y결합으로 제품 이동 → 축별 OFFSET 필수

5. 권장사항: 현행 유지 (X축 OFFSET + Y축 OFFSET + 각각 APPCFG SAVE)
