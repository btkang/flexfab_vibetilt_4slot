최종 결론: OFFSET은 축별로 필수 — X축 1회로 Y축 커버 불가
OFFSET 없으면 센서 원시 오프셋(0.25~0.48도)이 측정값에 그대로 반영되어 SPEC 초과

1포트몬 수동 확인 (0도 수평, X축 결합)

COM11에서 OFFSET 상태 변경 후 <AN,1> 쿼리

상태AN X (도)AN Y (도)비고
OFFSET=1 (보정됨)0.03-0.01정상 (≈0도)
OFFSET=0 (해제)-0.250.48원시 오프셋 노출
확인: OFFSET 해제 시 X축 0.25도, Y축 0.48도의 원시 오프셋 존재.
이 값은 센서의 물리적 설치 오차이며, OFFSET 명령이 이를 보정함.

최종 결론

1. Y축 OFFSET 필수 (개발팀 확인) — 자이로가 1축 센서이므로 X/Y 방향별 OFFSET 각각 필요

2. X축은 OFFSET SAVE 후 보정값 유지 — 테스트 3에서 X축 스펙아웃은 포트몬 테스트 잔여 영향. 실제 양산에서는 SAVE 후 스펙 이내 예상

3. 개체마다 원시 오프셋이 다름 — 시료1=0.53도, 시료2=0.78도. OFFSET 없이 양산 시 품질 보장 불가

4. 공장 지그에서는 축별 OFFSET 필수
  • X결합 → Y결합으로 제품 이동 시 자이로 방향(setdir)이 바뀌므로 각각 OFFSET 필요
  • 고객은 1회 설치 → OFFSET 1회로 충분

5. 진동(GAC)도 개체에 따라 FAIL — 시료1은 OK였지만 시료2에서 #14 GAC X FAIL (1.02)
  • 원시 오프셋이 큰 개체에서는 기울기뿐 아니라 진동까지 영향

6. 권장사항: 현행 유지 (X축 OFFSET + Y축 OFFSET + 각각 APPCFG SAVE)
