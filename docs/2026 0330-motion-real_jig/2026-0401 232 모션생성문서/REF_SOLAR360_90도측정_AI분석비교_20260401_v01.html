2. 논쟁 핵심: sin 감도 저하 vs DSP 선형화

2.1 sin 감도 문제 (일반론 — 맞는 말)

단순 가속도계가 arcsin(ax/1G)로 각도를 계산하면:
• 0도 근처: cos(0)=1 → 감도 최대
• 90도 근처: cos(90)=0 → 감도 거의 0
• 90도에서 1도 변화 시 sin 변화량 = 0.00015 → 노이즈 이하

2.2 SOLAR-360-420의 차이점 (데이터시트 근거)

근거내용
측정 범위±180° (90도를 훨씬 넘음)
정확도 표기"전 범위에서" ±0.03°
내부 처리"high performance MEMS sensor + digital signal processor → response is linearised"
아날로그 설정±90° range 예시 제공 (-90°=4mA, +90°=20mA)
분해능0.002° (1Hz 필터)
결론: 제조사가 DSP로 내부 보정/선형화를 하므로, 단순 sin 감도 문제가 그대로 적용되지 않음

2.3 주의할 점

  • 데이터시트 스펙은 이상적 조건 기준
  • 실제 90도에서 정확도가 0~45도와 동일한지는 확인 필요
  • 진동, 온도, 장착 오차 등 환경 요인에 의한 추가 오차 가능
  • 우리 프로젝트에서는 진동 측정 시 90도 위치를 사용하지만, 90도 "각도 정밀도"가 아니라 GAC(가속도) 값을 보므로 자이로 90도 정확도는 직접적 이슈 아님

이유: 90도에서 자이로 FineAdjust가 수렴 불안정
재분석: sin 감도 문제보다는 setzcur 영점 버그일 가능성 (2026-04-01 수정 완료)

3.3 VL10 센서의 90도 문제 (별개)

이대리 20개 제품 데이터에서 90도 오차 급증 (avg 0.36~0.63°):
• VL10 센서(가속도 기반)의 sin 감도 문제
• VL10은 DSP 선형화가 SOLAR-360 수준이 아닐 수 있음
• 자이로(SOLAR-360)의 90도 문제와 VL10의 90도 문제는 별개
