# 기울기 측정 비교 분석: 개발팀(이대리) vs 우리 지그

작성일: 2026-04-01 | 브랜치: step6-motion-jig-test

## 결론 (요약)

| 항목 | 이대리 (20개 제품) | 우리 (시료1, 토크1A) |
|------|-------------------|---------------------|
| 20도 오차 | avg 0.03~0.06 / max 0.16 | 0.093 ~ 0.195 |
| 45도 오차 | avg 0.07~0.14 (40~50도 보간) / max 0.58 | **0.526 ~ 0.837** |
| 20도 SPEC ±0.2 | **20/20 PASS** | 3/4 PASS (−20도 경계) |
| 45도 SPEC ±0.5 | **거의 전부 PASS** (40~50도 기준) | **2/4 FAIL** |
| 오차 배수 | 기준 (1x) | **2~9배 큼** |

**핵심: 동일 VL10 센서인데 이대리는 스펙인, 우리는 스펙아웃 → 센서 특성이 아니라 측정 환경 차이**

## 4. 오차 원인 분석

### 4.1 이전 결론 (CODE_오차분석_20260331) — 수정 필요

이전 문서에서는 "VL 센서의 가속도 기반 기울기 측정 물리적 한계"로 결론.
**하지만 이대리 20개 제품 데이터에서 40~50도 avg 0.07~0.14로 충분히 스펙인.**
→ 센서 자체 한계가 아니라 **우리 측정 환경의 문제**.

### 4.2 우리 오차가 큰 원인 후보

| # | 원인 후보 | 설명 | 확인 방법 |
|---|----------|------|----------|
| 1 | **OFFSET 시점** | 영점에서 OFFSET 후 각도 이동 vs 이대리 방식 차이 | 이대리 코드의 OFFSET 시퀀스 확인 |
| 2 | **FineAdjust 정밀도** | 자이로 수렴 허용치 0.05도 → 0.03도로 줄여야? | 이대리 코드의 수렴 조건 확인 |
| 3 | **센서 정렬** | VL 센서 X축과 지그 회전축 미정렬 (크로스축 커플링) | 토크 1A로 Y축 흔들림은 줄었으나 완전하지 않을 수 있음 |
| 4 | **AN 판정 방식** | 마지막 샘플 1개 vs 평균값 사용 | chart에서 ±0.03 진동 확인됨 |
| 5 | **스트리밍 안정화 시간** | 1초 버림+0.5초 대기+3초 수집 → 충분한지 | 이대리 수집 시간 비교 |
| 6 | **자이로 setdir/setzcur** | 자이로 방향 설정이 센서 축과 불일치 | setdir 값 확인 |
| 7 | **기계적 백래시** | 한 방향 이동 후 반대 방향 오차 비대칭 | 음수 방향 오차가 더 큰 패턴과 일치 |

### 4.3 비대칭 오차 패턴

우리 데이터에서 **음수 방향 오차 > 양수 방향 오차**:
- -20도: 0.195 vs +20도: 0.093 (2.1배)
- -45도: 0.837 vs +45도: 0.526 (1.6배)

이대리 데이터에서도 동일 경향:
- X-가 X+보다, Y-가 Y+보다 오차 약간 큼
- 다만 차이가 우리만큼 크지 않음

→ **기계적 백래시 + 우리쪽 추가 오차** 복합 원인 가능성

## 5. 다음 조치 (세부조정 시 참고)

### 5.1 우선 확인
1. 이대리 MotionAngleApp 소스에서 **OFFSET 시퀀스** 확인 (영점 초기화 순서)
2. 이대리 코드의 **FineAdjust 수렴 조건** 확인
3. 이대리 코드의 **AN 판정 방식** (마지막 샘플 vs 평균)

### 5.2 실험 계획
1. OFFSET 후 **동일 위치 반복 측정** — 재현성 확인
2. **양방향 접근** 테스트 — CW/CCW로 같은 각도 도달 시 차이
3. 수렴 허용치 0.05 → **0.03도**로 변경 후 재측정
4. AN **평균값** 판정으로 변경 후 재측정

### 5.3 SPEC 관련
- 20도 ±0.2: 이대리 데이터 기준 **충분히 달성 가능** (max 0.16)
- 45도 ±0.5: 이대리 데이터 기준 **달성 가능** (40~50도 avg 0.07~0.14)
- 90도: 이대리 데이터에서도 avg 0.36~0.63 → **별도 SPEC 필요**
- **현재 SPEC 자체는 유효 — 우리 환경 개선이 우선**
