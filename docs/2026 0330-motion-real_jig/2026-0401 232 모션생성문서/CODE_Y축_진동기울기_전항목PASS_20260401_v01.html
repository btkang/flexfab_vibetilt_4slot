2. 핵심 수정 사항

2.1 검사 순서 변경 (OFFSET vs GAC)

발견: <OFFSET,1> 캘리브레이션이 GAC 가속도 값을 리셋함
  • OFFSET 전: [GAC,0,-1.01,0.00,0.01,0.58] → X=-1.01 (중력 1G 정상)
  • OFFSET 후: [GAC,0,0.01,0.00,1.00,0.58] → X=0.01 (리셋됨, NG)
변경 전 (FAIL)변경 후 (PASS)
#7 영점 → #8 OFFSET → #9 저장
→ #10 기울기 → #11 진동 (FAIL) → #12 진동 		#7 영점 → #11 진동 (PASS) → #12 진동 (PASS)
→ #8 OFFSET → #9 저장 → #10 기울기
원리: OFFSET은 VL 센서의 기울기(AN) 측정 영점을 보정하는 명령. 동시에 GAC 가속도 출력도 보정 좌표계로 리셋됨.
GAC로 축별 중력 1G를 확인하려면 OFFSET 보정 전의 원시 가속도가 필요.
