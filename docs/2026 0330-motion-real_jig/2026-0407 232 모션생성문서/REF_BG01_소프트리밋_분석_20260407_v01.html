BG01 초기화 순서

1. PPC00 (에러 클리어)
2. PMS 파라미터 설정 (해상도, 토크, 속도, 가속도)
3. PMS071288000 / PMS08129-8000  ← 1단계: 초기 리밋 ±8000
4. PMO011 (영점 복귀)            ← 홈 센서로 원점 이동
5. PML011 (위치 확인)            ← 원점 -500 펄스 검증
6. PMS0812812000 / PMS08129-1000 ← 2단계: 운용 리밋 재설정
7. PMD 명령으로 검사 시작

BG01 검사 범위와 리밋 값 관계

  • 검사 각도: ±10.5도 (±1500 펄스)
  • 원점 위치: -500 펄스
  • 운용 리밋: +12000 / -1000
  • 안전 마진: 5000 펄스 이상

소프트 리밋 초과 시 동작

  • pmd5011 응답 = 소프트 리밋 충돌 (일시적 경고, FAIL 아님)
  • EMIO가 자동 복구 후 pmd0011 (정상 완료) 응답
  • BG01은 pmd5011 발생 시 1회 재시도, 재시도 후에도 실패 시 FAIL
