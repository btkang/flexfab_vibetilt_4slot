## 날짜: 2026-04-07

## BG01 소프트 리밋 2단계 설정

| 단계 | 시점 | Plus (PMS07) | Minus (PMS08) | 목적 |
|------|------|-------------|--------------|------|
| 1단계 | 영점 복귀 **전** | +8000 | -8000 | 홈 복귀 중 안전 확보 |
| 2단계 | 영점 복귀 **후** | +12000 | -1000 | 검사 운용 범위 제한 |

## BG01 초기화 순서

```
1. PPC00 (에러 클리어)
2. PMS 파라미터 설정 (해상도, 토크, 속도, 가속도)
3. PMS071288000 / PMS08129-8000  ← 1단계: 초기 리밋 ±8000
4. PMO011 (영점 복귀)            ← 홈 센서로 원점 이동
5. PML011 (위치 확인)            ← 원점 -500 펄스 검증
6. PMS0812812000 / PMS08129-1000 ← 2단계: 운용 리밋 재설정
7. PMD 명령으로 검사 시작
```

## BG01 검사 범위와 리밋 값 관계

- 검사 각도: ±10.5도 (±1500 펄스)
- 원점 위치: -500 펄스
- 운용 리밋: +12000 / -1000
- 안전 마진: 5000 펄스 이상

## 소프트 리밋 초과 시 동작

- `pmd5011` 응답 = 소프트 리밋 충돌 (일시적 경고, FAIL 아님)
- EMIO가 자동 복구 후 `pmd0011` (정상 완료) 응답
- BG01은 pmd5011 발생 시 1회 재시도, 재시도 후에도 실패 시 FAIL

## pcom 로그 분석 (pmd5011 발생 패턴 동일)

pcom 프로그램에서도 동일한 패턴 확인 (x.txt 로그):

```
[E.RCV] > pmo0011          ← 원점 복귀 완료
[E.RCV] > pmp0011          ← 자동 알림
...
[E.RCV] > pmd5011          ← 소프트 리밋 에러 (첫 이동)
[E.RCV] > ppc606138000     ← 자동 응답
[E.RCV] > pmd0011          ← 복구 후 정상 완료
```

### pcom vs BG01 vs 우리 — pmd5011 대응 비교

| 항목 | pcom | BG01 | 우리 |
|------|------|------|------|
| pmd5011 발생 | 원점 후 첫 이동 | 원점 후 첫 이동 | Z축 0도 복귀 시 |
| 대응 | 무시, pmd0011 대기 | 무시, 재시도 1회 | 무시(continue), pmd0011 대기 |
| 결과 | 정상 진행 | 정상 진행 | 정상 진행 |

### pcom FineAdjust 패턴
- `get---x`로 자이로 각도 읽기 → pmd 이동 → 반복
- 0.001도 단위까지 수렴 (약 16회 반복)
- 우리 FineAdjust와 동일한 로직

### 결론
- pcom/BG01/우리 프로그램 모두 **pmd5011을 정상 동작으로 취급**
- 소프트 리밋 에러는 EMIO 특성상 원점 복귀 후 첫 이동에서 발생하는 **정상 패턴**

### VIBE vs TILT 동작 차이
| 항목 | BG01 | 우리 |
|------|------|------|
| TILT | PMD 완료 대기 → 정지 후 측정 | 동일 |
| VIBE | PMD **이동 중** GAC 폴링 (진동 측정) | PMD 완료 후 정지 상태에서 GAC 측정 |

참고: BG01은 모터 이동 중 가속/감속 진동을 측정하지만, 우리는 정지 후 1G 확인 방식

### 소프트 리밋 운용값 비대칭 이유
- +12000: 검사가 양(+) 방향으로 더 많이 이동
- -1000: 음(-) 방향은 원점 근처만 사용
- 우리는 ±90도 대칭 검사 → **대칭 리밋이 적절**

### 위치 확인 방식 차이
| 항목 | BG01 | 우리 |
|------|------|------|
| 위치 검증 | PML011 (펄스 위치 읽기) | 자이로 FineAdjust |
| 방식 | EMIO 내부 카운터 기반 | 외부 센서(자이로) 기반 |
| 정밀도 | 펄스 단위 | 0.001도 단위 |

### 우리 소프트 리밋 적용 시 참고 포인트
1. **BG01과 모터/해상도가 다름** → 펄스 값 직접 비교 불가, 각도 기준으로 환산
2. **검사 범위가 다름** → BG01 ±10.5도, 우리 ±90도
3. **리밋 비대칭 불필요** → 우리는 양방향 대칭 검사
4. **pmd5011 대응 동일** → 무시하고 pmd0011 대기 (이미 구현됨)
5. **2단계 리밋 적용 검토** → 영점 전(넓음) + 영점 후(검사 범위 기반)
6. **속도/가속도 파라미터** → 검사 시간 최적화 시 조정 가능
