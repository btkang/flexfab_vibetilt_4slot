왜 X축과 Y축 부호가 반대?

물리적 지그 배치 때문:

  • X축: 모터 반시계 회전 → 시계 각도 증가 → step과 각도 부호 반대
  • Y축: 모터 반시계 회전 → 반시계 각도 증가 → step과 각도 부호 같음

변환 공식

int axisSign = (axis == "X") ? -1 : 1;
return (int)Math.Round(angleDelta / _stepResolution) * axisSign;

구체 예시

X축 +20도 이동

  • angleDelta = 20
  • steps = Round(20 / 0.1125) × (-1) = 178 × (-1) = -178 step
  • 모터: -178 step (시계 방향)

Y축 +90도 이동

  • angleDelta = 90
  • steps = Round(90 / 0.1125) × (+1) = 800 × (+1) = +800 step
  • 모터: +800 step (반시계 방향)
