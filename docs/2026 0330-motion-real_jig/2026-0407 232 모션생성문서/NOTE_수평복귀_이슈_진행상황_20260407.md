# NOTE: 수평 복귀 이슈 진행 상황

## 날짜: 2026-04-07

## 문제
검사 종료 후 -90도 상태에서 수평(0도)으로 복귀해야 하는데 동작 안 됨

## 시도 이력

### 1차: PMO011만 전송 (STX/ETX 없이)
- Send("PMO011") → EMIO가 인식 못함 (프레임 없음)
- 결과: 동작 안 함

### 2차: STX/ETX 프레임 추가 + PMO011
- Send("\x02PMO011\x03") → pmo0011 응답 받음 → 홈(135도)으로 이동
- PMD 1250 step 추가 → pmd0011 응답 안 옴
- 결과: 홈(135도)에서 멈춤, 0도로 안 감

### 3차: 자이로 측정 후 직접 step 이동
- 자이로 get---x → -89.8도 확인 → 798 step 이동 → pmd0011 응답 → 수평 복귀 성공
- 하지만 2차 보정에서 다시 +90도로 이동 (방향 반전 문제)
- 결과: 1차 이동 성공, 2차 보정 실패

### 4차: 고정 +800 step → 자이로 확인 → 보정 (현재)
- +800 step 전송 → pmd0011 응답 받음
- 자이로 확인: -89.5도 (안 움직임)
- 보정: +795 step → 결국 +90도로 감
- 결과: +800 step이 실제로 이동하지 않는 문제

## 현재 상태
- +800 step 명령은 pmd0011 응답이 오지만 **실제 모터가 안 움직임**
- 소프트 리밋 또는 에러 상태로 EMIO가 이동 거부 추정
- 자이로 측정 방식(3차)은 1차 이동에서 성공했었음

## 다음 시도 방안

2. finally에서 **소프트 리밋 ±8000 재설정** 후 이동
3. 3차 방식(자이로 측정 → step 이동)으로 되돌리고 2차 보정 제거
