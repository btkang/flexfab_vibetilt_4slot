## 불일치 상세

### 1. OFFSET 응답 (불일치)
- **사양서:** `<OFFSET,1,1>` → `[OFFSET,0,1,1]` (ID 포함)
- **실제:** `<OFFSET,1,1>` → `[OFFSET,0,1]` (ID 없음, 232와 동일)
- **비고:** 명령은 485 형식(ID 포함)인데 응답은 232 형식

### 2. AN 스트리밍 형식 (확인 필요)
- **사양서:** `[AN,1,X,Y]` (1=ID)
- **실제:** `[AN,0,-0.10,0.60]` (0=에러코드? ID?)
- **비고:** OFFSET 송신 전 잔류 AN 데이터로 수신됨. 정확한 형식 확인 필요

## 개발팀 확인 요청 사항
