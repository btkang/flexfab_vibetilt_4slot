2. 통신 사양

RS485 인터페이스. 모든 명령/응답은 ID 필드가 존재하고 ASCII 코드를 기본으로 동작.

항목값
Baud Rate115200 bps
Data Bits8
Stop Bits1
ParityNone

3.1. 데이터 패킷 구조

방향구조
명령 (TX)<명령, ID, 설정값> 또는 <명령, ID>
응답 (RX)[명령, RV, ID, 설정값]
응답 순서: [명령, RV, ID, 설정값] — RV(Return Value) → ID 순서 확정
필드설명
Head0 <명령 시작
Head1 [응답 시작
SP ,구분자
RV상태에 따라 응답 (0=정상)
ID디바이스 ID
Tail0 >명령 종료
Tail1 ]응답 종료

3.2. CRC 적용

CRC-16/UTMS 사용. '|' 없으면 CRC 미사용.

CRC 미사용: <GAC,1> → [GAC,0,1,0.15,-0.41,0.91,0.58]
CRC 사용:   <GAC,1|66EF> → [GAC,0,1,0.15,-0.41,0.91,0.58|8B9E]
CRC 예시의 GAC 응답 [GAC,0,1,...]은 3.1절 패킷 구조 [명령,RV,ID,...]와 일치 (RV=0, ID=1)

3.3. Return Value (RV)

RV설명
0정상 수신 및 동작
1패킷을 수신할 수 없는 상태
2유효하지 않은 패킷 (파라미터 미작성 등)
3CRC가 일치하지 않음
4알 수 없는 명령어
5레지스터에 쓴 데이터가 맞지 않음
6드라이버 접근 실패
7레지스터 쓰기 실패
8레지스터 읽기 실패
9파라미터 값의 범위가 벗어남

4.1.3. Set/Get Sensor Value Measurement Mode

MODE 설정

방향형식예시
명령<MODE, ID, X><MODE,1,01>
응답[MODE, RV, ID, X][MODE,0,1,01]

모드 목록:

값설명
00Default (측정 안 함)
01Raw Accel Gyro Data
02G scale Accel Data (GAC)
03Rms Accel Data
06Angle Data (AN)
09G scale Accel + Angle Data

4.1.3.2. Output Mode 2: G scale Accel Data (스트리밍)

ASCII 출력

방향형식예시
응답 (자동)[GAC, ID, X, Y, Z, RMS] (6필드)[GAC,1,0.12,0.03,1.00,1.01]
스트리밍은 RV 없이 [GAC, ID, X, Y, Z, RMS] — 쿼리 응답(7필드)과 형식이 다름

4.1.5. Get G Scale Accel Data (단건 쿼리)

방향형식예시
명령<GAC, ID><GAC,1>
응답[GAC, RV, ID, X, Y, Z, RMS] (7필드)[GAC,1,0,0.12,0.03,1.00,1.01]
주의: 예시 [GAC,1,0,...]에서 1,0의 순서가 3.1절 패킷 구조(RV,ID)와 반대.
3.2절 CRC 예시 [GAC,0,1,...]이 패킷 구조와 일치하므로, 4.1.5절 예시가 오기(RV↔ID 뒤바뀜)로 판단

비고:

  • real-time 데이터 1회 측정
  • Accel_X,Y,Z: X,Y,Z축 중력가속도(G), Range: -4.00~4.00G
  • Rms_3_axis: 3축 RMS, Range: 0.00~4.00G

4.2.4. Set/Get Offset Calibration

OFFSET 설정

방향형식예시
명령<OFFSET, ID, X><OFFSET,1,1>
응답[OFFSET, RV, ID, X] (4필드)[OFFSET,0,1,1]

OFFSET 확인

방향형식예시
명령<OFFSET, ID><OFFSET,1>
응답[OFFSET, RV, ID, X] (4필드)[OFFSET,0,1,1]

비고:

  • X: 0~1 (Default: 0 = 사용 안 함)
  • OFFSET 명령은 현재 Z축 가속도를 1G로, X,Y축 가속도/기울기를 0G로 설정
  • OFFSET=1 설정 시 현재 설치면 기준으로 데이터 획득 가능

OFFSET 적용 전후 비교 (PDF 비고)

<OFFSET,0> → [GAC,0,-0.11,-0.19,0.99,1.01]  [AN,0,-10.90,6.41]
<OFFSET,1> → [GAC,0,0.00,0.00,1.00,0.58]     [AN,0,0.00,0.00]
주의: 비고의 GAC/AN 예시는 RS-232 형식(ID 없음)으로 보임. RS-485 환경에서의 실제 형식과 다를 수 있음.
