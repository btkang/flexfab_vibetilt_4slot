# PLAN: 기울기(TILT) 판정 로직 변경

**작성일:** 2026-04-14  
**대상:** 모션지그 232/485, X축/Y축/XY축결합 — 전체 TILT proc  
**파일:** `ff_vibetilt/MotionJig.cs`

---

## 1. 배경

- 현재 판정: 스트리밍 수집 후 **마지막 1개 샘플**로 PASS/FAIL 판정 (BG01 싱글샷 방식 답습)
- 문제: 마지막 1개 값이 노이즈/이상치일 경우 오판 가능성
- BG01 기존 코드: 싱글샷 + **리트라이 3회** (총 4회 시도)
- 외부 AI 권고: 다수 샘플 기반 판정 (trimmed mean, median, all-in-SPEC 등)
- 회사 방침: 평균(average) 사용 지양

## 2. 변경 내용

### 판정 방식 변경

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 수집 시간 | 1000ms (하드코딩) | `tilt_stream_duration` (JSON, 기본 1000ms) |
| 판정 샘플 | 마지막 1개 | 마지막 N개 (`tilt_judge_tail_count`, 기본 10) |
| 판정 기준 | 마지막 1개 SPEC 이내 | 4가지 모드 선택 (`tilt_judge_mode`) |
| FAIL 시 | 즉시 FAIL | 리트라이 (`tilt_retry_count`, 기본 3, 총 4회 시도) |

### 판정 모드 (`tilt_judge_mode`)

| 모드 | 의미 | 강도 |
|------|------|------|
| `all_in_spec` | 마지막 N개 **전부** SPEC 이내 | 가장 엄격 |
| `trimmed_mean` | 상하 10% 제거 후 평균 | 중상 (이상치 제거) |
| `median` | 마지막 N개 중앙값 | 중간 (이상치 내성) |
| `average` | 마지막 N개 평균 | 중간 (노이즈 민감) |
| `last` | 마지막 1개 값 (BG01 방식) | 가장 느슨 |

### 노이즈 판정 (P2P) — 옵션, 기본 OFF

- 판정 모드와 **독립적으로 동작** (어떤 모드든 추가 체크)
- tail N개 중 Max - Min > limit → FAIL (평균 PASS여도)
- `tilt_noise_check: false` (기본 OFF), 필요 시 `true`로 활성화

## 3. 판정 로직 (의사코드)

```
for attempt = 0 to (1 + tilt_retry_count):
    스트리밍 수집 (tilt_stream_duration ms)
    전체 샘플 파싱 → allSamples (약 100개)
    
    tailSamples = allSamples 마지막 tilt_judge_tail_count개
    
    if tailSamples 전부 SPEC 이내:
        PASS → break
    else:
        로그 출력: "NG (attempt N/4), tail 중 X개 벗어남"
        if 마지막 attempt:
            최종 FAIL
        else:
            재측정 대기 → 다음 시도
```
