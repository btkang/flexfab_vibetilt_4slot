8. 결론

  • 232 모션지그 TEST 3회 + MP 5회 = 총 8회 ALL PASS
  • 진동 스트리밍 (MODE 02) 정상 동작: ~100샘플 수집, tail 5개 판정
  • 기울기 스트리밍 (MODE 06) 정상 동작: ~110샘플 수집, tail 10개 판정
  • 판정 모드 all_in_spec(엄격) + 리트라이 3회 안정 동작
  • MP 평균 2m51s (양산 허용 범위)
  • 2번 시료 Y축 GAC=0.98 경계값 재현 (개체 특성, SPEC 이내)
  • MongoDB 업로드 정상 (ctsm.product, Compass 검증 완료)
  • 구분선 로그 매 검사 시작마다 출력 확인
