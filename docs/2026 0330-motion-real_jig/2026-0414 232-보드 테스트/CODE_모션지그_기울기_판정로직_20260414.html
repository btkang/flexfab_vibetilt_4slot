3. 판정값 결정 방식

현재: 마지막 1개 샘플로 판정 (평균 아님)

3-1. TryParseAnFromRaw 코드 (라인 1280~1295)

private static bool TryParseAnFromRaw(string raw, bool isRs485, string axis,
    out double value, out List<double> allSamples)
{
    value = 0;
    allSamples = new List<double>();
    bool found = false;

    foreach (var frame in ExtractBracketFrames(raw))
    {
        if (!TryParseAnSample(frame, isRs485, out double x, out double y))
            continue;

        double v = (axis == "X") ? x : y;
        allSamples.Add(v);    // 전체 샘플 저장 (CSV용)
        value = v;             // 매번 덮어씀 → 마지막 값만 남음
        found = true;
    }
    return found;
}

3-2. 값 사용처

변수내용용도
value (vlAngle)마지막 1개 AN 샘플SPEC 판정에 사용
allSamples전체 AN 샘플 (~100개)CSV 저장용 (판정 미사용)
주의: 100개 수집하고 마지막 1개만 사용. 마지막 샘플이 노이즈이면 잘못된 판정 가능.
개선 옵션: 전체 평균 / 마지막 N개 평균 / 중앙값 등

4. SPEC 판정 로직

4-1. 판정 흐름 (2단계)

1단계: 센서 차이 에러 체크 (라인 911~920)

double diff = Math.Abs(gyroAngle - vlAngle);
if (diff >= sensorDiffError)   // 기본 10도
    → 즉시 FAIL (장착 오류 등 심각한 이상)

2단계: SPEC 오차 판정 (라인 922~931)

double absAngle = Math.Abs(targetAngle);
double tolerance = absAngle >= 40
    ? tilt_tolerance_45 (기본 0.5)    // ±45도
    : tilt_tolerance_20 (기본 0.2);   // ±20도

double error = vlAngle - gyroAngle;   // 오차 = VL - 자이로
bool anglePass = error >= -tolerance && error <= tolerance;

4-2. 판정 기준표

조건기준결과
|자이로 - VL| >= 10도sensor_diff_error즉시 FAIL + 중단
±20도 오차±0.2 이내OK
±45도 오차±0.5 이내OK
4개 각도 중 1개 NG-전체 FAIL + 중단

4-3. 판정 예시 (로그)

[TILT] -20도: 자이로=-19.977, VL=-19.940, 오차=0.037 [-0.2~0.2] OK
       → error = -19.940 - (-19.977) = +0.037
       → -0.2 <= 0.037 <= 0.2 → OK

[TILT] +45도: 자이로=44.975, VL=44.780, 오차=-0.195 [-0.5~0.5] OK
       → error = 44.780 - 44.975 = -0.195
       → -0.5 <= -0.195 <= 0.5 → OK
