7. FineAdjust (정밀 각도 수렴)

파라미터값설명
strict_tolerance0.05도첫 60초 동안 적용
relaxed_tolerance0.1도60초 초과 시 적용
max_steps250최대 스텝 수 (초과 시 FAIL)
fine_confirm_wait500ms수렴 확인 대기
fine_step_wait500ms이동 후 안정 대기
방향 반전 임계0.02도오차 증가 시 방향 반전

수렴 알고리즘

  1. 자이로 현재 각도 읽기
  2. 오차 = |목표 - 현재|
  3. 오차 > tolerance → step 이동 (오차 비례)
  4. 오차 증가 감지 → 방향 반전
  5. 오차 ≤ tolerance → 500ms 대기 후 재확인 → 수렴 완료
