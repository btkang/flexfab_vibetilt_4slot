결론: OFFSET(캘리브레이션)은 AN(각도 출력) 영점만 설정하며, GAC(가속도 원시값)에는 영향을 주지 않음.
• OFFSET = AN 각도 출력의 0도 기준점 설정 (소프트웨어 보정)
• GAC = 가속도 원시값 (하드웨어 측정, 중력 1G)
따라서 엑셀 사양서 순서(영점 → 캘 → 저장 → 기울기 → 진동)로 확정.
