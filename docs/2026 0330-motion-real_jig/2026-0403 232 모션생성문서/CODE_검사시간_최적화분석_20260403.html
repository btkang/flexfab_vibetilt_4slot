작성일: 2026-04-03 | 브랜치: step6-motion-jig-test | 대상: X축 + Y축 (MotionJig.cs 공통)

따라서 최적화 포인트도 X축/Y축 모두 동일하게 적용됨.

2. 최적화 포인트 (효과 큰 순서)

2.1 PMO011 홈복귀 후 대기 — -7~8초 ×2회

위치: MotionJig.cs:329
현재: Thread.Sleep(10000); — PMO011 응답 후 10초 추가 대기
문제: 응답(pmo0011)은 모터 도착 완료 의미. 추가 10초는 과도함. 
// MotionJig.cs:323-329
EmioSend(emio, "PMO011", log);
if (!EmioRecvUntil(emio, "pmo0011", 15000, log))
{
    log("[ZERO] FAIL: PMO011 timeout");
    return false;
}
Thread.Sleep(10000);  // ← 10초 → 2~3초로 단축 가능
항목현재최적화절감
PMO011 후 대기10,000ms2,000~3,000ms-7~8초
적용 횟수X축 1회 + Y축 1회 = 2회-14~16초

2.2 FineAdjust step 후 대기 — -50~60% (기울기 전체)

위치: MotionJig.cs:711-712
현재: 10step 초과 시 1000ms, 이하 시 500ms 대기
문제: 자이로 응답은 실제 ~100ms. 모터 안정화도 200~300ms면 충분. 
// MotionJig.cs:711-712
int waitMs = Math.Abs(moveSteps) > 10 ? 1000 : 500;
Thread.Sleep(waitMs);  // ← 단축 가능
이동 크기현재 대기최적화비고
>10 step1000ms500ms큰 이동 후 안정화
≤10 step500ms200~300ms미세 조정
수렴 확인 (라인 671)1000ms500ms최종 안정화 확인
기울기 1각도당 FineAdjust 평균 5~7회 반복. 4각도 × 2축 = 40~56회 호출.
300ms 단축 × 50회 = 약 15초 절감

4. 적용 우선순위 (권장)

1순위 (즉시 적용, 리스크 낮음):
• PMO011 후 대기: 10초 → 3초 (MotionJig.cs:329)
• AN 스트리밍 대기: 500ms → 300ms (MotionJig.cs:436)

2순위 (실측 후 적용):
• FineAdjust 대기: 500ms → 200~300ms (MotionJig.cs:711-712)
• 자이로 타임아웃: 2000ms → 800ms (MotionJig.cs:1146)
• 수렴 확인 대기: 1000ms → 500ms (MotionJig.cs:671)
